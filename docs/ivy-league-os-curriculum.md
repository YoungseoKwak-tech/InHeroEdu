# InHero Signature Program — Ivy League Operating System (ILOS)

**부제 — 아이비리그 학생들은 *무엇을* 배우는가가 아니라 *어떻게* 배우는가**

> 이건 "공부법 강의"가 아니라 **운영체제(OS) 설치 프로그램**이다.
> 학생은 강의를 듣는 게 아니라, 강의를 마칠 때마다 **실제 결과물**을 하나씩 손에 쥔다.
> SAT·AP·에세이는 주인공이 아니다 — 그것들은 이 OS 위에서 **자동으로 따라오는 산출물**이다.

---

## 0. 왜 이 프로그램인가 (포지셔닝)

- "SAT 1550 만드는 법"은 경쟁자가 많다. **"17세 국제학생이 스스로 관심사를 발견하고 → 연구·프로젝트로 키우고 → 아이비리그 학습 시스템을 구축하는 과정 전체"**를 하나의 OS로 묶는 프로그램은 거의 없다.
- 학부모가 가장 비싸게 결제하는 건 **점수**가 아니라 **사고방식과 자생력**이다. SAT는 점수를 주고, ILOS는 **어디를 가도 스스로 성장하는 능력**을 준다.
- **차별화 핵심 = "이건 유튜브에서 못 본다."** 매 강의 70% 이상이 이론이 아니라 **실물**이다:
  실제 Cornell 노트 · 실제 AP 단권화 자료 · 실제 연구노트 · 실제 교수 컨택 이메일 · 실제 Notion · 실제 캘린더 · 실제 프로젝트 문서 · 실제 TEDx 운영 자료 · 실제 InHero 제작 과정.

### 운영 원칙 (강의 ≠ 시청, 강의 = 변환)
모든 레슨은 다음 루프를 갖는다:

`강의 → 과제 → 결과물(artifact) → 피드백 → 다음 레슨 unlock`

예: "논문 읽는 법"은 영상으로 끝나지 않는다 →
**논문 3편 읽기 → Literature Matrix 작성 → 제출 → 다음 레슨 잠금 해제.**

### 대상
- 국제학교/해외고 학생 · 미국 대학 진학 준비생 · 미국 대학 재학생 · 자기주도 역량을 키우려는 학생
- **국제학생 특화**: 영어가 모국어가 아닌 상태에서의 학습 레이어, 해외에서 미국 연구실·인턴·교수에 접근하는 법, 비자/시간대/재정 현실까지 반영.

### 총 구성
**6 Seasons · 25 Modules · 105 Lessons · 50시간+ · 워크북 + Notion 템플릿 + 캡스톤 포함**

### 정직성 (브랜드 신뢰)
- 합격·출판을 **보장하지 않는다.** 대신 **스스로 할 수 있는 능력**과 **현실적 기대치·윤리**를 가르친다.
- 대신 써주는 컨설팅(주제추천·설계·대필·교정)과 **정반대** — "결과물을 대신 만들어주는 게 아니라, 혼자서도 만들 수 있는 사람을 만든다."

# InHero Signature Series — Researcher OS  *(별도 시그니처 트랙)*
**부제 — 혼자서 연구를 시작하고, 논문을 쓰고, 투고할 수 있는 학생 만들기**

> 대부분의 "논문 컨설팅"은 주제추천·설계·수정·교정까지 대신 해준다 → 학생은 *결과물*은 얻어도 *능력*은 못 얻는다.
> Researcher OS는 정반대 — **한 편의 논문이 아니라 "평생 연구할 수 있는 인간"을 만든다.**

**Before:** 논문 없음 · 연구 경험 없음 · 교수 연결 없음 · 어디서 시작할지 모름
**After:** 주제 발굴 → 논문 읽기 → Literature Review → 연구 설계 → 데이터 수집 → 논문 작성 → 저널 찾기 → 투고 → 수정 → *다음 연구*

**최종 보유물:** Research Interest Map · Research Notebook · Literature Database · Research Proposal · Draft Paper · Submission Package · Conference Presentation · Future Research Pipeline

### Phase 1 · Finding Questions
- **W1 What Is Research** — 연구의 정의 / 고등학생 연구의 현실 / 좋은 vs 나쁜 연구 · 과제: 관심 분야 20개
- **W2 How To Find Problems** — 왜 대부분 주제를 못 찾는가 / 문제 발견 훈련 · 실습: 세상 문제 50개
- **W3 Interest Mapping** — 생물·기술·교육·예술 연결
- **W4 Research Questions** — 연구 질문 100개 생성

### Phase 2 · Literature Review → 결과물: **Literature Review 문서**
- **W5** Google Scholar · **W6** PubMed · **W7** arXiv · **W8** 논문 해부(Abstract/Methods/Results/Discussion) · **W9** 논문 20편 분석 워크플로우 · **W10** Literature Matrix
