> "원서는 '제출'이 아니라 **'설계'** 다."

**이 모듈을 끝내면 손에 쥐는 것**
- ✅ Common App 활동란 10칸 — 150자 완성본

→ **제출 준비 완료 원서 패키지**

`[그림: 책상 위에 펼쳐진 원서 서류·노트북·교복 — 밤 11시 풍경]`

# 0. 입학사정관이 실제로 보는 순서

```
① Common App 지원서 대시보드  → 학교·전공·GPA·테스트
② Activities (활동란 10칸)    → 2분 스캔 — 패턴/스파이크
③ Essays (Personal Statement) → 4분 몰입
④ Supplemental Essays         → 1분/편 — 학교 핏
⑤ 추천서 2–3통               → 1–2분 — 세부 증거
⑥ Resume (선택)              → 30초 — 정보 확인
```

> 전체 8–12분. **서류들이 서로를 증거하도록** 설계해야 한다.

🎓 **Ivy Tip 1**: "에세이에서 언급한 활동이 활동란 1번에 없으면 사정관이 의심한다."(전직 Yale AO)
🎓 **Ivy Tip 2**: Princeton AO 출신 컨설턴트 Angel Pérez — "우리는 10분 안에 '이 학생이 우리 캠퍼스에서 무엇을 할지' 그림을 그린다. 서류가 흩어져 있으면 그 그림이 안 보인다."
🎓 **Ivy Tip 3**: 하버드 합격생 박지수(가명, Seoul Foreign School, Class of '24) — "제 원서의 모든 서류에 '데이터로 기후 불평등을 측정한다'는 문장이 각각 다른 형태로 반복됐다. 사정관이 어디서 읽어도 같은 학생이 보이도록."

# 0-1. 원서 전체 일관성 도해 (One Through-Line)

```
┌─────────────────────────────────────────────────┐
│              나의 Core Spike                     │
│   예) "한국계 청소년 기후 불평등 연구 + 정책"    │
└──────┬─────────────┬──────────────┬─────────────┘
       ↓             ↓              ↓
  활동란 1–3번   메인 에세이    Why Us 첫 단락
  (증거 데이터)  (스토리 장면)  (연결 근거)
       ↓             ↓              ↓
  추천서 핵심 키워드   Resume 상위 항목
```

> 사정관이 어느 서류를 펴든 **같은 학생 이미지**가 보여야 한다.

🎓 **Ivy Tip 1**: 제출 전 테스트 — 활동란 1번, 에세이 첫 문단, Why Us 첫 문장을 나란히 놓아라. 세 개가 같은 핵심 단어를 공유하면 Through-Line 성공.
🎓 **Ivy Tip 2**: 다른 스파이크를 활동란 7번 이후에만 배치하라. 1–6번은 전부 메인 스파이크의 증거 역할이어야 한다.
🎓 **Ivy Tip 3**: Columbia 합격생 이현우(Chadwick International, Class of '25) — "저는 원서 제출 전에 친구에게 제 활동란만 읽히고 '이 사람이 뭘 연구하는 것 같아?'라고 물었다. 한 번에 맞추면 성공, 못 맞추면 다시 썼다."

# 강의 99 · Common App — 활동란 전략

## 활동란이란?

- 최대 **10개** 활동 입력 (학교 내/외, 방과후, 봉사, 일 등)
- 각 항목: **Position/Role (50자) + 설명 (150자)**
- 학교명/시간/학년 별도 입력

**가장 흔한 실수 ❌**
- 무엇을 "했다"만 쓰기 → *결과·숫자·영향* 없음
- 10칸을 다 채우려고 약한 활동 끼워넣기
- 직위 그대로("멤버", "학생") → 실제 역할로

🎓 **Ivy Tip 1**: "6개 강한 활동 > 10개 밋밋한 활동." — 빈칸도 전략이다. (MIT 입학처 공식 블로그)
🎓 **Ivy Tip 2**: Position/Role 50자도 전략이다. "Club President" 대신 "Founder & Executive Director (12 members)" — 역할의 무게감이 달라진다.
🎓 **Ivy Tip 3**: 한국 국제학생 흔한 실수 — "전국 대회 1위"만 쓰고 규모 생략. 사정관은 한국 대회 규모를 모른다. 반드시 "(2,000 participants, national-level)"을 괄호로 추가.
🎓 **Ivy Tip 4**: Princeton 합격생 김민준(KIS Seoul, Class of '24) — "저는 활동란을 쓸 때 매 항목마다 '그래서 세상이 어떻게 달라졌나?'를 자문했다. 답이 없으면 다시 썼다."

# 99-1. 활동란 150자 공식

```
동사(능동) + 숫자/규모 + 행동 내용 + 결과/영향
────────────────────────────────────────────────
Designed  → 무엇을?   → 어떻게?   → 결과는?
Led       → 몇 명?    → 어디서?   → 변화는?
Published → 어디에?   → 무슨 주제? → 반응은?
```

**핵심 동사 리스트 (스파이크 유형별)**
```
[연구/분석] Analyzed / Developed / Designed / Engineered / Implemented
[리더십]   Founded / Launched / Directed / Managed / Recruited
[창작/출판] Published / Authored / Produced / Composed / Illustrated
[교육/멘토] Mentored / Tutored / Trained / Facilitated / Coached
[성과/수상] Secured / Won / Qualified / Earned / Achieved
[변화/영향] Reduced / Increased / Expanded / Transformed / Raised
```

> 수동("was selected", "participated") → 절대 피하라.

🎓 **Ivy Tip 1**: 150자는 공백 포함이다. 미리 Word count 확인 — Common App은 150자 초과 시 자동 절단.
🎓 **Ivy Tip 2**: 첫 단어가 동사인지 확인. "I founded…" → "Founded…" (I 삭제, 자리 아낌).
🎓 **Ivy Tip 3**: 숫자가 없는 불릿은 반드시 의심하라. "improved club culture" → "increased membership 12→47 in 8 months, survey satisfaction +34%"로 구체화.

# 99-4. 활동 순서 배열 전략

```
1번 = 가장 강한 스파이크 (사정관이 가장 먼저 본다)
2–3번 = 스파이크 보완/심화
4–5번 = 리더십/영향력 증거
6–7번 = 다양성 (예술, 스포츠, 개인 프로젝트)
8–9번 = 봉사/커뮤니티
10번 = 가족 책임/일 (해당 시) 또는 보조 활동
```

**국제학생 특별 주의**
- 한국 내 활동도 전부 기입 가능 — **영문으로 맥락 설명** 필수
- "전국 대회" → 참가자 수·등수 명시 (사정관이 규모 모름)
- 봉사 시간 부풀리기 ❌ — 추천서와 대조됨

🎓 **Ivy Tip 1**: 활동란 10칸을 읽고 나서 "이 학생이 5년 뒤 뭘 할지" 그려지면 성공.
🎓 **Ivy Tip 2**: 여름 프로그램(MIT, Stanford EPGY, Yale YSP 등)은 강한 스파이크 보강재다. 단, 유료 캠프보다 경쟁 선발 프로그램이 훨씬 강하게 읽힌다. 설명란에 "Selective: 8% acceptance rate"처럼 선발률 명시.
🎓 **Ivy Tip 3**: 활동란 "Hours per week / Weeks per year" 칸을 진지하게 써라. Harvard 합격생들 평균 주당 시간은 15–25시간(스파이크 1개 기준). 5시간 미만이면 깊이가 의심된다.
🎓 **Ivy Tip 4**: 1학년 활동은 4학년까지 이어졌는지가 핵심이다. 지속성 없는 "1년짜리 활동 10개"보다 "4년 이어온 활동 3개"가 훨씬 강하다. (전직 Dartmouth AO 증언)

# 🎓 실전 꿀팁 모음 — 활동란

- **"Additional Information" 칸을 활용하라**: 활동란 10칸에 못 담은 맥락(예: 코로나로 클럽이 해산된 이유, 가족 돌봄 책임)은 Common App Additional Info 650단어 칸에 설명 가능. 불이익 없음.
- **미출판 연구도 기재하라**: "Paper under review at Journal of X" — 결과가 없어도 과정 자체가 강력한 증거다.
- **Role 50자에서 '창립자' 먼저**: "Club Member → President → Founder" 순이 아니라, 창립자라면 "Founder & President" 가 첫 단어여야 한다.
- **숫자가 없는 항목은 없어야 한다**: 피아노조차 "10 years, Grade 8, 2 public performances/year" — 어떤 활동도 숫자 1개는 들어간다.
- **동일 활동이 여러 역할이면 분리 가능**: 예) 학교 오케스트라 수석 연주자 + 지역 청소년 오케스트라 단장 → 2칸 사용.
- **소셜 임팩트 숫자 만들기**: 인스타그램·유튜브·뉴스레터 팔로워/구독자, 서명 캠페인 참가자, 모금액 등 — 모두 숫자다.
- **합격생 분석**: Dartmouth Class of '27 합격생 활동란 공개 사례(College Confidential) — 상위 합격자 10명 중 8명이 창립자/편집장/주전 포지션 보유. '멤버'로만 기재된 항목은 평균 5번 이하.
- **체크리스트**: 10칸 완성 후 → 각 줄에 동사·숫자·결과가 있는지 3색 형광펜으로 표시. 색이 없는 줄은 수정.

# 강의 100 · Supplemental Essays — "Why Us" 공략법

## Supplemental이란?

- 각 학교가 Common App 외에 **별도 요구하는 에세이**
- 분량: 50–650단어 (학교마다 다름)
- 가장 중요한 유형: **"Why [School Name]?"**

**사정관이 Why Us에서 찾는 것**
```
진짜 리서치 여부 (복붙 감지 즉시 탈락)
       ↓
학교 특정 프로그램/교수/문화 언급
       ↓
"이 학생이 입학하면 우리 커뮤니티에 무엇을 더하나"
```

🎓 **Ivy Tip 1**: 학교 이름을 바꿔도 성립하는 Why Us = 쓰레기통행. **이 학교만** 가능한 문장을 1–2개 넣어라.
🎓 **Ivy Tip 2**: Yale 사정관 출신 컨설턴트 인터뷰(2023, The Princeton Review) — "We can immediately tell when a student has been to campus versus read a brochure. The ones who mention a specific building, a specific professor's office-hour moment, or a dining-hall conversation always stand out."
🎓 **Ivy Tip 3**: "Columbia has a great location in NYC" — 이런 문장은 NYU, Fordham, New School 지원자도 쓴다. 위치가 아닌 **특정 자원(교수·랩·과목·센터)**이 핵심.
🎓 **Ivy Tip 4**: Why Us를 쓰기 전에 반드시 해당 학교 학부 과정 Course Catalog(PDF)를 직접 열어서 과목 코드를 복사하라. 실제 과목 번호가 들어간 에세이는 리서치를 안 한 에세이와 즉각 구별된다.

# 100-1. Why Us 리서치 체크리스트 (학교별)

**조사해야 할 6가지**

| 카테고리 | 찾을 곳 | 메모할 것 |
|---|---|---|
| 특정 교수 연구 | 학교 faculty 페이지 | 교수명 + 논문 제목 |
| 독특한 커리큘럼 | 학교 course catalog | 다른 학교에 없는 과목명 |
| 연구소/센터 | 학교 research 페이지 | 센터명 + 내 관심사 연결 |
| 클럽/동아리 | student life 페이지 | 내가 합류할 조직 |
| 졸업생 인터뷰 | 유튜브/팟캐스트 | 문화·정신 키워드 |
| 캠퍼스 방문/버추얼 투어 | 공식 웹사이트 | 실제 장면·분위기 |

✍️ 학교별 **리서치 카드** 1장씩 작성 → Why Us 뼈대 완성.

🎓 **Ivy Tip 1**: 교수 리서치 심화법 — 교수 이름 + "Google Scholar"로 검색 → 최근 2년 논문 제목과 초록을 읽어라. 에세이에 논문 제목이나 핵심 개념을 쓰면 사정관이 "진짜 읽었구나" 체감.
🎓 **Ivy Tip 2**: 해당 학교 유튜브 채널(예: "Harvard University" 공식 채널)에서 학생 Q&A 영상을 보라. 재학생이 직접 언급하는 강점·문화가 가장 진짜다.
🎓 **Ivy Tip 3**: 재학생 블로그/서브레딧(r/ApplyingToCollege, r/Columbia 등)에서 "what I wish I knew before applying" 게시글을 찾아라. 학교 공식 자료에 없는 문화 키워드를 발굴할 수 있다.

# 100-2. Why Us 구조 공식 (250–350단어 기준)

```
[1단락] 나의 스파이크 + 이 학교를 처음 발견한 순간 (장면)
        "I first encountered Prof. Kim's work on urban heat islands
         while reading her 2023 Nature paper — the same problem
         I'd been trying to quantify in Seoul's Nowon district."

[2단락] 구체적 리소스 3가지 (교수·과목·클럽·센터)
        각각 → 내 계획과의 연결

[3단락] 내가 이 커뮤니티에 기여할 것
        "I plan to bring my bilingual climate-policy brief
         methodology to [Club Name], bridging Korean data
         that U.S. researchers rarely access."
```

> 복붙 방지: 3단락 중 **2단락 전체**는 이 학교에만 해당됨.

🎓 **Ivy Tip 1**: 1단락 오프닝에서 "I want to attend X because…"로 시작하지 마라. 장면(scene)으로 시작해야 사정관이 읽는다. "The first time I opened Prof. Tang's 2022 paper on aerosol forcing…"
🎓 **Ivy Tip 2**: 2단락에서 나열만 하지 말고 **왜 그 리소스가 나에게 필요한지** 1문장씩 연결하라. "EESC 4400's satellite data module would let me cross-validate the ground-level PM2.5 readings I collected in Seoul — a gap in my current methodology."
🎓 **Ivy Tip 3**: 기여 단락(3단락)에서는 "나는 X를 배울 것이다" 대신 "나는 X를 가져올 것이다"로 뒤집어라. 사정관은 학생이 캠퍼스를 풍요롭게 할지를 평가한다.

# 강의 101 · 추천서 — Brag Sheet 전략

## 추천서의 실제 역할

```
성적표 = 무엇을 했나 (숫자)
추천서 = 어떻게 했나 (성격·태도·과정)
```

- Common App 기준: **교사 추천서 2통 + 카운슬러 1통** (필수)
- 선택: 교수·멘토·고용주 추가 1통

**누구에게 부탁해야 하나**

| 우선순위 | 선택 기준 |
|---|---|
| ① | 내 스파이크 관련 과목 교사 (잘 안다) |
| ② | 다른 역량(리더십·창의성) 본 교사 |
| ③ | 수업 성적 좋은 교사보다 **나를 아는** 교사 |

❌ 교장·교감·유명인 (나를 모르면 의미 없음)

🎓 **Ivy Tip 1**: "추천서 교사 선택의 황금룰" — 사정관이 이 교사의 추천서를 읽고 "이 교사는 이 학생을 인간으로서 알고 있다"는 느낌이 들어야 한다. 성적이 좋아도 교사가 학생을 표면적으로만 알면 의미 없다.
🎓 **Ivy Tip 2**: Columbia 합격생 이현우(Class of '25) — "저는 영어 교사에게 부탁했는데, 이유는 수업에서 제가 쓴 에세이를 교사가 기억하고 있었기 때문이다. 10점 만점 시험보다 선생님이 기억하는 '순간'이 있는 교사를 골라라."
🎓 **Ivy Tip 3**: 11학년 2학기(한국 기준 고2 2학기)에 이미 누구에게 부탁할지 결정해두어라. 고3이 되면 교사도 다른 학생들의 추천서로 바쁘다.
🎓 **Ivy Tip 4**: 추가 추천서(Optional 3번째) — 연구 멘토·병원 지도교수·스타트업 CEO 등 학교 밖 어른이 학생을 어떤 전문적 맥락에서 봤는지 쓰면 교사 추천서와 각도가 달라져 강력하다. 단, 추가 추천서가 교사 추천서보다 약하면 오히려 마이너스.

# 101-1. Brag Sheet — 교사에게 건넬 1장

**Brag Sheet란?** 교사가 추천서를 잘 쓸 수 있도록 학생이 먼저 건네는 정보 요약지.

```
┌──────────────────────────────────────────────────┐
│  [학생 이름]의 추천서 참고 자료                   │
│  (To: [교사 이름] 선생님 / 제출 마감: MM월 DD일) │
├──────────────────────────────────────────────────┤
│ 1. 지원 학교 및 전공                              │
│ 2. 나의 스파이크 (핵심 테마 1–2문장)              │
│ 3. 이 수업에서 기억에 남는 순간/프로젝트 3개       │
│ 4. 수업 외 활동 중 교사가 모를 수 있는 것          │
│ 5. 내가 공동체에 기여한 방법                      │
│ 6. 어려움 극복 사례 (선택)                        │
│ 7. 교사가 강조해 주셨으면 하는 역량 2가지         │
└──────────────────────────────────────────────────┘
```

> "선생님, 대신 써 달라는 게 아니라 **기억을 도와드리는 자료**입니다."

🎓 **Ivy Tip 1**: Brag Sheet는 반드시 **인쇄해서 손으로 건네라**. 이메일만 보내면 교사가 바쁠 때 묻힌다. 인쇄본 + 이메일 동시 전달.
🎓 **Ivy Tip 2**: "3. 기억에 남는 순간" 항목은 학생이 먼저 특정 순간을 제안하는 것이다 — 교사가 기억을 못 할 수 있기 때문. "선생님, 10월에 제가 혼자 반론 자료를 만들어 온 수업 기억하시나요?" 같은 힌트를 준다.
🎓 **Ivy Tip 3**: "7. 강조해 주셨으면 하는 역량" — 지원 전공과 연결된 역량을 써라. 의대 지원이면 "과학적 사고와 타인에 대한 공감", CS 지원이면 "분석력과 문제 분해 능력". 교사는 이 키워드를 무의식적으로 에세이에 반영한다.

# 101-3. 추천서 요청 타이밍 + 매너

```
고3 6월 이전 ── 교사에게 구두로 먼저 물어보기
       ↓
교사 동의 → Brag Sheet + 마감일 명시한 이메일
       ↓
8월 말 ── Common App에 교사 이메일 입력 (초대 발송)
       ↓
마감 3주 전 ── 정중한 리마인더 1회
       ↓
제출 후 ── 감사 손편지 (이메일 아닌 손편지)
```

**국제학생 주의사항**
- 한국 학교 교사는 Common App 시스템 처음 접하는 경우 多
- 이메일 초대장 받는 법·작성 플랫폼(Common App Recommender Portal) 안내 첨부
- 영어 추천서 작성 부담 → 한국어로 쓰고 전문 번역 제안 가능 (일부 학교 허용, 반드시 확인)

🎓 **Ivy Tip 1**: 사정관이 가장 좋아하는 추천서 = "이 학생이 내 수업에서 한 일로, 다른 학생이라면 못 했을 구체적 장면"이 담긴 것.
🎓 **Ivy Tip 2**: Common App 교사 초대 이메일을 보낼 때, 교사가 시스템을 처음 쓴다면 짧은 "사용법 안내 PDF" 1장을 첨부하라. 불편을 최소화해야 교사가 더 잘 써준다.
🎓 **Ivy Tip 3**: 리마인더는 1회만. "선생님, 마감이 3주 남았습니다. 혹시 추가로 필요한 정보가 있으시면 말씀해 주세요." — 감사 + 정보 제공 + 부담 없음의 3박자.
🎓 **Ivy Tip 4**: 손편지는 합격·불합격과 무관하게 쓴다. 결과가 나온 뒤 교사에게 "덕분에 좋은 원서를 낼 수 있었습니다"는 손편지는 교사에게 영구적으로 기억된다 — 이후 동문 인터뷰 연결 등에도 도움.

# 101-4. 추천서 루브릭 — 사정관 기준

| 항목 | 약한 추천서 | 강한 추천서 |
|---|---|---|
| 구체성 | "성실하고 열심히 합니다" | "10월 중간고사 후 오답 분석지를 스스로 만들어 제게 보여줬습니다" |
| 구별력 | "이 학생을 추천합니다" | "25년 교직 중 상위 5명 안에 드는 학생" |
| 스파이크 연결 | 성적 위주 | 지적 성격·문제 접근 방식 |
| 길이 | 반 페이지 미만 | 1–1.5페이지 (구체 에피소드 포함) |

🎓 **Ivy Tip 1**: 추천서는 학생이 읽을 수 없다 (FERPA waiver 서명 시). 하지만 Brag Sheet를 통해 교사가 쓸 소재를 미리 제공하면 결과적으로 학생이 에세이 방향을 간접 설계하는 것이다.
🎓 **Ivy Tip 2**: 강한 추천서의 공통점(전직 Princeton AO 인터뷰, 2023) — "The best letters I read weren't about grades. They were about a student's intellectual posture — how they reacted when they were wrong, how they engaged when the answer wasn't clear."
🎓 **Ivy Tip 3**: 카운슬러 추천서는 학교 전체 맥락을 제공한다. 카운슬러가 너무 바쁘면 학교 프로필 자료(School Profile)를 함께 제출해야 사정관이 맥락을 이해한다.

# 🎓 실전 꿀팁 모음 — 추천서

- **교사를 압박하지 말고 돕는다**: "이런 에피소드를 써달라"고 직접 요청하지 말고, Brag Sheet에 에피소드를 나열해서 교사가 선택하도록 한다.
- **추천서 교사 2명의 각도를 다르게**: 1번 교사(이과 선생님) = 분석력·연구 접근, 2번 교사(문과 선생님) = 소통 능력·공동체 기여. 두 교사가 같은 역량을 쓰면 중복이다.
- **추가 추천서 적절히 활용**: 병원 지도교수, 연구 멘토, NGO 디렉터 등 — 단, Common App에서 3통째 추천서를 받으려면 사정관에게 별도 이메일로 "additional recommender" 추가를 안내받아야 하는 경우 있음.
- **Harvard 합격생 박지수(Seoul Foreign School, Class of '24)의 교사 선택 기준**: "수업 성적이 최고인 선생님이 아니라, 제가 수업 중 틀린 답을 냈을 때 어떻게 반응했는지 기억하는 선생님을 골랐다. 실패 장면을 아는 교사가 성장을 써줄 수 있다."
- **마감 캘린더 공유**: 교사 이메일로 Google Calendar 이벤트(마감일)를 공유하는 것도 실용적인 방법.
- **번역 지원 확인**: MIT, Caltech은 영어 추천서만 수락. Harvard, Yale, Princeton은 영어 이외 언어 추천서 + 공증 번역 허용 사례 있음 — 반드시 지원 학교 공식 FAQ 확인.
- **"Waiver" 반드시 서명**: 추천서 열람권 포기(Waiver) 서명을 해야 교사가 솔직하게 쓰고, 사정관도 신뢰한다. 서명 안 하면 추천서 신뢰도 하락.

# 강의 102 · Resume — 1페이지 설계법

## 대학 지원 Resume vs 활동란의 차이

```
활동란 (Common App)  ←→  Resume
────────────────────────────────
10칸 제한            제한 없음 (단, 1페이지)
150자 설명           3–5줄 불릿
점수·학년 별도        날짜·기간 모두 포함
학교 폼 양식          자유 디자인 (과하면 ❌)
```

**Resume는 필수인가?**
- 대부분 Ivy: 필수 아님 → **강력히 권고 (Optional이면 제출)**
- MIT, Caltech: 제출 안 함 (별도 활동란 방식)
- 제출 시: "Optional"이어도 제출하는 게 유리 (정보 추가)

🎓 **Ivy Tip 1**: Resume를 제출하는 목적은 "활동란에 못 담은 정보를 추가하는 것"이다. 활동란과 100% 동일한 내용의 Resume는 의미 없다.
🎓 **Ivy Tip 2**: Common App의 "Additional Information" 칸과 Resume를 혼동하지 마라. Additional Info = 텍스트, Resume = 파일 첨부(PDF). 둘 다 제출 가능하며 서로 다른 정보를 담는다.
🎓 **Ivy Tip 3**: Resume 파일명도 전략이다. "Resume_2026_KimJisoo.pdf" — 이름과 연도 포함. 사정관 컴퓨터에 파일이 여러 개일 때 구별된다.

# 102-3. Resume 흔한 실수 ❌ + 디자인 규칙

**내용 실수**
- 불릿 문장 → 동사로 시작 안 함 ❌
- 숫자·결과 없는 불릿 ("Participated in…") ❌
- 2페이지 Resume → 1페이지 강제 압축 ❌ 아니면 삭제
- 날짜 형식 불일치 (Jun 2024 vs 2024.06 혼용) ❌

**디자인 실수**
- 화려한 컬러·그래픽 → 산만, ATS 파싱 오류 ❌
- 폰트 2종 이상 → ❌ (본문 1종, 헤더 Bold만)
- 여백 0 → 읽기 힘듦 ❌

**추천 도구**
- Overleaf LaTeX 템플릿 (Jake's Resume)
- Google Docs — APA Resume 템플릿
- Canva → 너무 화려하면 ❌, 심플 버전만

🎓 **Ivy Tip 1**: 사정관이 Resume를 30초에 스캔한다. **첫 5줄**이 인상을 결정한다.
🎓 **Ivy Tip 2**: PDF로 저장 전 반드시 Mac·Windows 두 곳에서 열어봐라. 폰트가 깨지거나 레이아웃이 틀어지는 경우가 있다.
🎓 **Ivy Tip 3**: Resume를 제출하기 전 "Grammarly + 동사 시작 여부 수동 체크"를 동시에 실행하라. 자동화 도구는 동사 시작 여부를 못 잡는다.
🎓 **Ivy Tip 4**: Harvard 합격생 분석(College Kickstart, 2024) — 상위 합격자 Resume의 공통점: 불릿당 평균 1.8개의 수치, 섹션별 최대 4개 불릿, 흑백 디자인 90% 이상.

- **최종 제출 전 체크리스트**: ① 1페이지 확인 ② 동사 시작 확인 ③ 숫자 최소 1개/불릿 확인 ④ 날짜 형식 통일 ⑤ 오탈자 3회 이상 확인 ⑥ PDF로 저장 후 2개 기기에서 열기.

# 통합 — 원서 패키지 자기 점검 루브릭

| 항목 | 미달 | 통과 |
|---|---|---|
| 활동란 | 수동형 동사, 숫자 없음 | 능동 동사 + 숫자 + 결과 전 칸 |
| 활동 순서 | 무작위 | 스파이크 1–3번, 흐름 있음 |
| Why Us | 학교명만 바꾼 복붙 | 교수+과목+클럽 이 학교만 가능 |
| Brag Sheet | 없음 | 교사에게 전달 완료 |
| Resume | 2페이지 또는 동사 없음 | 1페이지, 능동+숫자, 스파이크 상단 |
| 일관성 | 서류들이 따로 놈 | 어느 서류도 같은 Through-Line |

→ **6개 모두 "통과"면 제출 준비 완료.**

🎓 **Ivy Tip 1**: 루브릭 6개 항목을 친구에게 내 서류를 보여주며 직접 평가받아라. 스스로 체크하면 오류를 못 잡는다.
🎓 **Ivy Tip 2**: 마지막 점검 — "이 원서를 본 사정관이 10초 뒤 동료에게 뭐라고 소개할까?" 그 한 문장이 떠오르면 제출하라. 안 떠오르면 Through-Line 보완이 필요하다.

# 🎓 원서 패키지 최종 꿀팁 모음

- **"72시간 냉각" 룰**: 마지막 드래프트를 완성한 뒤 최소 3일 뒤에 다시 읽어라. 직전에는 오류가 안 보인다.
- **소리 내어 읽기**: Why Us와 Personal Statement를 소리 내어 읽으면 어색한 문장이 즉각 드러난다.
- **사정관 입장 롤플레이**: 내 원서를 처음 보는 사람이 활동란 1~3번만 읽고 내 스파이크를 맞출 수 있어야 한다.
- **ED/EA 전략**: Early Decision(구속력 있는 조기 지원)은 합격률이 Regular Decision 대비 10~15%p 높다. 단, ED는 재정 패키지를 비교할 수 없으므로 장학금 필요 여부 먼저 결정.
- **국제학생 추가 서류**: CSS Profile(재정 지원 신청), 은행 잔고 증명서 등은 별도 마감이 있다. Common App 마감과 혼동 말 것.
- **Yale 합격생 이서연(NLCS Jeju, Class of '25) 최종 조언**: "원서 제출 버튼을 누르는 순간, 내가 컨트롤할 수 없는 영역이 된다. 제출 전까지 내가 할 수 있는 것에만 집중해라."
- **에세이 글쓰기 속도 팁**: 첫 드래프트는 무조건 빠르게 써라 (편집하지 말고). 나중에 다듬는다. 완벽주의로 첫 줄을 못 쓰는 것이 가장 흔한 실패 패턴.
- **마감 5일 전 체크리스트 실행**: 활동란 → Why Us → Brag Sheet 교사 제출 확인 → Resume PDF → Common App 제출 확인 버튼 순서로 최종 점검.
