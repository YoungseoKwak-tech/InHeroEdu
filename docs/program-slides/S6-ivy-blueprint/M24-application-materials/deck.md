# 강의 99 · Common App — 활동란 전략

## 활동란이란?

- 최대 **10개** 활동 입력 (학교 내/외, 방과후, 봉사, 일 등)
- 각 항목: **Position/Role (50자) + 설명 (150자)**
- 학교명/시간/학년 별도 입력

**가장 흔한 실수 ❌**
- 무엇을 "했다"만 쓰기 → *결과·숫자·영향* 없음
- 10칸을 다 채우려고 약한 활동 끼워넣기
- 직위 그대로("멤버", "학생") → 실제 역할로

🎓 **Ivy Tip**: "6개 강한 활동 > 10개 밋밋한 활동." — 빈칸도 전략이다.

---

# 99-1. 활동란 150자 공식

```
동사(능동) + 숫자/규모 + 행동 내용 + 결과/영향
────────────────────────────────────────────────
Designed  → 무엇을?   → 어떻게?   → 결과는?
Led       → 몇 명?    → 어디서?   → 변화는?
Published → 어디에?   → 무슨 주제? → 반응은?
```

**핵심 동사 리스트**
```
Founded / Launched / Designed / Analyzed / Published
Mentored / Secured / Reduced / Increased / Presented
Collaborated / Implemented / Advocated / Engineered
```

> 수동("was selected", "participated") → 절대 피하라.

# 99-4. 활동 순서 배열 전략

```
1번 = 가장 강한 스파이크 (사정관이 가장 먼저 본다)
2–3번 = 스파이크 보완/심화
4–5번 = 리더십/영향력 증거
6–7번 = 다양성 (예술, 스포츠, 개인 프로젝트)
8–9번 = 봉사/커뮤니티
10번 = 가족 책임/일 (해당 시) 또는 보조 활동
```

**국제학생 특별 주의**
- 한국 내 활동도 전부 기입 가능 — **영문으로 맥락 설명** 필수
- "전국 대회" → 참가자 수·등수 명시 (사정관이 규모 모름)
- 봉사 시간 부풀리기 ❌ — 추천서와 대조됨

🎓 **Ivy Tip**: 활동란 10칸을 읽고 나서 "이 학생이 5년 뒤 뭘 할지" 그려지면 성공.

# 99-5. Common App 에세이 (Personal Statement) — 빠른 가이드

**7개 프롬프트 중 가장 많이 선택되는 것**

| 프롬프트 | 핵심 | 적합 스파이크 |
|---|---|---|
| #1 배경/정체성 | 나는 누구인가 | 문화적 정체성, 이민 배경 |
| #2 역경 극복 | 어떻게 성장했나 | 실패→재건 서사 |
| #5 성취/이벤트 | 지적 성취 | 연구·경쟁·창작 |
| #7 자유 | 무엇이든 | 독특한 소재 |

**650단어 구조 공식**
```
1단락(훅·장면) → 2–3단락(사건·생각·전환) → 마지막(지금의 나 + 대학 연결)
```

❌ "I have always been passionate about..." → 절대 금지 첫 문장.

# 강의 100 · Supplemental Essays — "Why Us" 공략법

## Supplemental이란?

- 각 학교가 Common App 외에 **별도 요구하는 에세이**
- 분량: 50–650단어 (학교마다 다름)
- 가장 중요한 유형: **"Why [School Name]?"**

**사정관이 Why Us에서 찾는 것**
```
진짜 리서치 여부 (복붙 감지 즉시 탈락)
       ↓
학교 특정 프로그램/교수/문화 언급
       ↓
"이 학생이 입학하면 우리 커뮤니티에 무엇을 더하나"
```

🎓 **Ivy Tip**: 학교 이름을 바꿔도 성립하는 Why Us = 쓰레기통행. **이 학교만** 가능한 문장을 1–2개 넣어라.

---

# 100-1. Why Us 리서치 체크리스트 (학교별)

**조사해야 할 6가지**

| 카테고리 | 찾을 곳 | 메모할 것 |
|---|---|---|
| 특정 교수 연구 | 학교 faculty 페이지 | 교수명 + 논문 제목 |
| 독특한 커리큘럼 | 학교 course catalog | 다른 학교에 없는 과목명 |
| 연구소/센터 | 학교 research 페이지 | 센터명 + 내 관심사 연결 |
| 클럽/동아리 | student life 페이지 | 내가 합류할 조직 |
| 졸업생 인터뷰 | 유튜브/팟캐스트 | 문화·정신 키워드 |
| 캠퍼스 방문/버추얼 투어 | 공식 웹사이트 | 실제 장면·분위기 |

✍️ 학교별 **리서치 카드** 1장씩 작성 → Why Us 뼈대 완성.

---

# 100-2. Why Us 구조 공식 (250–350단어 기준)

```
[1단락] 나의 스파이크 + 이 학교를 처음 발견한 순간 (장면)
        "I first encountered Prof. Kim's work on urban heat islands
         while reading her 2023 Nature paper — the same problem
         I'd been trying to quantify in Seoul's Nowon district."

[2단락] 구체적 리소스 3가지 (교수·과목·클럽·센터)
        각각 → 내 계획과의 연결

[3단락] 내가 이 커뮤니티에 기여할 것
        "I plan to bring my bilingual climate-policy brief
         methodology to [Club Name], bridging Korean data
         that U.S. researchers rarely access."
```

> 복붙 방지: 3단락 중 **2단락 전체**는 이 학교에만 해당됨.

---

# 100-3. 📝 채워진 예시 — Columbia Why Us (275단어)

> *"When I found Prof. Yuki Tanaka's Lamont-Doherty lab studying aerosol-cloud interactions over East Asia, I realized Columbia held data I'd been searching for since collecting PM2.5 readings on my school rooftop in Seoul.*
>
> *I plan to join the Columbia Climate School's interdisciplinary track, pairing Earth Science methods from EESC 4400 with policy frameworks from SIPA's Environmental Policy workshop — a combination I haven't found at any other institution. Beyond coursework, the Columbia Energy Club's Carbon Pricing Working Group directly mirrors the policy briefs I've published with my research club in Korea, and I hope to expand our East Asia carbon-pricing dataset with the club's quantitative tools.*
>
> *I also intend to contribute: Korean-language climate communication is almost absent from major U.S. university outreach. Having already translated two IPCC summary sections for a Korean science blog with 15,000 monthly readers, I'd bring this bilingual bridge to Columbia's Science Communication initiative, helping East Asian international students engage with climate research in their first language."*

**무엇이 좋은가**
- ① 교수명·논문·랩 이름 → 진짜 리서치
- ② 과목 코드 → 카탈로그 파봤다는 증거
- ③ 기여 → 구체적, 학교 특정적

# 100-4. 흔한 실수 ❌ + FAQ

**흔한 실수**
- "Columbia has a great reputation and diverse campus." → ❌ 모든 학교에 해당
- 교수 이름만 나열, 연결 없음 → ❌ 왜 그 교수인지 설명 없으면 의미 없음
- 학교를 칭찬만 → ❌ 내가 무엇을 *줄* 것인지 없음
- 분량 과초과 (250단어 제한에 350단어) → ❌ 자동 감점

**FAQ**
| 질문 | 답 |
|---|---|
| 교수 이메일 연락 먼저 해야 하나? | 석사·박사는 필수, 학부는 플러스 (강제 아님) |
| 캠퍼스 방문 못 했으면? | 버추얼 투어 + 재학생 Q&A 인용 가능 |
| 여러 학교에 비슷하게 써도 되나? | 학교명·교수·클럽은 반드시 교체. 구조만 재사용 |

# 강의 101 · 추천서 — Brag Sheet 전략

## 추천서의 실제 역할

```
성적표 = 무엇을 했나 (숫자)
추천서 = 어떻게 했나 (성격·태도·과정)
```

- Common App 기준: **교사 추천서 2통 + 카운슬러 1통** (필수)
- 선택: 교수·멘토·고용주 추가 1통

**누구에게 부탁해야 하나**

| 우선순위 | 선택 기준 |
|---|---|
| ① | 내 스파이크 관련 과목 교사 (잘 안다) |
| ② | 다른 역량(리더십·창의성) 본 교사 |
| ③ | 수업 성적 좋은 교사보다 **나를 아는** 교사 |

❌ 교장·교감·유명인 (나를 모르면 의미 없음)

---

# 101-1. Brag Sheet — 교사에게 건넬 1장

**Brag Sheet란?** 교사가 추천서를 잘 쓸 수 있도록 학생이 먼저 건네는 정보 요약지.

```
┌──────────────────────────────────────────────────┐
│  [학생 이름]의 추천서 참고 자료                   │
│  (To: [교사 이름] 선생님 / 제출 마감: MM월 DD일) │
├──────────────────────────────────────────────────┤
│ 1. 지원 학교 및 전공                              │
│ 2. 나의 스파이크 (핵심 테마 1–2문장)              │
│ 3. 이 수업에서 기억에 남는 순간/프로젝트 3개       │
│ 4. 수업 외 활동 중 교사가 모를 수 있는 것          │
│ 5. 내가 공동체에 기여한 방법                      │
│ 6. 어려움 극복 사례 (선택)                        │
│ 7. 교사가 강조해 주셨으면 하는 역량 2가지         │
└──────────────────────────────────────────────────┘
```

> "선생님, 대신 써 달라는 게 아니라 **기억을 도와드리는 자료**입니다."

# 101-3. 추천서 요청 타이밍 + 매너

```
고3 6월 이전 ── 교사에게 구두로 먼저 물어보기
       ↓
교사 동의 → Brag Sheet + 마감일 명시한 이메일

마감 3주 전 ── 정중한 리마인더 1회
       ↓
제출 후 ── 감사 손편지 (이메일 아닌 손편지)
```

**국제학생 주의사항**
- 한국 학교 교사는 Common App 시스템 처음 접하는 경우 多
- 이메일 초대장 받는 법·작성 플랫폼(Common App Recommender Portal) 안내 첨부
- 영어 추천서 작성 부담 → 한국어로 쓰고 전문 번역 제안 가능 (일부 학교 허용, 반드시 확인)

🎓 **Ivy Tip**: 사정관이 가장 좋아하는 추천서 = "이 학생이 내 수업에서 한 일로, 다른 학생이라면 못 했을 구체적 장면"이 담긴 것.

# 101-4. 추천서 루브릭 — 사정관 기준

| 항목 | 약한 추천서 | 강한 추천서 |
|---|---|---|
| 구체성 | "성실하고 열심히 합니다" | "10월 중간고사 후 오답 분석지를 스스로 만들어 제게 보여줬습니다" |
| 구별력 | "이 학생을 추천합니다" | "25년 교직 중 상위 5명 안에 드는 학생" |
| 스파이크 연결 | 성적 위주 | 지적 성격·문제 접근 방식 |
| 길이 | 반 페이지 미만 | 1–1.5페이지 (구체 에피소드 포함) |

**흔한 실수 ❌**
- 교사가 학생 대신 직접 Brag Sheet 내용을 그대로 복붙 → ❌ 사정관이 감지
- 학생이 추천서 초안 써줌 → ❌ 절대 금지 (윤리 위반)
- 마감 직전 요청 → ❌ 교사도 인간, 품질 떨어짐

# 102-3. Resume 흔한 실수 ❌ + 디자인 규칙

**내용 실수**
- 불릿 문장 → 동사로 시작 안 함 ❌
- 숫자·결과 없는 불릿 ("Participated in…") ❌
- 2페이지 Resume → 1페이지 강제 압축 ❌ 아니면 삭제
- 날짜 형식 불일치 (Jun 2024 vs 2024.06 혼용) ❌

**디자인 실수**
- 화려한 컬러·그래픽 → 산만, ATS 파싱 오류 ❌
- 폰트 2종 이상 → ❌ (본문 1종, 헤더 Bold만)
- 여백 0 → 읽기 힘듦 ❌

**추천 도구**
- Overleaf LaTeX 템플릿 (Jake's Resume)
- Google Docs — APA Resume 템플릿
- Canva → 너무 화려하면 ❌, 심플 버전만

🎓 **Ivy Tip**: 사정관이 Resume를 30초에 스캔한다. **첫 5줄**이 인상을 결정한다.

# 통합 — 원서 패키지 자기 점검 루브릭

| 항목 | 미달 | 통과 |
|---|---|---|
| 활동란 | 수동형 동사, 숫자 없음 | 능동 동사 + 숫자 + 결과 전 칸 |
| 활동 순서 | 무작위 | 스파이크 1–3번, 흐름 있음 |
| Why Us | 학교명만 바꾼 복붙 | 교수+과목+클럽 이 학교만 가능 |
| Brag Sheet | 없음 | 교사에게 전달 완료 |
| Resume | 2페이지 또는 동사 없음 | 1페이지, 능동+숫자, 스파이크 상단 |
| 일관성 | 서류들이 따로 놈 | 어느 서류도 같은 Through-Line |

→ **6개 모두 "통과"면 제출 준비 완료.**

# 통합 — 흔한 실수 & FAQ 총정리

**❌ 결정적 실수**
- 에세이와 활동란이 *다른 학생처럼* 보임 → Through-Line 없음
- Supplemental을 마감 전날 씀 → 리서치 없이 쓴 티 남
- 추천서 부탁을 10월에 → 교사에게 무례, 품질 하락
- Resume를 제출 안 함 (Optional이라서) → 정보 손실

**FAQ**
| 질문 | 답 |
|---|---|
| 활동이 5개뿐이면? | 6–10칸 공란 가능 — 없는 활동 억지로 만들지 말 것 |
| 추천서 영어 수준이 걱정 | 교사에게 번역 지원 제안 가능, 내용이 훨씬 중요 |
| Why Us 250단어 — 너무 짧지 않나? | 짧아도 **학교 특정성** 높으면 우위. 낭비 단어 채우기 ❌ |
| Resume 제출 타이밍 | Additional Info 칸에 PDF 첨부하거나 포털 업로드 |
