# 강의 92 · 학교 리스트 — 왜 대부분이 틀리는가

**두 가지 흔한 오류**
```
오류 A: 명성 집착
  Harvard, Yale, Princeton, Columbia, Penn… (전부 Reach, 전략 없음)

오류 B: 안전 과다
  Safety만 5개 → 도전 안 하고 후회
```

**올바른 프레임**
```
총 12–16개 학교
  ├─ Reach  : 4–6개 (합격 확률 <20%)
  ├─ Match  : 4–6개 (합격 확률 30–60%)
  └─ Safety : 3–4개 (합격 확률 >70%, 진학 의향 있음)
```

🎓 **Ivy Tip**: Safety는 "갈 의향 없는 보험"이 아니라 **"합격하면 기쁜 학교"**로 골라라. 그게 에세이 퀄리티를 지킨다.

|---|---|---|---|

| MIT | ~4.7% | ~3% 내외 | ~10% |
| Princeton | ~4.6% | ~2–3% | ~11% |
| Yale | ~4.6% | ~3% 내외 | ~11% |
| Columbia | ~3.9% | ~3% 내외 | ~13% |
| Cornell | ~8.1% | ~5–6% | ~10% |
| UPenn | ~6.5% | ~4–5% | ~12% |
| UCLA (공립) | ~9% | ~14% (OOS 기준) | ~5% |

# 강의 92 · Reach / Match / Safety 분류 기준

**나를 기준으로 분류해야 한다 (순위 기준 X)**

| 구분 | 기준 | 판단 팁 |
|---|---|---|
| Reach | 내 GPA/SAT가 25th 백분위 미만, 또는 합격률 <15% | Ivies + 탑 문리대 대부분 |
| Match | 내 GPA/SAT가 25th–75th 백분위 중간 | 상위 30위권 사립 다수 |
| Safety | 내 GPA/SAT가 75th 백분위 이상, 합격률 >50% | 주립 Honor College 등 |

```
✅ 체크: 학교 CDS → C9(SAT 25th/75th) → 내 점수 위치 확인
✅ 체크: 국제학생 재정지원 여부 (Need-Blind vs Need-Aware)
✅ 체크: PrepScholar / College Transitions CDS 무료 검색 활용
```

🎓 **Ivy Tip**: Reach 6개를 다 넣어도 전략은 "에세이 차별화"에 달렸다. 점수가 비슷한 지원자들끼리 에세이로 갈린다.

# 강의 92 · 🎓 실전 꿀팁 모음

- **CDS C9 직접 읽기**: Google에 "Harvard Common Data Set 2024–25 PDF" 검색 → Section C 확인. 25th/75th SAT·GPA 공식 수치가 여기 있다. 학원 자료보다 정확하다.
- **Naviance vs 실제**: 재학 중인 학교가 Naviance(scattergram 툴)를 쓴다면 반드시 활용. 단, 학교별 샘플이 적으면 outlier에 속지 말 것.
- **공립대 함정**: UC Berkeley(국제 합격률 ~11%), UCLA(~14%) — SAT 1580도 Reach다. UC는 에세이 PIQ 8개 중 4개를 별도 준비해야 한다.
- **Safety 선정 공식**: 내 SAT가 그 학교 75th 백분위보다 +30점 이상, GPA가 75th 이상, 국제학생도 재정 지원 가능 → 이 3개 동시 만족 시 Safety 확정.
- **WL 보험**: Reach 4개 중 1개는 WL 전환율이 상대적으로 높은 학교(Cornell, Georgetown 등)로 고른다. Ivies의 WL → 합격 전환은 연도에 따라 0–2% 수준.
- **영국·캐나다 병행**: UCL, University of Toronto 등을 Safety 위치로 추가하면 심리적 안전망이 생긴다. 단, UCAS 마감(1/15)과 Common App 마감이 겹치므로 에세이 분리 작업 일정을 9월에 잡아라.
- **학교 홈페이지 "Class Profile" 페이지**: 합격자 중위 SAT, 국적 분포, 공립/사립 고교 비율이 나온다. 매년 10–11월 업데이트 확인.

# 강의 92 · 국제학생 재정 지원 분류

**반드시 확인해야 할 두 가지**

```
Need-Blind (국제학생 포함)        Need-Aware (국제학생)
─────────────────────────        ──────────────────────────
Harvard, Yale, Princeton,        Cornell, Dartmouth, UPenn,
MIT, Amherst, Bowdoin            Brown, Columbia, Georgetown,
                                 + 대부분 사립·공립
```

> Need-Blind ≠ 100% 충족 보장. 단, 재정 필요가 합격에 불이익을 주지 않음.

**❌ 흔한 실수**: Need-Aware 학교에 100% 재정 지원을 신청하면서 **"재정 불필요"로 표기** — 이후 CSS Profile 제출 안 해 자동 탈락.

**CSS Profile 제출 마감**: 학교별로 다르다. ED/EA 지원 시 보통 11/1–11/15, RD는 2/1–3/1. **입학 마감과 재정 마감은 다르다** — 반드시 각 학교 Financial Aid 페이지에서 별도 확인.

✍️ 실습: 내 리스트 각 학교의 Need-Blind/Aware 여부 + CSS Profile 마감일을 표에 채워라.

# 강의 92 · 재정 지원 실전 — CSS Profile & Net Price Calculator

**CSS Profile이란?**
- College Board가 운영하는 재정 지원 양식 (FAFSA보다 훨씬 상세)
- 부모 소득·자산, 형제자매 학비, 부동산 등 전부 기재
- 제출 비용: 학교당 $25 (첫 학교 $16), 미국 외 거주 시 온라인 신청

**Net Price Calculator 필수 활용**
```
각 학교 홈페이지 → "Net Price Calculator" 검색
→ 가족 소득·자산 입력 → 예상 Financial Aid 패키지 확인
→ 실제 연간 비용 = 학비($60–70k) - 예상 장학금
```

**현실 수치 예시 (Harvard, 2025 기준)**
- 가족 소득 $65,000 이하 → 학비 $0 (전액 지원)
- 가족 소득 $65–150k → 소득의 0–10% 자부담
- 가족 소득 $150–200k → 소득의 ~10% 자부담

> Harvard·Princeton·Yale은 국제학생도 동일 기준 적용. Need-Blind 실질적 혜택이 크다.

# 강의 92 · 흔한 실수 & FAQ

**❌ 흔한 실수**
- Safety를 "설마 안 가겠지"로 넣는다 → 에세이를 대충 씀 → WL/불합격
- 같은 학교를 Reach에 2개 넣음 (예: Harvard REA + Princeton REA — 규정상 불가)
- 공립 주립대를 Safety로 착각 — UC Berkeley, UCLA는 한국 국제학생에게 Reach에 가깝다
- CSS Profile 마감을 입학 마감과 같다고 착각 → 늦게 제출 → 재정 패키지 축소

**Q. 리스트가 12개 미만이어도 되나요?**
A. 안전마진이 줄어든다. 특히 RD 시즌에 전부 불합격하면 Gap Year 또는 재지원 외에 선택지가 없다. 최소 10개를 권장.

**Q. 영국·캐나다 학교를 같이 지원해도 되나요?**
A. 된다. 단, 데드라인·추천서 형식·에세이 체계가 전혀 다름. 별도 플래닝 필요. UCAS는 Personal Statement 1개로 6개 학교에 동시 지원하는 구조.

# 강의 93 · 지원 전략 — ED / EA / RD 기본 개념

```
Early Decision (ED)              Early Action (EA)
──────────────────               ──────────────────
· 합격 시 반드시 진학           · 합격해도 진학 의무 없음
· 1개 학교만 ED 지원 가능      · 복수 지원 가능 (학교별 규정)
· 재정 패키지 비교 불가        · 재정 비교 후 결정 가능
· 데드라인: 보통 11/1 (ED I)   · 데드라인: 보통 11/1
            1/1–1/15 (ED II)

Regular Decision (RD)
──────────────────────
· 데드라인 1/1 또는 1/15
· 재정 패키지 비교 가능
· 합격률이 ED/EA보다 낮은 경향
```

🎓 **Ivy Tip**: 국제학생에게 ED는 **재정 비교 포기**를 의미한다. 학교가 100% Need-Met(재정 전액 충족)를 보장한다는 확신이 없으면 Need-Blind 학교(Harvard·Yale·Princeton·MIT)에만 ED/REA를 쓰는 것이 원칙.

# 강의 93 · ED 전략 — 언제 써야 하는가

**ED가 유리한 조건 (모두 만족해야 함)**

| 조건 | 체크 |
|---|---|
| 이 학교가 진심으로 1순위 | ☐ |
| 재정 지원이 필요 없거나 Need-Blind 학교 | ☐ |
| 현재 프로필이 그 학교 Match~Low Reach | ☐ |
| 에세이·추천서 11/1 전에 완성 가능 | ☐ |
| Why Us 에세이가 학교 특정 내용으로 가득 찬 상태 | ☐ |

**ED 합격률 부스트 — 공개 수치 (2024–25 기준)**
```
Columbia   RD: ~3.9%   vs  ED: ~10.8%    → 약 2.8배
UPenn      RD: ~5.1%   vs  ED: ~14.3%    → 약 2.8배
Dartmouth  RD: ~6.2%   vs  ED: ~21.3%    → 약 3.4배
Cornell    RD: ~7.0%   vs  ED: ~24.1%    → 약 3.4배
```

> ED 부스트는 실재하지만, **프로필이 안 되면 부스트도 없다.** 에세이 완성도가 낮은 상태로 ED를 쓰면 RD 기회를 날린다.

# 강의 93 · ED II — 놓치기 쉬운 두 번째 기회

**ED II란?**
- ED I(11/1) 불합격·Defer 후 다른 학교에 ED 재도전
- 마감: 보통 **1/1–1/15** (RD 마감과 비슷)
- ED II를 제공하는 주요 학교: Tulane, Emory, Vanderbilt, Colby, Middlebury, NYU, WashU

**ED II 전략적 활용**
```
11월: ED I 제출 (1순위 학교)
12/15: ED I 결과 → 불합격 or Defer
1/1: ED II 제출 (2순위 학교) + RD 나머지 동시 제출
```

🎓 **Ivy Tip**: Vanderbilt ED II 합격률은 RD 대비 약 2배. Emory ED II도 유사. ED I에서 Defer 받았다면 ED II 카드를 쓰는 게 유리할 수 있다.

# 강의 93 · EA & REA (Restrictive EA) 주의점

**Restrictive Early Action (REA / SCEA)**

> Harvard, Yale, Princeton, Stanford는 EA지만 **REA/SCEA** — 다른 사립 Early에 동시 지원 불가.

```
REA 허용 지원:                   REA 금지 지원:
· 공립대 EA (Michigan, UNC 등)  · 다른 사립 ED (Cornell ED 등)
· 외국 학교 조기 전형            · 다른 사립 EA (MIT EA 등)
· 장학금 프로그램                · 사립 REA 동시 (HYP 중복)
```

**❌ 흔한 실수**: Harvard REA + Cornell ED 동시 지원 → 둘 다 무효 처리 가능. MIT EA + Harvard REA 동시 → Harvard REA 규정 위반.

> **MIT는 REA가 아닌 일반 EA** — MIT EA + 공립대 EA는 문제없다. 단 MIT EA + Harvard REA는 Harvard 규정 위반.

🎓 **Ivy Tip**: REA를 쓰기로 했다면, 그 에너지를 **한 학교의 Why Us 에세이에만 집중**하라. 분산이 최악의 전략이다.

# 강의 93 · Defer 대응 전략

**Defer(연기)란?**
EA/REA 지원자가 바로 합격/불합격 결정을 받지 않고 RD 풀로 넘어가는 것.

**Defer 받았을 때 할 일**
```
1. LOCI (Letter of Continued Interest) 제출
   - 분량: 1페이지 이내
   - 내용: "아직도 이 학교가 1순위" + 11월 이후 새 성과 1–2개
   - 제출 시기: Defer 통보 후 2주 이내 (1/1 전후)

2. 추가 자료 제출 가능 여부 확인
   - 2학기 성적, 새 수상, 연구 발표 등
   - 학교마다 포털 통해 업로드 허용 여부 다름

3. 인터뷰 재요청 (학교에서 먼저 요청하지 않았다면 Alumni Interview 신청)
```

🎓 **Ivy Tip**: Harvard REA Defer → RD 전환 후 최종 합격률은 약 5–8% 수준으로 알려진다 (공식 미공개). Defer = 가능성 있음, 단 기적은 아님.

# 강의 93 · 🎓 실전 꿀팁 모음

- **ED 11/1 마감 역산**: 에세이 최종본은 10/20까지 완성. 10/21–10/31은 오탈자 교정, 교사 추천서 업로드 확인, CSS Profile 제출만. 마지막 주에 에세이 쓰는 건 재앙.
- **추천서 요청 타이밍**: 최소 8–10주 전, 즉 8월 말–9월 초. 고등학교 담임(카운슬러)에게는 학교 리스트 확정본과 활동 요약표를 함께 제출하라 (Brag Sheet).
- **Cornell ED 합격률 24%**: 같은 프로필로 RD 지원 시 ~7%. 단, Need-Aware이므로 재정 신청 금액이 클수록 불이익. 재정 자부담 $30k 이상 가능하면 ED가 유리.
- **Dartmouth ED 21%**: Dartmouth는 전체 합격자의 약 47%를 ED로 선발. 진심으로 1순위라면 ED 효과가 가장 큰 Ivy 중 하나.
- **MIT EA는 non-restrictive**: MIT EA를 쓰면서 U of Michigan EA, UNC EA 등 공립 EA 동시 지원 가능. MIT + 공립 EA 3–4개 조합은 흔한 전략.
- **WL(Waitlist) LOCI 작성법**: "저는 이 학교를 여전히 1순위로 생각합니다" + 1월 이후 새 성과(수상, 논문 게재, 성적 상승 등) 구체적으로 1–2개. 감사 인사로 마무리. 1페이지 엄수.
- **재정 Appeal**: 합격 후 재정 패키지가 마음에 안 들면 Appeal 가능. 다른 학교 더 나은 패키지 제시 + 가족 특수 상황(의료비 등) 추가 설명. Ivy는 보통 1회 Appeal 허용.
- **Common App 제출 직후**: 확인 이메일 저장 + 각 학교 지원자 포털 계정 즉시 생성. 추가 서류 요청, 인터뷰 초대가 포털로 오는 경우가 많다.

# 강의 93 · 흔한 실수 & FAQ

**❌ 흔한 실수**
- Why Us 에세이를 전부 똑같이 복사 → 학교 이름만 바꿈 → AO가 즉시 감지
- 추천서 요청을 10월에 함 → 선생님이 거절하거나 퀄리티 저하
- "보내고 잊음" — 제출 후 Midyear Report, Interview 요청, 추가 서류 미확인
- CSS Profile 마감을 입학 마감과 같다고 착각 → 재정 패키지 0 or 축소

**Q. WL(Waitlist)을 받았을 때 어떻게 하나요?**
A. LOCI(Letter of Continued Interest)를 2주 안에 제출. 1페이지 이내, 새 성과 1–2가지 포함. 한국 국제학생 WL 전환율은 낮지만 0이 아니다.

**Q. ED로 불합격하면 RD 불이익이 있나요?**
A. 없다. Defer(EA 연기)와 달리 ED 불합격은 RD 재지원 불가 학교들이 있음 — 학교 정책을 반드시 확인하라.

**Q. 재정 Appeal은 누구나 할 수 있나요?**
A. 합격 후라면 대부분 가능. 단 근거 없는 Appeal은 효과 없음. 다른 학교 오퍼 레터 첨부가 가장 강력한 근거.

**전공 선택의 두 가지 함정**

```
함정 1: 인기 전공 따라가기
  "Computer Science로 쓰면 더 유리하지 않을까?"
  → CS는 가장 경쟁이 치열한 전공 중 하나
  → MIT CS 합격률: ~4.7% (전체), STEM 지원자 내 더 낮음

함정 2: 일단 Undecided
  "나중에 결정하면 되니까 일단 Undecided"
  → Undecided는 전략이 없다는 신호로 읽힐 수 있음
  → 단, College 단위 입학 학교(Yale·Harvard 등)는 괜찮음
```

```
내 스파이크 + 활동 스토리
      ↓
그것과 연결된 전공을 쓴다
      ↓
"왜 이 전공인가"를 에세이·인터뷰에서 설명할 수 있다
```

# 강의 94 · 전공 변경 옵션과 학교별 유연성

**전공 유연성은 학교마다 크게 다르다**

| 학교 구조 | 설명 | 예시 |
|---|---|---|
| College 단일 지원 | 입학 후 전공 선택, 유연 | Yale, Princeton, Harvard (일부) |
| School별 지원 | 전공 학교로 직접 지원, 전과 어려움 | Cornell (7개 칼리지), UPenn |
| Liberal Arts Core | 폭넓은 교양 후 전공 | 대부분 문리대 |

**School별 지원 학교 지원 시 주의**
```
Cornell: Engineering vs A&S vs ILR은 각각 별도 지원
         전과는 내부 경쟁 필요, 합격률 차이 있음
         Engineering ED 합격률 > A&S ED 합격률 (역설적으로 Engineering이 더 넓은 경우)
UPenn:   Wharton vs SEAS vs CAS — 전공 학교가 다름
         Wharton은 Ivy 중 경영학 유일 → 경쟁 극심
```

🎓 **Ivy Tip**: School별 지원 학교는 **지원 School 선택 자체가 전략**. 점수 같아도 School마다 합격률이 다를 수 있다. Cornell A&S로 입학 후 내부 전과로 Engineering 가는 경로도 실재한다.

```
STEM 전공                        비 STEM 전공
```

- Finance는 **STEM 아님** — 별도 확인 필수

# 강의 94 · 🎓 실전 꿀팁 모음

- **전공 선택 + Why Us 연결 공식**: "저는 [전공]을 통해 [문제]를 해결하고 싶습니다. [학교]의 [교수명/연구실/수업명]이 그 첫 발판입니다." — 이 문장이 Why Us 에세이의 핵심 문장.
- **교수 이메일 전략**: Why Us에 교수를 언급하기 전, 실제로 논문 1편을 읽고 짧은 이메일을 보내라. 인터뷰에서 "이 교수님 연구 알고 있나요?"라는 질문에 답할 수 있어야 한다.
- **UPenn Wharton 현실**: 국제학생 합격률 ~3%. 경영학 스파이크(창업·금융 프로젝트) 없이 지원하면 에세이가 아무리 좋아도 어렵다. Wharton 대신 Penn CAS (Economics) 전략도 유효.
- **Columbia Core Curriculum**: Columbia는 모든 학생이 Core(고전·문학·철학 필수 이수)를 거친다. CS 지원자도 Core에 진심으로 흥미 있다는 메시지를 에세이에 넣어야 한다.
- **Princeton BSE vs AB**: Engineering(BSE)과 Arts & Sciences(AB) 입학 시 전공 분리. BSE → AB 전과는 가능하지만 내부 경쟁. STEM 스파이크이지만 인문 혼합을 원하면 AB + 복수전공이 실용적.
- **Undecided 쓰는 게 나은 경우**: 활동이 2–3개 분야에 걸쳐 있고 통합하는 스토리가 아직 없을 때. 단, 에세이에서 "나는 여러 관심사를 통합하는 방향을 탐색 중"이라는 맥락은 있어야 한다.
- **이중전공/복수전공 언급**: Why Us에서 "저는 CS와 Philosophy를 복수전공하고 싶습니다"처럼 구체적 조합을 쓰면 AO 눈에 더 선명하게 보인다. 단, 현실적으로 가능한 조합인지 학교 요강 먼저 확인.

# 강의 94 · 흔한 실수 & FAQ

**❌ 흔한 실수**
- 에세이마다 전공이 다름 (학교 A에서는 Economics, 학교 B에서는 CS) → 원서 전체 일관성 붕괴
- "Undecided"를 전략으로 사용 — 단, Harvard·Yale처럼 College 단위 지원이면 괜찮음
- 관심 교수·연구실을 Why Us에 쓰고 실제로는 이메일 한 번도 안 보냄 → 인터뷰에서 걸림
- OPT 연장 때문에 CS로 억지 전과 → 흥미 없는 전공 4년 + 성적 저하

**Q. 전공을 2개 쓸 수 있나요?**
A. 대부분 Common App에서 1개 입력. 단, 일부 학교는 Secondary Major Interest 란이 있음. 2개를 쓸 경우 둘 다 연결되는 스토리가 있어야 한다.

**Q. 입학 후 전공을 바꿔도 되나요?**
A. 된다. 단 School별 지원 학교(Cornell, UPenn 등)는 내부 전과 경쟁 필요. College 단위 입학(Yale·Harvard)은 1학년 말 ~ 2학년 초에 자유롭게 선택 가능.

# 흔한 실수 총정리 & 마지막 FAQ

**❌ 절대 하지 마라**
- Safety 학교 에세이를 대충 쓰기 — Yield 데이터를 AO는 안다
- Why Us를 위키피디아 수준 정보로 채우기 ("귀교는 훌륭한 연구 시설을 갖추고 있습니다")
- 추천서 선생님께 마감 2주 전 부탁하기 — 최소 8주 전
- 재정 신청 없이 지원 → 합격해도 갈 수 없음
- CSS Profile과 입학 원서를 같은 날 제출한다고 착각 — 둘은 별개 시스템
- Defer 받고 LOCI를 제출 안 함 — Defer = 포기가 아니다

**Q. 학교를 더 쓸수록 합격 확률이 높아지나요?**
A. 20개 이상은 오히려 에세이 퀄리티가 분산된다. 12–16개가 현실적 최대.

**Q. 재수(Gap Year)도 전략이 될 수 있나요?**
A. 된다. 단 Gap Year의 내용이 원서 스토리를 강화해야 한다. 연구 인턴십·출판·창업 등 구체적 성과가 있어야 "전략적 Gap Year"로 인정된다.

**Q. Alumni Interview를 요청받으면 어떻게 해야 하나요?**
A. 72시간 이내 회신, 화상 or 대면. 지원 동기·전공 이유·캠퍼스 생활 계획 준비. Interview는 합불 결정적 요인은 아니지만 "왜 이 학교인가"를 다시 한번 설득하는 기회다.
