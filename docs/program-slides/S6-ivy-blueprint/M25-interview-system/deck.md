# 0. 왜 인터뷰가 결정적인가

```
합격자 비율 내 인터뷰 비중 (Yale AO 비공개 메모 인용):
  서류 비슷한 두 지원자 → 인터뷰가 "결정적 증거"
  점수가 완벽해도 → 인터뷰서 "맞지 않는다"면 보류
  점수가 조금 낮아도 → 인터뷰서 "진짜다" 싶으면 어드
```

**인터뷰의 실제 기능**
- 서류를 *확인*한다 — 에세이의 내가 *진짜 나*인지.
- "왜 우리 학교?"를 **살아있는 언어**로 검증한다.
- 동문 인터뷰어가 한 줄 메모를 제출 → 파일에 들어간다.

🎓 **Ivy Tip**: 인터뷰는 심문이 아니라 **대화**다. 인터뷰어도 합격생을 찾고 싶어한다.

## 파트 1 · 동문 인터뷰 구조 이해

**누가 면접을 보나?**
```
Ivy 8개교 기준:
  Harvard  → HAA(Harvard Alumni Association) 지역 담당자
  Yale     → 졸업생 자원봉사자, 보통 졸업 후 1–20년
  Columbia → CUMB(Columbia University Alumni Association)
```

- 첫 이메일에서 **Zoom 선호 여부** 미리 확인해두기.

🎓 **Ivy Tip**: 인터뷰어는 사정관이 아니다. *동문 선배*로 대하면 어색함이 사라진다.

# 103-2. STAR 답변 프레임워크

> "Situation → Task → Action → Result"

```
S (상황) : 구체적 장소·시간·맥락 1~2문장
T (과제) : 내가 해결해야 했던 것
A (행동) : 내가 한 것 (수동 아님 → 능동)
R (결과) : 측정 가능 or 배운 것

전체 : 90초~2분 목표 (영어 기준 약 200~250단어)
```

**나쁜 답 ❌ vs 좋은 답 ✅**

| | 나쁜 답 ❌ | 좋은 답 ✅ |
|---|---|---|
| S | "한 번은 어려운 상황이 있었어요" | "고2 여름, 교내 리서치팀 팀장을 맡았을 때" |
| T | "열심히 해야 했어요" | "팀원 3명이 방향을 잃어 마감이 위태로웠어요" |
| A | "같이 열심히 했어요" | "매주 30분 1:1 체크인을 도입하고 역할을 재배분했어요" |
| R | "잘 됐어요" | "발표 평점 4.8/5, 팀원 2명이 이후 같은 팀 요청" |

# 103-3. "왜 이 학교?" 답변 설계 (5-Layer Framework)

```
Layer 1 │ 스파이크 연결     — "내 [관심영역]이 [학교의 X]와 맞물린다"
Layer 2 │ 구체 자원        — 교수 이름·Lab·프로그램·수업 코드
Layer 3 │ 캠퍼스 문화      — 기숙사·클럽·전통·가치
Layer 4 │ 동문/현재 재학생  — 이야기 들은 구체 사람
Layer 5 │ 나의 기여        — 내가 캠퍼스에 가져올 것
```

**규칙:** Layer 2 없으면 Generic — 반드시 **수업명·교수명** 하나 이상 포함.

🎓 **Ivy Tip**: Yale AO가 인터뷰어 메모에서 "why us"를 별도 체크한다. "Yale의 분위기가 좋아서"는 0점이다.

# 103-4. "왜 이 학교?" — 📝 채워진 예시 (Cornell · 생명공학 전공)

> *"저는 고등학교 2년 동안 DIY 바이오센서를 만들며 저비용 진단 기술에 매달렸습니다. Cornell을 선택한 이유는 세 가지입니다.*
>
> *첫째, Weill Institute for Cell and Molecular Biology의 Lois Pollack 교수님 랩이 X선 산란으로 단백질 접힘을 실시간 관찰하는데, 제 센서 연구와 직결됩니다.*
>
> *둘째, Cornell의 Engineering-Biology Cross-College Major 구조가 공학 + 의과학을 학부에서 동시에 밟을 수 있게 합니다 — 다른 Ivy에는 없는 루트입니다.*
>
> *셋째, 입학생 Sarah Kim(2023 Cornell)과 얘기했을 때 '학생이 교수 랩에 1학년 때부터 들어간다'는 말이 결정적이었습니다."*

**왜 좋은가**
- Layer 2: 교수 이름 + 랩 이름 명시
- Layer 5: 내 연구가 어떻게 캠퍼스에 기여할지 암시
- Generic 문구 "좋은 교육" 없음

---

# 103-5. "왜 이 전공?" — 흔한 실수 ❌ 대 좋은 답 ✅

| 항목 | 흔한 실수 ❌ | 좋은 답 ✅ |
|---|---|---|
| 출발점 | "어릴 때부터 좋아했어요" | "고2 때 [구체 사건]이 계기" |
| 근거 | "이 분야가 유망해서" | "내가 [구체 행동]을 해봤고 그때 몰입했어요" |
| 학교 연결 | 없음 | "[학교의 X 프로그램]으로 더 깊이 팔 수 있어요" |
| 미래 | "취업이 잘 되니까" | "해결하고 싶은 [구체 문제]와 연결" |

✍️ 실습: "왜 이 학교/전공" 2분 스크립트를 지금 소리 내어 써라 — 키워드 아님, *문장으로*.

# 103-6. 자주 틀리는 질문 TOP 5 — 국제학생 특화

| 질문 | 국제학생 흔한 실수 ❌ | 정답 방향 ✅ |
|---|---|---|
| Tell me about yourself | 이력서 낭독 | 스토리 1개 → 핵심 가치로 연결 |
| Biggest weakness | "없어요" / "완벽주의" | 진짜 약점 + 개선 증거 |
| 10년 후 | 직업명만 | 풀고 싶은 문제 + 역할 |
| Challenge | 점수 이야기 (시험 어려웠다) | 인간관계·사회적 도전 우선 |
| How will you contribute | "열심히 할게요" | 구체 클럽·이벤트·커뮤니티 |

🎓 **Ivy Tip**: "완벽주의"는 Ivy 인터뷰에서 가장 많이 나오는 답이다. 인터뷰어는 속으로 눈을 굴린다.

# 강의 104 · Mock Interview — 연습 시스템

## 파트 2 · 어떻게 연습하는가

**Mock Interview 3단계 루프**

```
1. 혼자 → 녹화 (15분)
      ↓
2. 파트너/멘토 → 피드백 (30분)
      ↓
3. 루브릭 자기채점 → 개선 포인트 3개 추출 (15분)
      ↓
   다시 1단계 — 최소 3회전
```

**도구 세팅**
- 카메라: 눈높이 (노트북 거치대 필수 — 아래서 올려보는 각도 ❌)
- 배경: 깔끔한 벽 or 선반 (어수선한 방 ❌)
- 조명: 창문 빛이 얼굴 앞에서 (역광 ❌)

# 104-1. Mock Interview 채점 루브릭 (100점 만점)

| 항목 | 배점 | 3점 (Pass) | 1점 (Fail) |
|---|---|---|---|
| 구체성 | 25 | 장소·이름·숫자 포함 | 추상 일반론 |
| 자연스러움 | 20 | 대화하듯 자연스러움 | 외운 티 남 |
| 눈맞춤 | 15 | 카메라 70% 이상 | 카메라 거의 안 봄 |
| 길이 | 15 | 90초~2분 | 30초 이하/3분 초과 |
| 왜 학교 | 15 | Layer 2 이상 포함 | Generic |
| 역질문 | 10 | 인터뷰어 맞춤 질문 | "없어요" or 위키 질문 |

→ **70점 이상** = Mock 통과. 미달 시 재녹화 후 재채점.

# 104-2. Mock Interview 파트너 운영법

**파트너 역할 분담**
```
Round 1:  A가 인터뷰이 → B가 인터뷰어 + 채점 (30분)
Round 2:  B가 인터뷰이 → A가 인터뷰어 + 채점 (30분)
디브리핑: 루브릭 기반 피드백 교환 (15분)
```

**인터뷰어 역할 팁 (B로서)**
- 실제로 대화하듯 — 로봇처럼 질문지만 읽지 말 것.
- "흥미롭네요, 그 부분 더 얘기해줄 수 있어요?"로 follow-up 추가.
- 채점은 *답 내용*이 아니라 루브릭 항목만으로.

🎓 **Ivy Tip**: 파트너 없으면 InHero 멘토(현 Ivy 재학생)에게 Mock 신청 — 실제 같은 학교 동문 인터뷰어에 가장 가깝다.

# 104-3. 녹화 분석법 — "3번 보기" 프로토콜

```
1회차 시청: 소리 끄고 보기  → 표정·눈맞춤·손 제스처만 관찰
2회차 시청: 화면 끄고 듣기  → 속도·필러(um, like, 어)·목소리 확인
3회차 시청: 정상 재생       → 전체 인상 (루브릭 채점)
```

**가장 많이 발견되는 문제**
| 문제 | 해결 방법 |
|---|---|
| "um", "어" 남발 | 멈추는 연습 — 침묵이 자신감이다 |
| 너무 빠른 말 | 핵심 단어 후 0.5초 pause 의도적 삽입 |
| 눈이 위로 향함 | 떠올리는 중 → 답 미리 정리해두기 |
| 답이 너무 짧음 | STAR 2번째 예시 준비해두기 |

# 105-1. 긴장 관리 — 국제학생 실전 팁

**"나는 영어가 모국어가 아닌데 어떡하지?"**

```
걱정 ❌                         현실 ✅
──────────────────────────────────────────
완벽한 발음이 필요하다       → 명료함·내용이 발음보다 중요
빠르게 말해야 한다          → 느리고 또렷함이 신뢰감
모르는 단어 나오면 끝       → "Could you rephrase that?" 가능
침묵 = 실패                 → 2~3초 생각 후 답 = 자신감
```

**실전 긴장 해소 3가지**
1. **박스 호흡** (4-4-4-4): 대기실에서 조용히
2. **"최악이어도 괜찮다" 리셋**: 인터뷰 한 번으로 불합격 안 남
3. **인터뷰어를 선배로 보기**: 심사관 아님, 대학 경험 나눠주고 싶은 동문

🎓 **Ivy Tip**: Harvard 합격생 인터뷰 회고 — "면접 끝나고 인터뷰어가 '정말 기대되는 지원자'라고 했어요. 영어 발음은 한국 억양이 강했는데."

# 105-2. 영어 실전 대응 문구 모음

**이해 못 했을 때**
- "I'm sorry, could you rephrase that?"
- "Just to make sure I understood — are you asking about [내 이해]?"

**생각할 시간이 필요할 때**
- "That's a great question. Let me think for a moment."
- "I'd like to give you a thoughtful answer — give me just a second."

**답 정리하며 시작할 때**
- "So, to answer that — " (STAR 시작)
- "The experience that comes to mind is…"

**마무리 전환**
- "Does that answer what you were looking for?"
- "I'm happy to elaborate if you'd like."

# 105-3. 역질문 — 준비 방법 + 예시 10개

**규칙**
```
❌ 웹사이트/위키에서 찾을 수 있는 것은 묻지 마라
✅ 인터뷰어 개인 경험에 뿌리 둔 질문이 최고
```

**역질문 예시 10개 (인터뷰어 맞춤형)**

| # | 역질문 | 노리는 효과 |
|---|---|---|
| 1 | "인터뷰어님은 어떤 계기로 [학교]를 선택하셨나요?" | 공감 + 대화 오픔 |
| 2 | "재학 중 가장 예상 밖의 수업이나 경험은 무엇이었나요?" | 진짜 캠퍼스 인사이트 |
| 3 | "[내 전공]으로 가장 활용도 높은 과외활동은 뭐였나요?" | 전공 진지함 보여줌 |
| 4 | "졸업 후 [학교]가 준 가장 큰 자산은 뭐였나요?" | 장기 사고 어필 |
| 5 | "[학교]에서 가장 도움됐던 자원(교수·센터·클럽)은?" | 리서치 연결 가능 |
| 6 | "지금 돌아가도 같은 학교 선택하시겠어요? 이유는?" | 진솔한 대화 유도 |

| 8 | "[캠퍼스의 특정 전통/행사]는 실제로 어떤가요?" | 구체 리서치 어필 |
| 9 | "제 에세이/활동 중 더 알고 싶은 부분이 있으신가요?" | 서류 보완 기회 |
| 10 | "한 가지 조언을 주신다면?" | 마무리 인상 |

# 105-4. 역질문 — 흔한 실수 ❌

| 실수 | 왜 문제인가 |
|---|---|
| "역질문 없어요" | 관심 없다는 신호로 읽힘 |
| "장학금 받을 수 있나요?" | 동문 인터뷰어는 금융 전문가 아님 |
| "SAT 점수가 낮은데 괜찮을까요?" | 불안 노출 + 분위기 경직 |
| "학교 홈페이지에 있는 정보" 질문 | 리서치 안 했다는 신호 |
| 3개 이상 연속으로 | 인터뷰가 아니라 조사가 됨 — 1~2개 적당 |

✍️ 실습: 지원 학교 1개 선택 → 역질문 3개를 지금 인터뷰어 개인 경험 기반으로 작성하라.

# 105-5. 국제학생 특화 — 자주 묻는 추가 질문 대응

| 인터뷰어 질문 | 함정 | 정답 방향 ✅ |
|---|---|---|
| "미국에서 공부하면 어려운 점은?" | 약점만 나열 | 어려움 + 내 대응 전략 |
| "한국 교육 시스템에 대해 어떻게 생각해요?" | 비판 or 무조건 칭찬 | 배운 것 + 내가 더 원하는 것 |
| "왜 한국 대학은 안 가나요?" | 한국 폄하 | 미국에서만 가능한 특정 자원 |
| "영어 실력은 충분하다고 생각해요?" | "네, 완벽해요" | 현재 수준 솔직 + 개선 노력 |

🎓 **Ivy Tip**: Penn 합격 국제학생(서울·영어 비원어민) — "영어 불완전함을 솔직히 말하고, '대신 이중 문화 시각이 강점'이라 했더니 인터뷰어가 메모했다."

# FAQ — 국제학생이 가장 많이 묻는 것

**Q. 인터뷰가 없는 학교도 있나요?**
A. 있다. Columbia는 2023년부터 동문 인터뷰 공식 폐지. MIT·Caltech 등도 없음. 지원 학교 웹사이트 직접 확인.

**Q. Zoom vs 대면 중 어느 게 유리한가요?**
A. 공식적으로 차이 없다. 단, 대면은 *관계*가 형성될 가능성 높음. 둘 다 가능하면 대면 우선.

**Q. 인터뷰에서 잘못한 것 같으면 회복이 안 되나요?**
A. 동문 메모는 "인상" 수준 — 서류가 더 큰 비중. 잘못한 인터뷰 하나로 불합격이 결정되지 않는다.

**Q. 인터뷰어가 내 학교/성적을 알고 있나요?**
A. 일반적으로 이름과 지역 정도만 안다. 성적/에세이 모름 — 오히려 기회.

**Q. 한국어로 인터뷰 가능한가요?**
A. 아니다. 전부 영어. 단, 속도·발음 완벽 불요.
