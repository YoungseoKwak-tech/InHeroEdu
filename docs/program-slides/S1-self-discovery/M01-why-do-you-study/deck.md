# 왜 동기부터인가? (도표)

| 흔한 출발점 | InHero 출발점 |
|---|---|
| 스펙부터 쌓는다 | **왜 하는지**부터 정한다 |
| 남이 한 활동 따라함 | 내 감정·호기심에서 출발 |
| 번아웃 → 중도 포기 | 내적 동기 → 지속 |
| 에세이에 쓸 게 없음 | 모든 활동이 한 서사로 연결 |

🎓 **Ivy Tip**: 입학사정관은 "무엇을 했나"보다 **"왜 그걸 했나(motivation)"** 의 일관성을 본다.

---

# 동기의 2종류 (프레임워크)

```
외적 동기 (extrinsic)        내적 동기 (intrinsic)
─────────────────           ─────────────────
성적 · 등수 · 칭찬           호기심 · 몰입 · 의미
↓ 빨리 타오르고 꺼짐         ↓ 느리지만 오래 감
시험 끝나면 멈춤             평생 학습으로 이어짐
```

- 단기 폭발력은 외적 동기, **장기 생존력은 내적 동기.**
- 목표: 외적 동기로 출발하더라도 **내적 동기로 갈아끼우는 것.**

---

# 강의 1 · "지금 안 하면 미래가 좁아진다"의 진짜 의미

- 공포 마케팅이 아니라 **선택지(option) 의 문제**.
- 지금의 노력 = 미래에 **고를 수 있는 문(門)의 수**.

```
노력 적음 →  ▢ ▢ □ □ □   (열린 문 2개)
노력 많음 →  ▢ ▢ ▢ ▢ ▢   (열린 문 5개)
```
> 합격이 목표가 아니라, **나중에 후회 없이 고를 수 있는 상태**가 목표.

✍️ 1분 메모: "내가 닫고 싶지 않은 문 3개는?"

# 📂 실물 — 합격생의 실제 동기 메모

`[그림: 코넬 합격생이 고1 때 쓴 손글씨 동기 메모 스캔]`

- "성적 때문"이 아니라 **"죽은 해파리에서 가치를 본 순간"** 에서 출발.
- 동기가 구체적 장면일수록 → 나중에 에세이 소재가 된다.

🎓 **Ivy Tip**: 동기는 추상명사("열정")가 아니라 **장면(scene)** 으로 적어둬라.

- 6개월 뒤 다시 열어볼 것 (Season 6에서 사용).

# 강의 2 · 롤모델 분석 시스템

목표: 존경하는 사람 → **공통 패턴 추출** → 내 가치관 발견.

```
롤모델 10명
   ↓ 각자 "무엇 때문에 존경?"
공통 키워드 추출 (예: 끈기 · 창조 · 타인을 도움)
   ↓
나의 핵심 가치 3개 도출
```

🎓 **Ivy Tip**: 유명인 말고 **반경 1m 안의 사람**(선배·선생님·부모)도 넣어라 — 더 진짜다.

# 강의 3 · 좋아하는 "감정" 찾기

직업("의사")이 아니라 **감정**에 집중하라.

```
호기심 — 자꾸 검색하게 되는 것
몰입   — 시간 가는 줄 모르는 것
분노   — 못 참고 바꾸고 싶은 것
경외감 — 보면 압도되는 것
```

> 직업은 바뀌어도 **감정의 패턴은 안 바뀐다.** 그게 진짜 나침반.
