# 0. 대부분의 학생이 틀리는 출발점

```
일반 경로:   활동 검색 → 따라하기 → 번아웃 → "에세이 쓸 게 없다"
InHero 경로: 왜/누구 → 감정·가치 → 활동이 거기서 자라남 → 한 서사로 연결
```

**왜 이게 중요한가 — 입학사정관의 시선**
- 사정관은 하루 40–60개 원서를 읽는다(평균 **8–10분/원서**).
- "무엇을 했나(activity list)"는 다 비슷해 보인다.
- 기억에 남는 건 **"왜 그걸 했는지의 일관성(through-line)."**

🎓 **Ivy Tip**: 활동 10개가 *따로 놀면* 0점, *한 축으로 꿰이면* 그게 스파이크.

# 0-1. "동기 없는 노력"의 비용 (도표)

| | 동기 없는 노력 | 동기 있는 노력 |
|---|---|---|
| 지속 | 시험 끝나면 멈춤 | 시험 무관하게 지속 |
| 깊이 | 표면 암기 | 파고듦 |
| 회복 | 실패=포기 | 실패=재료 |
| 산출 | 점수만 | 점수+프로젝트 |
| 에세이 | 소재 빈곤 | 소재 풍부 |

> 같은 시간을 써도 **결과의 복리(compounding)** 가 다르다.

# 1. 강의 1 · 동기의 과학

**두 종류의 연료**
```
외적 동기 (Extrinsic)        내적 동기 (Intrinsic)
성적·등수·칭찬·보상           호기심·몰입·의미·자율
─────────────               ─────────────
↑ 즉발력 강함                ↑ 지속력 강함
↓ 빨리 꺼짐(보상 사라지면)   ↓ 느리게 붙음
```
- 과잉정당화 효과: 좋아서 하던 일도 **보상이 붙으면 흥미가 준다**(연구로 확인된 현상).
- 전략: 외적 동기로 *시동*을 걸되, 빠르게 **내적 동기로 갈아끼운다.**

---

# 1-1. 동기 감쇠 곡선 (Motivation Decay)

```
의욕
 │＼
 │  ＼______          ← 외적 동기만: 급락 후 바닥
 │        
 │   ／ˉˉˉˉˉˉˉˉ      ← 내적 동기: 느리지만 우상향
 │ ／
 └────────────── 시간
```

**갈아끼우는 3가지 레버**
1. **자율(Autonomy)** — "시켜서"를 "내가 정해서"로
2. **숙련(Mastery)** — 어제보다 나아짐을 *측정*
3. **목적(Purpose)** — 이게 누구에게 도움 되나

🎓 **Ivy Tip**: 세 레버 중 하나라도 약하면 의욕이 샌다. 매주 셀프 점검.

---

# 1-2. "문(門) 모델" — 노력의 진짜 의미

> 공부는 합격이 목표가 아니라 **나중에 고를 수 있는 문의 수**를 늘리는 일.

```
지금 적게:  ▢ ▢ □ □ □ □ □   (열린 문 2)
지금 많이:  ▢ ▢ ▢ ▢ ▢ ▢ ▢   (열린 문 7)
```

- 17세의 노력 = 22세의 **선택지**.
- 목표 재정의: "합격" → **"후회 없이 고를 수 있는 상태."**

✍️ 30초 메모: *내가 닫고 싶지 않은 문 3개*는?

---

# 1-3. 📂 실물 — 합격생의 고1 동기 메모

`[그림: 코넬 ECE 합격생이 고1 때 쓴 손글씨 동기 메모 스캔 — '죽은 해파리' 첫 등장]`

# 1-4. ✍️ 과제 · Future Letter — 작성 가이드

**목적:** 10년 후의 나에게 편지를 써서, 오늘의 방향을 역산한다.

**구조(3문단, 250–400단어):**
| 문단 | 써야 할 것 | 가이드 질문 |
|---|---|---|
| ① 하루 한 장면 | 10년 후 평범한 화요일 아침 | 일어나서 무엇을 하나? 누구와? |
| ② 풀고 있는 문제 | 그때 내가 매달린 문제 | 왜 그게 나를 붙드나? |
| ③ 오늘의 첫걸음 | 17세의 내가 오늘 시작할 1가지 | 가장 작은 행동은? |

# 1-5. Future Letter — 📝 채워진 예시 (발췌)

> *"2036년 화요일 아침. 나는 방콕의 작은 진단 스타트업 사무실에서 종이만큼 얇은 바이오센서 시제품을 들여다보고 있다. … 내가 매달리는 문제는 '왜 가난한 동네일수록 진단이 늦는가'다. … 그래서 17세의 나는 오늘, 학교 과학실에서 pH 센서 하나를 직접 만들어보는 것부터 시작한다."*

**무엇이 좋은가**
- ① 추상 아님 → *방콕·바이오센서* 구체 장면
- ② 점수 아님 → *진단 격차* 라는 문제
- ③ 거창 아님 → *오늘 pH 센서 하나*

# 1-6. Future Letter — 채점 루브릭 + 흔한 실수

**루브릭(각 1–3점, 7점↑ 통과)**
| 항목 | 1점 | 3점 |
|---|---|---|
| 구체성 | "행복하게 산다" | 장면이 그려짐 |
| 문제 | 직업명만 | 풀 문제가 분명 |
| 행동 | "열심히 한다" | 오늘 할 1가지 |

**흔한 실수 ❌**
- 직업 이름만 적기("의사가 된다")
- 남이 멋있다 할 미래(내 게 아님)
- 너무 큼("세상을 바꾼다") → 장면으로 쪼개라

# 2. 강의 2 · 롤모델 분석 시스템

**핵심 원리:** 존경하는 사람들의 **공통 패턴**이 곧 *내 가치*다.

```
롤모델 10명 → 각자 "무엇 때문에?" → 공통 키워드 → 내 핵심 가치 3개
```

**선정 규칙**
- 유명인 3 + **반경 1m 안의 사람 4**(선배·선생님·부모·친구) + 역사/책 인물 3.
- "성공"이 아니라 **"닮고 싶은 태도"** 기준.

🎓 **Ivy Tip**: 가까운 사람을 넣을수록 가치가 *진짜*가 된다 — 사정관도 구별한다.

---

# 2-1. 롤모델 분석표 — 📝 채워진 예시

| # | 롤모델 | 존경 이유(태도) | 추출 가치 |
|---|---|---|---|
| 1 | 일론 머스크 | 불가능을 기본값으로 안 봄 | 담대함 |
| 2 | 옆반 선배 | 혼자 앱 만들어 출시 | 실행력 |
| 3 | 생물 선생님 | 모르면 "같이 찾아보자" | 정직·호기심 |
| 4 | 마리 퀴리 | 인정 못 받아도 계속 | 끈기 |
| 5 | 엄마 | 작은 약속도 지킴 | 신뢰 |
| … | | | |

→ 가장 자주 나온 3개: **담대함 · 실행력 · 호기심** = 나의 축

# 2-2. 가치 추출 워크플로우 (도표)

```
원초 단어 10개 (이유들)
   ↓ 비슷한 것 묶기
클러스터 3–4개
   ↓ 각 클러스터 대표 1단어

   ↓ 검증: "내가 한 행동에 이 가치가 보이나?"
확정
```

✍️ 실습: 표 작성 → 클러스터링 → **핵심 가치 3개 + 각각 내 행동 증거 1개.**

# 3. 강의 3 · 감정 나침반

> 직업("의사")이 아니라 **감정**에 집중하라. 직업은 바뀌어도 *감정 패턴*은 안 바뀐다.

**4대 신호 감정**
| 감정 | 신호 | 가리키는 것 |
|---|---|---|
| 호기심 | 자꾸 검색·질문 | 탐구 영역 |
| 몰입 | 시간 가는 줄 모름 | 재능 영역 |
| 분노 | 못 참고 고치고 싶음 | 사명 영역 |
| 경외감 | 압도됨·소름 | 비전 영역 |

---

# 3-1. 감정별 발굴 질문 (프롬프트)

**호기심** — 최근 한 달, 시키지 않았는데 검색한 것 5개?
**몰입** — 시간 가는 줄 몰랐던 활동 3개? 그때 *무엇을* 하고 있었나?
**분노** — 뉴스/일상에서 "이건 진짜 문제다" 싶은 것 3개?
**경외감** — 보고 소름 돋았던 것(영상·책·자연·사람) 3개?

🎓 **Ivy Tip**: **분노**가 가장 강한 스파이크 연료다 — "없어서 내가 만들었다"의 출발점.

---

# 3-2. Emotion Map — 📝 채워진 예시

| 감정 | 최근 순간 3개 | 공통점 |
|---|---|---|
| 호기심 | CRISPR 영상, 센서 원리, 단백질 접힘 | **생명+측정** |
| 몰입 | 회로 납땜, 데이터 그래프, 코딩 | **만들기** |
| 분노 | 동네 병원 오진, 느린 진단 | **의료 격차** |
| 경외감 | 인공장기 다큐 | **생명공학** |

→ 4칸 교집합: **"생명과학 × 공학으로 진단 격차 줄이기"** = 관심 영역 후보

---

# 3-3. 감정 → 관심 영역 수렴 (도해)

```
호기심(생명+측정)╲        ╱몰입(만들기)
                  ╲      ╱
                   ● 바이오센서로 진단 ●
                  ╱      ╲
   분노(의료격차)╱        ╲경외감(생명공학)
```

> 4개 감정이 한 점으로 모이면, 그게 **너만의 스파이크 후보**.

✍️ 실습: 내 4칸의 교집합을 **한 문장**으로.
