# 0. 왜 "지도"인가 (도표)

| 리스트 사고 | 지도 사고 |
|---|---|
| 활동을 나열 | 활동을 **연결** |
| 따로 노는 스펙 | 한 축으로 수렴 |
| "많이 했다" | "**일관되게** 했다" |
| 평범(replaceable) | 스파이크(memorable) |

> 합격 프로필의 공통점은 활동 *수*가 아니라 **"한 문장으로 설명되는 일관성."**

🎓 **Ivy Tip**: 사정관은 "이 학생은 ___ 한 애"라고 *한 줄로 메모*한다. 그 한 줄을 네가 설계하라.

# 0-1. 스파이크 vs 올라운더 (도해)

```
올라운더:   ▔▔▔▔▔▔▔   (다 평평, 안 튐)
스파이크:   ▔▔▔█▔▔▔   (한 곳 뾰족, 기억됨)
```

- 상위권은 다 성적이 좋다 → 성적은 *입장권*.
- 차별점 = **한 분야의 깊이(스파이크)** + 그걸 향한 활동의 정렬.

✍️ 30초: 내가 "남들보다 한 뼘 더 깊은" 분야 후보 1개?

# 1. 강의 4 · 관심사는 발견하는 것

```
❌ "어떤 활동이 입시에 좋아요?"
⭕ "나는 시키지 않아도 자꾸 무엇을 하지?"
```

**관심사 = 미래 상상이 아니라 과거 행동 데이터**
| 데이터 소스 | 무엇을 보나 |
|---|---|
| 검색·유튜브 기록 | 진짜 호기심 |
| 산 책·저장한 글 | 돈/시간 쓴 곳 |
| 시간 가계부 | 몰입 영역 |
| 대화 주제 | 자꾸 말하는 것 |

✍️ 실습: 최근 한 달 "시키지 않았는데 한 것" 10개 → 키워드화.

# 2. 강의 5 · 마인드맵 4단계 구축

```
1) 중앙: '나'
2) 1차 가지: 관심 영역 7개 (생물/코딩/음악/사회/…)
3) 2차 가지: 영역별 구체 키워드 5개
4) 형광펜: 에너지 큰 가지 3개
```

| 단계 | 시간 | 팁 |
|---|---|---|
| 중앙 | 1분 | 손으로 |
| 1차 | 10분 | 7개 못 채워도 OK |
| 2차 | 15분 | 막히면 검색기록 참고 |
| 형광 | 3분 | "두근거림" 기준 |

🎓 **Ivy Tip**: 디지털보다 **손**으로 먼저. 손이 더 솔직하다.

# 3. 강의 6 · 점과 점 연결하기 (교차)

> 스파이크는 한 점이 아니라 **두 점이 만나는 교차로**에서 난다.

```
생물  ╲           ╱ 공학
       ╲         ╱
        ● 바이오센서 ●   ← 교차로 = 스파이크
       ╱         ╲
사회  ╱           ╲ 음악
```

**교차 공식**: `[영역 A] × [영역 B] → 무엇을 만들 수 있나?`
예: 생물 × 공학 → *저가 진단 센서* / 사회 × 공학 → *접근성 기술*

✍️ 실습: 형광 친 3개를 둘씩 짝지어 **교차 아이디어 3개**.

# 3-1. 교차 아이디어 평가 (도표)

| 기준 | 질문 | 점수(1–5) |
|---|---|---|
| 에너지 | 생각만 해도 두근? | |
| 실행성 | 고등학생이 시작 가능? | |
| 독창성 | 남들이 잘 안 함? | |
| 확장성 | 4년간 키울 수 있나? | |

→ 합산 1위 교차 = **스파이크 1순위 후보**.

🎓 **Ivy Tip**: 너무 흔한 교차(예: "코딩×교육 앱")는 차별성이 낮다. 한 끗 더 좁혀라.

# 4. 강의 7 · T자형 탐색 전략

```
       넓게(가로): 여러 분야 맛보기
   ─────────────────────────────
                 │
                 │ 깊게(세로): 한 분야 파고들기
                 │
            T자형 인재
```

**타이밍 규칙**
| 학년 | 모드 | 행동 |
|---|---|---|
| 9–10 | 넓게 | 여러 분야 샘플링 |
| 11 | 좁히기 | 스파이크 1개 선택 |
| 12 | 깊게 | 결과물 완성 |

🎓 **Ivy Tip**: 너무 일찍 좁히면 *우물 안*, 너무 늦으면 *깊이 없음*. 11학년이 분기점.

# 5-1. 자기 점검 루브릭

| 항목 | 미달 | 통과 |
|---|---|---|
| 영역 수 | 3개 이하 | 7개 |
| 키워드 | 추상적 | 구체·검증 가능 |
| 교차 | 없음 | 3개+평가 |
| 수렴 문장 | 모호 | A×B 명확 |

→ 4개 통과 시 M3 unlock.

# 5-2. 흔한 실수 & FAQ

**❌ 실수**
- 미래 상상으로 가지 채움 → *과거 행동 데이터*로.
- 너무 일찍 1개로 좁힘 → 9–10학년은 *넓게*.
- 흔한 교차로 만족 → *한 끗 더 좁혀* 독창성 확보.

**Q. 교차가 안 보이면?**
A. 가지가 너무 추상적. 키워드를 *명사·구체물*로 더 쪼개라(예: "과학"❌ → "pH 센서"⭕).
