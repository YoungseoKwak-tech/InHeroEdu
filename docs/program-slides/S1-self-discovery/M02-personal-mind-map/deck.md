# Module 2 · Personal Mind Map
### 시즌 1 · 자기 발견 시스템

> 관심사는 **정하는 게 아니라 발견하는 것.**
> 흩어진 점들을 지도로 그리면, 나만의 "스파이크 축"이 보인다.

🎯 결과물: **Personal Interest Map (1장)**

`[그림: 한 학생의 실제 관심사 마인드맵 예시 — 생물×공학으로 수렴]`

---

# 왜 "지도"인가? (도표)

| 리스트 사고 | 지도 사고 |
|---|---|
| 활동을 나열 | 활동을 **연결** |
| 따로 노는 스펙 | 하나의 축으로 수렴 |
| "많이 했다" | "**일관되게** 했다" |
| 평범 | 스파이크(뾰족함) |

🎓 **Ivy Tip**: 합격 프로필의 공통점은 활동 수가 아니라 **"한 문장으로 설명되는 일관성"**.

---

# 강의 4 · 관심사는 발견하는 것

```
잘못된 질문:  "어떤 활동이 입시에 좋아요?"
좋은 질문:    "나는 어떤 걸 시키지 않아도 자꾸 하지?"
```

- 관심사 = **과거의 행동 데이터**에서 추출 (미래 상상 ❌, 과거 증거 ✅)
- 증거: 검색 기록 · 유튜브 시청 · 산 책 · 시간 쓴 것.

✍️ 1분: 최근 한 달 "시키지 않았는데 한 것" 5개 적기.

---

# 마인드맵 만드는 법 (4단계 프레임워크)

```
1) 중앙에 '나'
2) 1차 가지: 관심 영역 5~7개 (생물/코딩/음악/사회…)
3) 2차 가지: 각 영역의 구체 키워드
4) 색칠: 에너지가 큰 가지에 형광펜
```
`[그림: 4단계가 단계별로 채워지는 마인드맵 진행 이미지]`

---

# 강의 5 · 나만의 마인드맵 구축 (실습)

| 단계 | 할 일 | 시간 |
|---|---|---|
| A | 빈 종이/Notion 중앙에 이름 | 1분 |
| B | 관심 가지 7개 | 10분 |
| C | 가지마다 키워드 5개 | 15분 |
| D | 에너지 큰 가지 3개 형광 | 3분 |

🎓 **Ivy Tip**: 디지털보다 **손으로** 먼저. 손이 더 솔직하다.

---

# 강의 6 · 점과 점 연결하기

> 스파이크는 한 점이 아니라 **두 점이 만나는 교차로**에서 생긴다.

```
생물  ╲           ╱ 공학
       ╲         ╱
        ● 바이오센서 ●   ← 너의 교차로
       ╱         ╲
음악  ╱           ╲ 사회
```

✍️ 실습: 형광펜 친 3개 가지를 **둘씩 짝지어** 교차 아이디어 3개 적기.

---

# 📂 실물 — 합격생의 실제 마인드맵 진화

`[그림: 같은 학생의 마인드맵 3개월 전 vs 후 비교 스캔]`

- 처음엔 8개 영역이 흩어짐 → 3개월 뒤 **'생명과학×공학'** 한 축으로 수렴.
- 핵심: 지우고 합치는 **편집**이 발견이다.

🎓 **Ivy Tip**: 지도는 1회용이 아니라 **분기마다 업데이트**하는 살아있는 문서.

---

# 강의 7 · 탐색의 기술 (T자형)

```
       넓게 (가로): 여러 분야 맛보기
   ───────────────────────────
              │
              │ 깊게 (세로): 한 분야 파고들기
              │
        T자형 인재
```

- **먼저 넓게** 탐색 → 에너지 큰 곳 발견 → **그 다음 깊게.**
- 너무 일찍 좁히지 마라(고1), 너무 늦게 좁히지도 마라(고3).
