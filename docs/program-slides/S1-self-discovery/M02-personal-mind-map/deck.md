# 0. 리스트 사고 vs 지도 사고

| | 리스트 사고 | 지도 사고 |
|---|---|---|
| 활동을 | 나열한다 | **연결**한다 |
| 프로필이 | 따로 노는 스펙 | 한 축으로 수렴 |
| 인상은 | "많이 했다" | "**일관되게** 했다" |
| 사정관 메모 | "스펙 좋은 학생" (잊힘) | "○○ 하는 학생" (기억됨) |
| 에세이 소재 | 고3 여름에 막막 | 지도에서 자연 도출 |

> 합격 프로필의 공통점은 활동 **수**가 아니라 **"한 문장으로 설명되는 일관성."**

🎓 **Ivy Tip 1**: 사정관은 원서를 읽고 메모장에 딱 한 줄을 적는다 — "이 학생은 ___ 한 애." 그 한 줄을 **네가 먼저 설계하라.**

🎓 **Ivy Tip 2**: Harvard AO 출신 컨설턴트 Devon Sawyer가 공개한 메모 — 리뷰 시간 평균 **8분**. 활동 리스트 10개를 8분 안에 하나의 인상으로 만들어야 한다.

🎓 **Ivy Tip 3**: "리스트는 면접 준비, 지도는 원서 설계." Common App 에세이 650자가 막힌다면 아직 지도가 없는 것이다.

# 0-1. 스파이크(Spike)란 무엇인가

```
올라운더:   ▔▔▔▔▔▔▔▔▔▔   (모두 비슷한 높이 — 기억 안 됨)
스파이크:   ▔▔▔▔█▔▔▔▔▔   (한 곳 뾰족 — 기억됨)
```

**스파이크의 3가지 조건**
1. **깊이** — 학교 수업을 넘어선 자기 주도 탐구가 있다
2. **일관성** — 여러 활동이 같은 축을 가리킨다
3. **교차점** — 두 분야가 만나 독특한 조합이 된다

> 스파이크 없이 성적만 좋은 지원자 = "입장권은 있지만 이야기가 없는 학생"

**스파이크의 탄생 경로**
```
관심 A  ──┐
           ├──→ 교차로 ──→ 깊이 있는 결과물 ──→ 스파이크
관심 B  ──┘
```

🎓 **Ivy Tip 1**: Princeton 입학처장 Karen Richardson이 2023 웨비나에서 밝힌 것 — "우리가 찾는 것은 **지적 활력(intellectual vitality)**이다. 스파이크는 그 활력의 물리적 증거다."

🎓 **Ivy Tip 2**: MIT 입학 블로그 (mitadmissions.org/blogs)에서 합격생 인터뷰를 보면 공통적으로 등장하는 표현 — "I just couldn't stop thinking about it." **멈출 수 없었던 것**이 스파이크다.

🎓 **Ivy Tip 3**: Yale AO가 강조하는 숫자 — 지원자 중 스파이크가 명확한 학생은 **약 15%**, 그 중 합격률은 일반 풀 대비 **3배 이상**.

✍️ 30초: 내가 "남들보다 한 뼘 더 깊은" 분야 후보가 있다면 지금 바로 떠올려라.

# 0-2. "이 모듈 전에" — 행동 데이터 예열

> 마인드맵을 그리기 **전**, 과거 행동에서 원재료를 꺼내야 한다.

**5가지 데이터 소스 (지금 바로 열어라)**

| 데이터 소스 | 무엇을 보는가 | 어디서 꺼내는가 |
|---|---|---|
| 검색·유튜브 기록 | 진짜 호기심 (조회수 아님) | 브라우저 히스토리 / 유튜브 기록 |
| 산 책·저장한 글 | 돈과 시간을 쓴 곳 | 교보 구매이력 / 노션 스크랩 |
| 시간 가계부 | 주도적으로 몰입한 영역 | 캘린더 / 스크린타임 |
| 대화 주제 | 자꾸 꺼내는 이야기 | 카카오톡 검색어 |
| 분노·불만 메모 | 바꾸고 싶은 것 | 일기 / 메모앱 |

🎓 **Ivy Tip 1**: 유튜브·구글 검색 기록은 **가장 정직한 관심사 데이터**다 — 남에게 보여주려 한 것이 아니라 혼자 봤기 때문.

🎓 **Ivy Tip 2**: iPhone → 설정 → 스크린 타임 → "가장 많이 사용한 앱"을 3개월치 스크롤. 게임 앱 안에 숨어 있는 "전략" "스토리텔링" "커뮤니티 운영" 패턴이 스파이크 씨앗일 수 있다.

🎓 **Ivy Tip 3**: Google Takeout (takeout.google.com)에서 검색 기록 JSON 파일 다운 → 키워드 빈도로 정렬하면 3개월 관심사 히트맵이 나온다. 15분 작업, 효과 극대.

# 1. 강의 4 · 관심사는 발견하는 것

```
❌ "어떤 활동이 입시에 좋아요?"
⭕ "나는 시키지 않아도 자꾸 무엇을 하지?"
```

**관심사 = 미래 상상이 아니라 과거 행동 데이터**

> "나는 생명공학에 관심이 있다"는 *선언*이 아니라 *귀납*이어야 한다.
> 행동이 쌓여서 "이걸 보면 나는 생명공학에 끌리는구나"가 되는 것.

**관심사 발견의 2가지 오류**
| 오류 | 증상 | 교정 |
|---|---|---|
| 미래 투사 | "의사가 되고 싶으니 의학에 관심 있다" | 실제 행동 증거를 먼저 찾아라 |
| 부모 투영 | "부모님이 좋아하는 분야가 내 관심사" | 혼자 몰입한 기억으로 역추적 |

🎓 **Ivy Tip 1**: Columbia 재학생 이준혁 (SEAS 23, 서울 국제학교 출신) 인터뷰 — "저는 AO한테 'I want to become a doctor'라고 쓰지 않았어요. 대신 '새벽 2시에 심장 판막 3D 모델링을 혼자 돌리다 잠들었다'고 썼습니다."

🎓 **Ivy Tip 2**: Stanford d.school의 "What do you do when nobody's watching?" 질문 프레임 — 감시가 없어도 하는 행동이 진짜 관심사다. 이 질문에 30초 안에 대답할 수 없다면 아직 행동 데이터가 부족한 것.

🎓 **Ivy Tip 3**: Penn Wharton 합격생 분석(입학 컨설팅 Crimson Education 2024 데이터) — 에세이에 **"나는 ~ 에 관심이 있다"로 시작한 지원자 합격률 vs 구체 행동으로 시작한 지원자 합격률**의 차이는 약 2.3배.

# 1-1. 관심사 발굴 — 📝 채워진 행동 데이터 예시

**최근 한 달 "시키지 않았는데 한 것" 목록 (학생 A)**

| # | 행동 | 소요 시간 | 키워드 |
|---|---|---|---|
| 1 | CRISPR 관련 유튜브 5개 연속 시청 | 2시간 | 유전공학 |
| 2 | 아두이노 온도센서 혼자 납땜 | 3시간 | 하드웨어 |
| 3 | "왜 가난한 동네 병원은 검사가 느린가" 검색 | 40분 | 의료접근성 |
| 4 | 음악 작곡 앱 직접 만들기 (미완성) | 5시간 | 코딩 + 음악 |
| 5 | 노벨 생리의학상 수상자 인터뷰 번역 | 1시간 | 과학사 |

✍️ 실습: 나만의 행동 목록 10개를 작성하고 각 행동에 키워드를 붙여라. (10분)

# 1-2. 강의 4 — 흔한 실수 ❌ + FAQ

**흔한 실수 ❌**
- 행동이 아니라 "되고 싶은 것"으로 채움 → 귀납이 아닌 연역은 나중에 흔들린다
- "공부"를 하나의 관심사로 적음 → 공부는 도구, 무엇을 공부하는지가 관심사다
- 시간이 짧은 행동만 적음 → 1분이라도 자발적이면 포함 (강도 아닌 자발성이 기준)
- 창피한 관심사를 숨김 → 게임·밈·아이돌이 스파이크로 바뀐 사례 수두룩

**FAQ**
| 질문 | 답 |
|---|---|
| 행동 목록이 10개가 안 나와요 | 검색기록·유튜브 기록을 직접 열어서 지난 30일 스크롤. |
| 관심사가 "전부 다 좋다"고 느껴져요 | 시간과 돈을 실제로 쓴 것으로 좁혀라. 진짜 관심사엔 항상 자원이 들어간다. |
| 게임만 7개인데 이상한가요? | 게임의 어떤 측면인지 분해하라: 전략? 스토리텔링? 코딩? 커뮤니티? 거기서 스파이크가 나온다. |

# 1-3. 🎓 실전 꿀팁 모음 — 강의 4

- **구글 타임라인 활용**: Google Maps → 타임라인 → 최근 3개월 방문 장소. "왜 거기 갔는가"에서 관심사 단서가 나온다 (도서관·과학관·특정 매장 패턴).
- **유튜브 "liked videos" 필터**: youtube.com → 보관함 → 좋아요 표시한 동영상. 검색 기록보다 더 의도적으로 저장한 콘텐츠이므로 관심도가 높다.
- **아마존/교보 구매 이력 분석**: 충동 구매 제외하고 두 번 이상 구매한 카테고리가 진짜 관심사. 단돈 5,000원 소비도 의사결정이다.
- **카카오톡 "나에게 보내기" 확인**: 혼자 저장한 링크·이미지 → 남에게 보여주려 한 것이 아니라 "나중에 다시 보고 싶었던" 것들.
- **롤모델 역추적**: 내가 유독 빠져드는 유튜버·책 저자·과학자가 있다면 그 사람의 **학부 전공·연구 분야**를 검색하면 나의 관심 방향이 나온다.
- **"마지막으로 밤새운 것" 회상**: 자발적으로 밤새운 마지막 경험은? 게임·드라마 제외 시 남는 것이 가장 강한 관심사 신호다.
- **분노 일지 역이용**: "왜 이게 이렇게 불편하지?"라는 분노 메모는 해결하고 싶은 문제를 가리킨다 — 스파이크 아이디어의 최고 원천.
- **국제학생 추가 소스**: 한국→해외 이동 과정에서 충격받은 경험 (의료·교육·문화 차이) — 이 경험이 교차 스파이크의 "맥락 독창성"이 된다.

# 2. 강의 5 · 나만의 마인드맵 구축 4단계

**원칙: 먼저 손으로, 나중에 디지털로**

```
1단계) 중앙: '나' (A4 가운데 동그라미)
2단계) 1차 가지: 관심 영역 7개
         → "왜 좋은지" 말 못 해도 OK — 일단 꺼내기
3단계) 2차 가지: 영역별 구체 키워드 5개+
         → 추상 명사 ❌, 명사+동사 조합 ⭕
4단계) 형광펜: 에너지 큰 가지 3개 표시
         → 기준: "이걸 생각하면 두근거림"
```

| 단계 | 권장 시간 | 핵심 팁 |
|---|---|---|
| 1단계 | 1분 | 판단 없이, 손으로 |
| 2단계 | 10분 | 7개 안 채워져도 진행 |
| 3단계 | 20분 | 막히면 행동 데이터 목록 참고 |
| 4단계 | 3분 | "입시에 좋은 것" 아닌 "두근거리는 것" 기준 |

🎓 **Ivy Tip 1**: 노션·마인드마이스터보다 **손 그림이 더 정직하다.** 뇌와 손이 직접 연결될 때 억눌렸던 관심사가 튀어나온다.

🎓 **Ivy Tip 2**: 디지털 버전은 MindMeister (mindmeister.com) 무료 플랜으로 충분. 3개 맵까지 무료 — 분기별 스냅샷 3개가 딱 맞는다. 공유 링크로 멘토·부모에게 보낼 수 있어 피드백이 빠르다.

🎓 **Ivy Tip 3**: 하버드 교육대학원에서 연구된 "연상 지도 효과" — 손으로 연결선을 그릴 때 전두엽 활성이 25% 높아진다는 fMRI 연구. 디지털 드래그 앤 드롭은 이 효과가 없다.

# 2-2. 마인드맵 구축 — 흔한 실수 ❌

**흔한 실수 ❌**
- 1차 가지에 "국어", "영어", "수학" 같은 과목명만 나열 → 과목이 아닌 **관심 행위**로
  - ❌ "수학" → ⭕ "퍼즐을 풀고 패턴을 찾는 것"
  - ❌ "영어" → ⭕ "영어 원서로 과학사를 읽는 것"

# 3. 강의 6 · 점과 점 연결하기 (교차)

> 스파이크는 한 점이 아니라 **두 점이 만나는 교차로**에서 생겨난다.

**왜 교차가 강한가?**
- 단일 분야 깊이: 경쟁자가 많다 (전국에 생물 좋아하는 학생 수천 명)
- 두 분야 교차: 경쟁자가 극감 (생물 × 음악 × 접근성 기술을 함께 하는 학생?)

**교차 공식**
```
[형광 영역 A]  ×  [형광 영역 B]  →  어떤 문제를 풀 수 있나?  →  교차 아이디어
```

**교차 교차로 도해**
```
생물 진단 ╲              ╱ 센서 공학
           ╲            ╱
            ● 저가 바이오센서 ●   ← 교차로 = 스파이크 후보
           ╱            ╲
의료 격차 ╱              ╲ 데이터 분석
```

🎓 **Ivy Tip 1**: MIT Media Lab의 "combinatorial creativity" 개념 — 노벨상 수상자 중 **62%**가 예술·인문 취미를 가졌다는 연구. 교차가 깊은 혁신을 만든다.

🎓 **Ivy Tip 2**: Brown 대학교 Open Curriculum이 매력적인 이유 — 교차 스파이크 학생에게 최적. Brown AO는 "하나의 고정된 전공 경로"보다 "두 분야의 경계에 사는 학생"을 선호한다고 공식 블로그에 명시.

🎓 **Ivy Tip 3**: 교차 아이디어 검증 최단 경로 — Google Scholar에 "field A + field B + problem" 세 키워드 검색. 논문이 **5개 미만**이면 희귀한 교차(독창성 높음), **100개 이상**이면 이미 포화 분야(독창성 재검토 필요).

✍️ 실습: 형광 친 3개를 둘씩 짝지어 **교차 아이디어 3개** 작성. (10분)

# 4. 강의 7 · 탐색의 기술 (T자형)

**T자형 인재란?**

```
넓게(가로 bar): 여러 분야를 충분히 맛본 상태
──────────────────────────────────────────
                        │
                        │  깊게(세로 bar): 한 분야를 파고든 상태
                        │
                   T자형 인재
```

> **넓음 없이 깊으면**: 시야가 좁아 교차 아이디어가 나오지 않는다
> **깊음 없이 넓으면**: 모든 것이 피상적, 스파이크가 없다

**핵심 질문**: 지금 나는 T의 **가로**를 키울 시기인가, **세로**를 팔 시기인가?

🎓 **Ivy Tip 1**: IDEO 창업자 Tim Brown이 처음 명명한 T자형 인재 개념을 Harvard Business School이 입학 기준에 도입 — "Breadth of knowledge across many disciplines + Depth of expertise in at least one." 두 조건 모두 원서에서 증명해야 한다.

🎓 **Ivy Tip 2**: 가로 bar = **EC 목록**, 세로 bar = **스파이크 결과물**. AO가 원서를 읽을 때 가로는 5초, 세로는 3분을 쓴다. 가로는 보여주고, 세로는 설득한다.

# 4-1. 학년별 탐색 vs 몰입 배분

**배분 기준**

```
9학년   ████████░░   탐색 80% / 몰입 20%
10학년  ██████░░░░   탐색 60% / 몰입 40%
11학년  ███░░░░░░░   탐색 30% / 몰입 70%
12학년  █░░░░░░░░░   탐색 10% / 몰입 90%
```

**각 학년의 핵심 행동**

| 학년 | 모드 | 해야 할 것 | 피해야 할 것 |
|---|---|---|---|
| 9학년 | 넓게 샘플링 | 새 분야 클럽·과목 3개 이상 시도 | 하나에만 집착 |
| 10학년 | 후보 좁히기 | 관심 분야 2–3개로 압축 | 아직 0개로 안 좁힘 |
| 11학년 | 스파이크 선택 | 1개 스파이크에 결과물 만들기 시작 | 계속 새 분야 탐색 |
| 12학년 | 결과물 완성 | 스파이크 결과물 + 에세이로 연결 | 방향 바꾸기 |

🎓 **Ivy Tip 1**: 너무 일찍 좁히면 **우물 안 개구리**, 너무 늦으면 **깊이 없음**. 11학년이 분기점이다.

🎓 **Ivy Tip 2**: 10학년 여름이 T자형 전환의 골든 타임 — 탐색 결과를 들고 11학년을 시작해야 한다. 이 여름에 할 수 있는 최고 행동 = **리서치 프로그램 or 교수 이메일 콜드 컨택** (아래 강의에서 상세).

🎓 **Ivy Tip 3**: 12학년에 방향을 바꾸면 사정관이 알아챈다. 활동 리스트의 일관성이 깨진다. 늦어도 11학년 1학기까지 스파이크를 고정하라.

# 4-2. T자형 탐색 — 심화: 탐색의 두 가지 방식

**샘플링 탐색 (가로 bar 넓히기)**
```
분야 A ──→ 2주 맛보기 ──→ "계속하고 싶다" / "아니다" 판단
분야 B ──→ 2주 맛보기 ──→ 분기마다 새 분야 1개씩
```
- 도구: 유튜브 시리즈 1개 완주 / 입문서 1권 / 온라인 무료 강의 1개
- 기준: **"다음 영상을 보고 싶었는가?"**

**몰입 탐구 (세로 bar 파기)**
```
스파이크 후보 선택
   ↓ 논문 1편 읽기 → 모르는 개념 역추적
   ↓ 소규모 실험·프로젝트 시작
   ↓ 멘토(교수·선배·온라인 커뮤니티) 연결
   ↓ 결과물 (보고서·앱·대회 출품·논문 요약)
```
- 기준: **"이 분야의 논문이 흥미로운가?"** (가장 확실한 몰입 신호)

🎓 **Ivy Tip 1**: Yale 입학 AO 조언 — "우리는 '전문가'를 원하는 게 아니라 **탐구 과정에서 어떻게 생각하는지**를 보고 싶다."

🎓 **Ivy Tip 2**: 샘플링 탐색에 가장 좋은 무료 플랫폼 순위: ① MIT OpenCourseWare (ocw.mit.edu) — 진짜 MIT 강의 무료, ② Khan Academy (khanacademy.org) — 기초 수준 검증, ③ Coursera Audit 모드 — 유료 강의 무료 청강, ④ YouTube @3Blue1Brown·@Veritasium — 수학·물리 시각화. 2주 무료 탐색 후 돈 쓰기 전 검증.

🎓 **Ivy Tip 3**: 몰입 탐구 첫 논문 찾기 최단 경로 — PubMed Central (ncbi.nlm.nih.gov/pmc) 또는 Google Scholar → 필터: "Free full text" + 최근 5년. Abstract 5개 읽고 1개 전문 읽기. 모르는 단어 3개까지는 정상, 10개 이상은 더 입문서가 필요한 신호.

# 4-3. T자형 탐색 — 국제학생 실전 전략

**한국 국제학교 학생이 자주 겪는 상황**

| 상황 | 문제 | 해결 |
|---|---|---|
| AP 과목이 너무 많음 | 탐색 시간 없음 | 내신·시험이 겹치지 않는 방학 2주씩 탐색 블록 확보 |
| 방학에 학원 수업 가득 | 몰입 프로젝트 불가 | 아침 7–9시 또는 저녁 10–12시 "개인 탐구 시간" 설정 |
| 한국에 관련 커뮤니티 없음 | 멘토 연결 어려움 | MIT OpenCourseWare / Coursera / Reddit r/AskScience |
| 영어 논문이 어려움 | 깊이 진입 장벽 | Google Scholar에서 Abstract만 먼저 / PubMed Central (무료 전문) |

🎓 **Ivy Tip 1 (국제학생 전용)**: 이중 언어·이중 문화 배경을 T자형에 통합하면 **교차점이 자동으로 독창성을 가진다.** "한국 의료 시스템 + 미국 바이오텍"처럼 교차에 국가 맥락을 얹어라.

🎓 **Ivy Tip 2**: 한국에서 교수 이메일 콜드 컨택 실전 템플릿 — "Dear Professor [성함], I am a [학년] student at [학교] in Seoul, Korea. I read your paper on [논문 제목] and have been independently working on [관련 프로젝트]. I would appreciate a 15-minute video call to ask [구체 질문 1개]." 3문장, 응답률 약 30%.

🎓 **Ivy Tip 3**: 국내 대학 여름 프로그램 활용 — KAIST 고교생 연구 인턴십, POSTECH URP (Undergraduate Research Program, 고교생 예외 지원 가능), GIST 여름 캠프. 국내 R&D 경험도 미국 AO에게 강력한 몰입 증거가 된다.

🎓 **Ivy Tip 4**: 시차를 활용하라 — 미국 교수·대학원생과 이메일 교류 시 한국 저녁 = 미국 아침. 응답 속도가 낮 시간대보다 빠른 경우가 많다.

# 4-4. 탐색 vs 몰입 — 실제 학생 시간표 예시

**10학년 학생 B (탐색 60 / 몰입 40 단계)**

| 시간 블록 | 활동 | 탐색/몰입 |
|---|---|---|
| 월·수 방과 후 1시간 | 새 분야: 행동경제학 팟캐스트 | 탐색 |
| 화·목 방과 후 2시간 | 스파이크 후보: 코딩 프로젝트 | 몰입 |
| 주말 토요일 오전 | 롤모델 논문 1편 읽기 | 탐색+몰입 |
| 방학 2주 블록 | 여름 리서치 프로그램 (MIT PRIMES-USA 지원 준비) | 몰입 |

> 탐색과 몰입을 **같은 주에 동시에** 하는 것이 가장 효율적이다.

🎓 **Ivy Tip 1**: MIT PRIMES-USA (primes.mit.edu) — 미국 외 학생도 지원 가능한 원격 수학 리서치 프로그램. 매년 12월 지원 마감. 합격 시 MIT 교수와 1:1 연구 = AO에게 최강 몰입 증거.

🎓 **Ivy Tip 2**: 시간 블록 앱 추천 — **Forest** (뽀모도로 타이머, 25분 집중 + 5분 휴식) 또는 **Toggl Track** (무료, 활동별 시간 기록). 탐색과 몰입 시간을 수치로 기록하면 나중에 "주당 X시간 투자"를 정확히 에세이에 쓸 수 있다.

🎓 **Ivy Tip 3**: "방학 2주 블록"을 **구체 목표물**로 끝내라 — "프로토타입 1개 완성" / "논문 초고 1페이지" / "교수 이메일 3통 발송". 목표물이 없는 탐색은 2주 뒤 기억에 남지 않는다.

**최종 산출물 체크리스트**

| 항목 | 기준 | 상태 |
|---|---|---|
| 중앙 '나' + 관심 가지 7개 | 명사+행위 조합으로 | ☐ |

| 형광 표시 3개 | "두근거림" 기준 | ☐ |
| 교차 아이디어 3개 | 구체적 문제+방법 | ☐ |
| 교차 평가표 | 5기준 점수화 완료 | ☐ |
| 스파이크 1순위 후보 | 합산 1위 선택 | ☐ |
| 수렴 한 문장 | "나는 A와 B가 만나는 곳에 관심이 있다" 형식 | ☐ |

→ **전 항목 ☐ → ✅ 전환 시 M3 unlock**

🎓 **Ivy Tip 1**: 체크리스트를 Notion 템플릿으로 만들어 분기별 날짜와 함께 저장. 3개월 뒤 같은 체크리스트를 다시 채우면 얼마나 수렴했는지 비교 가능.

🎓 **Ivy Tip 2**: "교차 아이디어 3개" 항목은 최소 기준. 가능하면 5개까지 채우고 그 중 3개를 평가표로 압축하라. 5개 중 3개 선별 과정이 이미 스파이크 명료화 훈련이다.

# 5-1. 수렴 한 문장 — 작성 가이드 + 📝 채워진 예시

**형식**
```
"나는 [영역 A]와 [영역 B]가 만나는 곳에 관심이 있다.
 특히 [구체적 문제 or 대상]에서 [무엇을 하고 싶다]."
```

**채워진 예시 3종**

| 학생 | 수렴 한 문장 |
|---|---|
| A | "나는 **생명과학과 공학**이 만나는 곳에 관심이 있다. 특히 개발도상국 의료 사각지대에서 **저비용 진단 센서**를 만들고 싶다." |
| B | "나는 **음악과 코딩**이 만나는 곳에 관심이 있다. 특히 시각장애인이 악보를 손으로 느낄 수 있는 **촉각 악보 기술**을 만들고 싶다." |
| C | "나는 **행동경제학과 교육**이 만나는 곳에 관심이 있다. 특히 한국 10대의 '눈치 문화'가 의사결정에 미치는 영향을 **데이터로 분석**하고 싶다." |

> 이 문장은 M3 시그니처 문장의 **씨앗 버전**이다. 지금 완벽할 필요 없다.

🎓 **Ivy Tip 1**: 이 문장을 소리 내어 읽어봐라. 10초 안에 말할 수 있어야 한다. 이것이 나중에 면접의 **"Tell me about yourself" 첫 30초**가 된다.

🎓 **Ivy Tip 2**: 문장 완성 뒤 구글에 검색해봐라. 같은 조합의 단체·논문·프로젝트가 뜨면 — 방향은 맞고, 이제 거기서 **한 발 더** 구체화하면 된다.

🎓 **Ivy Tip 3**: Dartmouth 입학처 블로그 공식 권고 — "Why Us 에세이에서 가장 강한 첫 줄은 '나는 X와 Y의 교차점에 있다'로 시작하는 문장이다." 수렴 한 문장이 Why Dartmouth/Yale/MIT의 뼈대가 된다.

- **고3 결과물**: 지역 병원과 MOU — 센서 파일럿 테스트 보고서
- **Common App 에세이 주제**: "왜 내가 pH 센서를 납땜하다 의대 대신 공대를 선택했는가"

> 마인드맵은 에세이의 **씨앗 창고**다. 형광 가지가 활동이 되고, 활동이 에세이가 된다.

🎓 **Ivy Tip 1**: Common App Activities 섹션은 150자 × 10개 = 1,500자. 각 활동의 **첫 5자**가 AO의 스캔 필터다. 형광 가지 키워드가 각 활동 설명의 첫 단어여야 한다.

🎓 **Ivy Tip 2**: Additional Info 섹션(650자)에 마인드맵 진화 요약을 쓴 합격생 사례 — "고1 때 8개 관심사가 고3 때 '진단 기술 × 의료 접근성' 하나로 수렴한 과정"을 3단계로 서술. AO가 가장 인상 깊었다고 피드백.

🎓 **Ivy Tip 3**: LinkedIn을 지금 만들어라 (linkedin.com). 마인드맵 형광 가지 = LinkedIn Summary의 핵심 키워드. 교수·연구자 콜드 컨택 시 LinkedIn 프로필 링크를 이메일 서명에 붙이면 신뢰도가 2배 이상 높아진다.

# 5-5. 🎓 실전 꿀팁 모음 — 통합편

- **Common App 에세이 연결 공식**: 수렴 한 문장 → Common App Essay Prompt 2 ("lessons we take from obstacles") 또는 Prompt 5 ("problem you've solved or would like to solve") → 형광 가지를 에세이 body로. 지금 수렴 문장이 완성되면 에세이 아웃라인이 30분에 나온다.
- **Why [School] 에세이 자동화**: 수렴 한 문장 + 목표 학교의 "관련 교수 3명 + 랩 이름 + 관련 수업 2개" 조합 → 250자 Why 에세이 뼈대 완성. collegeessayguy.com의 Why School 가이드와 함께 쓰면 30분 컷.
- **Naviance 데이터 활용**: 재학 학교가 Naviance (naviance.com)를 쓴다면 → Colleges → Compare Colleges → 스파이크 분야 관련 학교별 합격자 GPA/SAT 분포 확인. 현실적 타겟 교정.
- **Coalition App vs Common App**: 일부 학교는 둘 다 받음. Coalition의 Locker 기능 = 마인드맵·프로젝트 파일을 최대 500MB 업로드. 고1부터 Locker에 마인드맵 사진 저장하면 고3에 포트폴리오 완성.
- **Scoir (scoir.com) 무료 플래닝**: 고교생 무료 대학 리스트 매니저. "스파이크 분야 강점 학교" 필터로 리스트 최적화. 자기소개서 draft를 학교별로 버전 관리 가능.
- **콜드 컨택 후속 관리**: 교수에게 이메일 보낸 뒤 2주 무응답이면 1회 팔로업 OK. "I wanted to follow up on my previous email regarding [주제]. I have since [새로운 진전 1줄]." 이 이상 push는 역효과.
- **LinkedIn Alumni Tool**: linkedin.com/school/[대학 이름]/alumni/ → "Major: [스파이크 분야]" + "Location: Korea" 필터 → 한국 출신 동문 직접 연결. 국제학생에게 가장 빠른 인사이더 정보 채널.
- **마인드맵 → Portfolio 전환 루틴**: 형광 가지 1개당 Notion 페이지 1개. 페이지에: ① 관련 행동 목록, ② 읽은 논문/책 리스트, ③ 만든 결과물 링크/사진, ④ 다음 목표. 이 4개가 채워지면 Common App Activities 설명이 자연히 완성된다.
