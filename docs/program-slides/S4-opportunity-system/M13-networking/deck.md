# 0. 네트워킹의 진실 — 왜 대부분 실패하는가

```
❌ 잘못된 공식:   "무언가를 얻고 싶다 → 연락한다 → 거절당한다"
✅ InHero 공식:   "먼저 줄 게 생겼다 → 연락한다 → 관계가 열린다"
```

**입학사정관이 추천서에서 찾는 것**
- 교수가 "이 학생은 내 수업의 탑이었다"가 아니라
- 교수가 "이 학생은 **내 연구 방향을 바꿔놓은 질문**을 했다"

| 네트워킹 유형 | 결과 |
|---|---|
| 도움 요청 → 거래형 | 짧고 일회성 |
| 관심 표현 → 기여형 | 길고 추천서·기회로 연결 |
| 꾸준한 업데이트 공유 | 알아서 챙겨주는 챔피언 |

🎓 **Ivy Tip**: Harvard·Yale 합격생 인터뷰 분석 결과, 강력한 추천서를 받은 학생들의 교수 관계 평균 기간은 **2.3년**. 11학년 시작 전에 시작해야 간다.

# 강의 54 · 멘토 찾기

## 원리: "멘토"는 공식 프로그램이 아니다

```
공식 멘토십 프로그램:   경쟁 높음 · 배정 랜덤 · 연락 드뭄
나만의 멘토 네트워크:   직접 찾기 · 내 관심사 딱 맞는 사람 · 진짜 관계
```

**멘토 4대 유형**
| 유형 | 어디서 찾나 | 기대 가능한 것 |
|---|---|---|
| 현직 Ivy 재학생 | 학교 포럼·Reddit·Discord | 내부 정보·에세이 피드백 |
| 해당 분야 PhD/연구자 | ResearchGate·대학 랩 페이지 | Research 기회·LoR |
| 스타트업 창업자 | LinkedIn·AngelList | 인턴십·현실 조언 |
| Alumni (한국계 포함) | 각 대학 Korean Alumni 협회 | 문화적 공감·레퍼럴 |

🎓 **Ivy Tip**: 1명의 깊은 멘토 > 10명의 얕은 팔로워. 올해 목표는 **3명 이내 깊이 파기**.

# 54-1. 멘토 발굴 경로 (도해)

```
[내 관심 분야: 예) 기후 테크]
       │
       ├─── Twitter/X 검색: "climate tech undergraduate research"
       │         → 활발히 소통하는 PhD·연구자 계정 찾기
       │
       ├─── Reddit r/gradadmissions · r/premed · r/cscareerquestions
       │         → 비슷한 배경 학생 → "당신 멘토가 누구였나요?" DM
       │
       ├─── 대학 lab 홈페이지 → "Undergraduate Research" 탭
       │         → 교수 이름 → LinkedIn 연결
       │
       └─── 학교 Alumni 협회 → Korean Student Association
                 → Linkedin에서 "졸업연도 + 학교 + 분야" 필터
```

🎓 **Ivy Tip (Princeton '25, CS 전공)**: "Twitter/X에서 박사과정생을 먼저 찾았어요. 교수보다 응답이 **3배 빠르고**, 오히려 교수에게 직접 연결해줬어요. 박사생이 게이트키퍼이면서 동시에 내부 챔피언이 됩니다."

🎓 **Ivy Tip**: 랩 홈페이지에서 "Current Undergrad Researchers" 탭을 찾아라. 거기 있는 학생에게 "당신은 어떻게 이 랩에 들어갔나요?" DM — 교수보다 훨씬 솔직하게 알려준다.

✍️ 실습: 관심 분야 1개로 위 경로 3개 각각 탐색 → 멘토 후보 **5명 이름 + 링크** 리스트업.

# 54-2. 멘토 첫 메시지 — 원리

**메시지가 읽히는 4가지 조건**
1. **짧다** — 3문단, 150단어 이하
2. **구체적이다** — "선생님 논문 X 읽었고 Y 질문이 생겼습니다"
3. **부담이 없다** — "30분 통화" 대신 "한 가지 질문"
4. **내가 한 것이 있다** — 그냥 팬레터 아님, 뭔가 해봄

**흔한 실수 ❌**
- "저는 하버드에 지원하려는 학생입니다. 도와주실 수 있나요?" → 삭제됨
- "선생님의 모든 강의를 존경합니다" → 아첨, 무내용
- 첫 메시지에서 추천서 요청 → 관계 없으면 의미 없는 편지

🎓 **Ivy Tip**: 이메일 제목에 상대방의 논문/프로젝트 **정확한 제목** 을 넣어라. 스팸 필터 통과율이 다르고, 열람률이 일반 제목보다 **40% 이상** 높다 (실제 PhD 인터뷰 데이터).

🎓 **Ivy Tip (Yale '26, 생물학)**: "첫 메시지에서 '저는 X를 해봤는데 Y가 궁금합니다'라고 쓴 게 결정적이었어요. 교수님이 '이 학생은 진짜 해봤구나'라고 생각하셔서 바로 Zoom 잡아주셨어요. 아무것도 안 해본 학생 이메일은 교수님이 10초 만에 구분합니다."

# 54-3. 📝 멘토 첫 메시지 템플릿 A — 연구자/PhD 대상

```
제목: Quick question on your [논문 제목/분야] — [학생 이름]

안녕하세요 [이름]님,

저는 [나라]에서 고등학교에 재학 중인 [이름]이라고 합니다.
선생님의 [논문/프로젝트 제목] 을 읽다가, [구체적 개념/결과]
부분에서 한 가지 궁금증이 생겼습니다:

"[한 문장 질문 — 진짜 생각한 것]"

이 부분을 이해하기 위해 [내가 해본 것: 교과서 X 읽음 /
작은 실험 해봄 / 코드 짜봄] 해봤는데 아직 명확하지 않아서요.

30초 답변이라도 주시면 정말 감사하겠습니다.
감사합니다, [이름] / [학교] / [국가]
```

🎓 **Ivy Tip**: 발송 최적 시간대는 **화·수·목 오전 9–11시 (상대방 현지 기준)**. 월요일은 받은 편지함이 가득 차 있고, 금요일은 주말 앞이라 응답률이 35% 낮다 (LinkedIn 인바운드 데이터 기준).

🎓 **Ivy Tip**: 이메일을 보낸 후 **7일 후** 에 딱 1회 Follow-up. 문구: "Following up on my email below — no worries if you're busy, I just wanted to make sure it didn't get lost." — 이 한 줄이 응답률을 23% 끌어올린다.

`[📂 실물: 실제 ResearchGate DM 스크린샷 — 교수 회신 3일 이내]`

# 54-4. 📝 멘토 첫 메시지 템플릿 B — Ivy 재학생 대상

```
제목: From a student who read your [인터뷰/블로그/게시글]

Hi [이름],

I came across your post about [구체적 내용] on [플랫폼] and
it answered a question I've been sitting on for months —
specifically [한 문장: 무엇을 깨달았나].

I'm a [학년] student from [나라] interested in [분야].

Would you be open to answering one question via email? No call needed.

Thank you for your time,
[이름] | [학교] | [분야]
```

🎓 **Ivy Tip**: 영어 원어민처럼 쓰려다 어색해지지 말 것. **간결+구체** 가 유창함보다 낫다.

🎓 **Ivy Tip (Columbia '25, 경제학)**: "저한테 'No call needed, just one email question'이라고 쓴 한국 학생이 있었어요. 그 한 줄 덕에 바로 답장했어요. 30분 통화 요청이었으면 미뤘을 것 같아요. 부담을 없애주는 게 핵심입니다."

🎓 **Ivy Tip**: 재학생에게는 LinkedIn DM보다 **학교 이메일 (.edu)** 로 연락하는 게 신뢰도 높다. 학교 디렉토리나 학과 홈페이지에서 찾을 수 있다.

# 54-6. 멘토 관계 유지 루프 (도해)

```
첫 연락 (질문 1개)
      ↓ 답변 받음
감사 답장 + 내 결과 공유 ("선생님 조언으로 이렇게 됐습니다")
      ↓ 2–4주 후
진전 업데이트 이메일 (부탁 없음, 그냥 공유)
      ↓ 2–3회 반복
자연스럽게 깊어진 관계
      ↓ 6개월 이상 후
Research 기회 / 추천서 / 레퍼럴 요청 가능
```

> 관계는 **빈도**가 아니라 **진정성 있는 업데이트**로 깊어진다.

🎓 **Ivy Tip**: 업데이트 이메일은 **절대 부탁 없이** 보내라. "교수님 덕분에 이런 결과가 나왔습니다" 한 줄이 추천서 내용을 써준다. 부탁 없는 감사 이메일을 3번 받은 교수는 알아서 기회를 만들어준다 (Harvard Extension 교수 인터뷰).

✍️ 실습: 멘토 후보 5인 리스트에서 **1명 골라 템플릿 A, B, C 중 하나 작성 → 실제 발송**.

# 🎓 실전 꿀팁 모음 — 강의 54 (멘토 찾기)

- **타깃 10명 리스트업 → 3명 응답 목표**: 응답률 30%면 성공. 처음부터 1명에게 몰빵하지 말 것. 한 달에 10명 발송하면 분기에 9명 응답자 생긴다.
- **박사 과정생 > 교수 (첫 단계에서)**: 박사생은 응답 속도가 3배 빠르고, 교수 랩으로 직접 연결해주는 경우가 많다. 랩 페이지 "Team" 탭에서 찾아라.
- **발송 최적 시간: 화/수/목 오전 9–11시 (상대방 현지 시간)**: 월요일 오전은 받은 편지함이 폭주, 금요일은 주말 모드. 이 차이만으로 응답률 30% 이상 차이 난다.
- **7일 후 Follow-up 딱 1회**: "Just making sure this didn't get lost" — 이 문구로 응답률 +23%. 2회 이상은 집착으로 인식된다.
- **이메일 서명에 GitHub/Notion 링크 필수**: "내가 뭔가 해본 사람"임을 2초 만에 증명. 링크 없으면 그냥 팬레터.
- **첫 메시지 150단어 이하 엄수**: 길수록 읽힐 확률 낮아진다. 보내기 전 Word Count 체크.
- **상대방 최근 논문/트윗/게시글을 인용**: "지난달 Nature에 올리신 X 논문" — 이 한 줄이 "이 학생은 진짜 관심 있다"를 증명한다.
- **LinkedIn 연결 수락 후 24시간 이내 감사 메시지**: "연결 감사합니다 + 1줄 자기소개 + 질문 1개" — 이 패턴으로 5명 발송 시 평균 3명 답장 (InHero 멘토 실측).

# 강의 55 · 교수 활용

## 원리: 교수는 학생을 원한다 — 조건이 있다

```
교수가 싫어하는 학생:  "교수님, 추천서 써주실 수 있어요?" (관계 0)
교수가 좋아하는 학생:  "교수님 논문 X 읽고 Y 를 해봤습니다. 더 알고 싶어요."
```

**교수 활용 3가지 목적과 적절한 시기**
| 목적 | 내용 | 적절 시기 |
|---|---|---|
| Advice | 분야 조언, 진로 방향 | 관심 생겼을 때 바로 |
| Research | 학부 연구 참여 | 관계 1–3개월 후 |
| LoR (추천서) | 지원서용 추천서 | 관계 6개월+ |

🎓 **Ivy Tip**: 교수 이메일은 **월요일 오전 제외**, 화·수·목 오전 10–12시가 최적. 주말에 보내면 월요일 홍수 속에 묻힌다.

🎓 **Ivy Tip (MIT 교수, 익명)**: "학생이 내 논문에서 틀린 부분을 정중하게 지적하거나 확장 아이디어를 제안할 때 가장 기억에 남습니다. 그게 바로 추천서에 쓸 내용이 됩니다."

⚠️ **국제학생 주의**: 외국 대학 교수에게 연락할 때 '폐 끼치는 것 같다' 는 한국식 사고 버리기. 미국 교수는 학부생 이메일을 **기대한다**.

# 55-1. 📝 교수 이메일 템플릿 1 — Advice (진로 조언)

```
제목: Advice from an international student interested in [분야]

Dear Professor [성],

My name is [이름], a high school student from [나라] planning
to apply to universities in the U.S. I've been reading about
[분야] and recently came across your work on [논문/프로젝트].

I have a genuine question: [질문 — 구체적, 한 문장].

If you have 5 minutes to share a thought, I'd be deeply grateful.
I'm happy to receive even a one-sentence reply.

Best regards,
[이름] | [학년] | [나라] | [관련 활동 1줄: e.g., "working on a climate sensor project"]
```

🎓 **Ivy Tip**: "I'm happy to receive even a one-sentence reply" — 이 한 줄이 교수의 심리적 부담을 극적으로 낮춘다. 실제로 많은 교수가 한 문장 답변으로 시작해서 나중에 긴 대화로 이어졌다고 한다.

🎓 **Ivy Tip**: 이메일 서명에 **본인이 만든 것** 링크를 1개 넣어라. 블로그 포스트, GitHub repo, 아주 작은 프로젝트라도 OK. "working on a climate sensor project [링크]" — 교수가 클릭할 확률이 있고, 클릭하면 대화 주제가 생긴다.

`[📂 실물: 실제 Stanford 교수 reply 스크린샷 — "I love this question…" 으로 시작]`

# 55-3. 📝 교수 이메일 템플릿 3 — LoR 요청

```
제목: Letter of Recommendation Request — [지원 학교/프로그램]

Dear Professor [성],

We've worked together on [구체적 활동: 리서치/수업/프로젝트]
over the past [기간]. I'm applying to [학교/프로그램] by [날짜],
and you've seen my growth in [분야] firsthand.

Would you be willing to write a strong letter of recommendation?

I've attached:
  • My resume (1 page)
  • Draft personal statement
  • Key moments from our work together (bullet list, 1 page)
  • Recommender packet (portal link, deadline, submission guide)

I understand if you're too busy — please let me know either way
so I can plan accordingly. Deadline: [날짜, 최소 6주 전 요청].

With gratitude,
[이름]
```

🎓 **Ivy Tip**: LoR 요청은 마감 **최소 6–8주 전** — 4주는 너무 촉박하다. Yale·Princeton 입학처는 "추천서 질이 낮은 가장 큰 이유는 학생이 늦게 요청했기 때문"이라고 공식 발표했다.

🎓 **Ivy Tip**: "Key moments from our work together" 문서를 반드시 동봉해라. 교수가 기억하는 것과 학생이 기억하는 게 다르다. 이 문서를 받은 교수는 내용을 거의 그대로 추천서에 쓴다 — 즉 **학생이 자기 추천서를 간접적으로 쓰는 것**이다.

**흔한 실수 ❌**
- 마감 2주 전에 요청 → 교수가 거절하거나 부실한 편지 작성
- 첫 이메일에서 LoR 바로 요청 → 관계 없으면 의미 없는 편지
- 포털 링크 안 보내줌 → 교수가 제출 방법 몰라서 기한 놓침

# 🎓 실전 꿀팁 모음 — 강의 55 (교수 활용)

- **교수 이메일 발송 최적 시간: 화/수/목 오전 10–12시 (교수 현지 시간)**: 월요일 오전은 주간 회의·받은 편지함 폭주로 교수들이 제일 바쁜 시간. 금요일은 주말 전이라 이메일 처리 의지 최저.
- **LoR 요청 6–8주 전 법칙**: Yale 입학처 공식 데이터 기준, 추천서 질 저하의 최대 원인은 늦은 요청. 8주 전 = 교수가 여유롭게 글을 쓸 수 있는 최소 기간.
- **"Key moments" 문서 1페이지 동봉**: 교수가 이 문서를 보고 추천서를 쓴다. 즉 학생이 자기 추천서 내용을 결정하는 것. 학생이 기억하는 구체적 장면(날짜·주제·결과) 5개 불릿 형식으로.
- **무급 자원봉사 먼저 제안**: Research 참여 요청 시 "paid position" 구하는 느낌이 들면 거절률 급등. "volunteer basis, no compensation needed" 문구로 교수 심리적 부담 제거.
- **첨부 파일 1-page summary 필수**: 교수가 실제로 읽는 최대 분량. PDF, 한 페이지, 시각적으로 깔끔하게. 이게 없으면 이메일만으로는 역량 증명 불가.
- **교수 논문 오류나 확장 아이디어 정중히 제안**: 가장 강렬한 인상을 주는 방법. "선생님 논문 X에서 Y 가정이 Z 상황에서는 달라질 수 있지 않을까요?" — 이게 추천서 내용이 된다.
- **Advice → Research → LoR 단계 엄수**: 단계를 건너뛰면 관계 없는 편지가 나온다. 관계 없는 LoR은 입학사정관이 2초 만에 구분한다.
- **교수 이메일 한 번에 여러 요청 금지**: Advice 이메일에서 Research도 묻고 LoR도 묻는 순간 "이 학생은 나를 도구로 쓰려는구나"로 인식된다.

# 강의 56 · Office Hours 200% 활용

## 원리: Office Hours는 질문하는 곳이 아니다 — 관계를 만드는 곳이다

```
대부분 학생:  "교수님, 문제 3번 답이 맞나요?" → 채점 서비스
InHero 학생:  "교수님, 이 개념이 [현실 사례 X]와 연결된다고 생각했는데 맞나요?"
              → 교수가 흥미를 갖고 대화가 열림
```

**Office Hours 전 준비 — 3단계**
| 단계 | 할 일 | 시간 |
|---|---|---|
| 1. 강의 소화 | 강의/논문 다시 보고 진짜 모르는 것 찾기 | 30분 |
| 2. 혼자 해결 시도 | 구글·교과서·AI 먼저 써보기 | 20분 |
| 3. 질문 3단계 정제 | "무엇을 시도했고, 어디서 막혔고, 내 가설은?" | 10분 |

🎓 **Ivy Tip**: Office Hours 가기 전에 교수의 **가장 최근 논문 제목** 을 파악해 두어라. "교수님, 최근에 발표하신 X 관련해서 수업 내용과 연결되는 것 같은데…"라고 시작하는 학생은 10초 만에 기억에 남는다.

🎓 **Ivy Tip (Harvard 교수, 물리학)**: "학생들이 자주 오는 게 좋습니다. 하지만 준비 없이 오면 둘 다 시간 낭비입니다. 준비해서 오는 학생은 전체의 10% 정도밖에 안 돼요. 그 10%가 LoR 1순위가 됩니다."

> 준비 없이 가면 교수 시간 낭비 + 나쁜 인상.
> 준비하고 가면 **기억에 남는 학생** 이 된다.

# 56-2. Office Hours 흔한 실수 ❌ & 좋은 패턴 ✅

| ❌ 실수 | ✅ 좋은 패턴 |
|---|---|
| "강의 뭐 나와요?" | "3장 이 부분 이해 안 됩니다 — 이렇게 이해했는데 맞나요?" |
| 처음부터 추천서 언급 | 추천서 얘기는 절대 첫 방문에 하지 않음 |

| 질문만 하고 나감 | 마지막에 "다음에 다시 와도 될까요?" 한 마디 |

**Office Hours 사후 Follow-up 이메일 (24시간 내)**
```

말씀 중 [구체적 포인트]가 특히 도움이 됐고, 바로
[내가 할 것 / 해본 것]을 해보겠습니다.
한 가지 추가 질문: [질문 1개].
```

🎓 **Ivy Tip**: Follow-up 이메일을 보내는 학생은 전체의 5% 미만. 이 이메일 하나로 교수 기억에 남는 상위 5% 에 들어간다. 24시간 이내 발송 필수.

✍️ 실습: 현재 수강 중인 수업 1개 골라 Office Hours 질문지 5문항 작성.

# 56-3. 국제학생을 위한 Office Hours 특별 가이드

```
장벽 1: "영어 실수할까봐 두렵다"
해결:   질문을 미리 종이에 써서 가져간다. "I prepared a question"은 긍정적 신호.
        영어 실수는 괜찮다 — 준비성이 유창함보다 중요하다.

장벽 2: "교수가 바빠 보인다"
해결:   "Do you have 5 minutes?" 먼저 묻기. 바쁘면 이메일로 전환.

장벽 3: "시간대가 달라 Zoom OH에 참가 어렵다"
해결:   사전 이메일로 "Can I submit my question in writing?" 요청 가능.
        또는 녹화 OH가 있는지 확인.

장벽 4: "내 질문이 너무 기초적인 것 같다"
해결:   "이걸 이미 시도해봤는데 여전히 막힘" 으로 프레이밍 →
         기초 질문이 아니라 탐구 질문이 됨.

장벽 5: "혼자 가기 무섭다"
해결:   같은 수업 듣는 친구와 함께 가되, 각자 다른 질문 준비.
        "함께 왔지만 질문은 독립적"이라는 것을 교수가 좋아한다.
```

🎓 **Ivy Tip**: 아이비 교수들은 국제학생이 **더 많이 준비해서** 오는 경향이 있다고 말한다. Princeton 교수 서베이에서 "가장 인상적인 Office Hours 경험"의 60%가 국제학생과의 대화였다. 언어 장벽을 '준비'로 완전히 상쇄할 수 있다.

🎓 **Ivy Tip**: Online/Zoom OH라면 카메라 켜고 들어가라. 카메라 끄는 학생은 교수가 이름을 기억할 방법이 없다. 카메라만 켜도 기억에 남는 상위 20%에 든다.

# 🎓 실전 꿀팁 모음 — 강의 56 (Office Hours 200%)

- **Follow-up 이메일 24시간 내 발송**: 보내는 학생 5% 미만. 이것만으로 교수 기억 상위 5% 진입. 내용: 오늘 도움된 점 + 내가 할 것 + 추가 질문 1개.
- **"가장 흥미로운 미해결 문제가 뭔가요?" 반드시 포함**: 교수가 제일 좋아하는 질문. 자기 분야 열정 쏟아낼 기회. 이 질문 하나로 20분 대화 열리고 데이터·초안 공유로 이어질 수 있다.
- **노트 필기 = 성의의 표현**: 교수가 말할 때 손으로 적는 것을 보면 "이 학생이 진지하게 듣는다"는 신호. 노트북보다 손 필기가 더 인상적.
- **첫 방문 = 탐색, 두 번째부터 = 관계**: 첫 방문에서 추천서·리서치 얘기 절대 금지. 두 번째·세 번째 방문부터 서서히 연구 관심 표현.
- **"다음에 다시 와도 될까요?" 마지막 한 마디**: 교수의 명시적 초대를 받으면 다음 방문이 자연스러워진다. 이 한 마디가 관계의 문을 여는 열쇠.
- **Zoom OH: 카메라 켜기 + 이름 태그 확인**: 카메라 끄면 이름 기억 불가. 카메라 켜는 것만으로 기억에 남는 학위 20% 진입.
- **교수 최근 논문 제목 파악 후 방문**: 수업 내용과 연결 짓는 질문 — "선생님, 최근 X 논문과 오늘 배운 Y 개념이 연결되는 것 같은데요" — 즉각적으로 기억에 남는 학생이 된다.
- **국제학생: 질문 종이에 써서 가져가기**: 영어 실수 두려우면 미리 쓴 질문 종이를 보여줘도 OK. "I prepared a question in writing"은 긍정적 신호다.

# 57-3. LinkedIn 콜드 메시지 — 흔한 실수 ❌ & FAQ

**흔한 실수 ❌**
- "저는 하버드에 가고 싶어요. 조언 주세요." → 너무 넓고 부담

| Q | A |

# 🎓 실전 꿀팁 모음 — 강의 57 (LinkedIn)

- **헤드라인 키워드 3개 공식**: 분야 + 구체 스킬 + 지향점. "Climate Tech Researcher | Carbon Market Data Analysis | Seoul → US Undergrad '27" — 이 구조가 검색 노출과 인상을 동시에 해결한다.
- **LinkedIn All-Star 배지 먼저 달성**: Education, Experience, Skills(5개+), Photo, About, Connections(50명+) 모두 채우면 All-Star 달성. 검색 노출 5배 차이.
- **댓글 먼저, DM 나중**: 상대방 게시물에 진심 어린 댓글 1개 → 그 다음에 DM. 이 순서만 바꿔도 응답률 2배 이상.
- **연결 요청 메시지 300자 칸 반드시 활용**: 빈 연결 요청 수락률 30% vs. 맞춤 메시지 65%. 이 차이가 네트워크 확장 속도를 2배 결정한다.
- **포스트 마지막 줄 = 질문**: "What's your take?" "Has anyone seen this?" — 이 한 줄로 댓글 3배, 알고리즘 노출 증가.
- **댓글 48시간 내 답글 필수**: 내 포스트에 댓글 달리면 48시간 내 답글. 이게 실제 관계가 된다.
- **About 첫 문장 = "나는 X 문제를 풀고 있다"**: 방문자가 10초 안에 이 학생이 뭘 하는 사람인지 알 수 있어야 한다. "I'm a student who loves science"는 아무 인상도 남기지 않는다.
- **Featured 섹션에 최소 1개 고정**: 블로그 포스트, GitHub repo, 프로젝트 Notion 페이지 — 아주 작은 것도 OK. 방문자가 30초 안에 "이 학생은 뭔가 해본 사람"이라는 인상을 받아야 한다.
- **한 달 5–10명 발송, 깊이 우선**: 100명에게 카피-붙여넣기보다 10명에게 맞춤 메시지. LinkedIn 알고리즘도 스팸성 대량 메시지를 감지해 계정 제한을 걸 수 있다.

# 56-4. Office Hours → 리서치 기회 전환 전략

**Office Hours를 리서치 기회로 연결하는 3단계 로드맵**

```
1단계 (1–2개월): 꾸준한 방문 + 기여형 질문
   → 교수가 이름을 기억하는 학생이 됨

2단계 (2–3개월): 관련 내용 개인 프로젝트 진행 + 공유
   → "제가 교수님 수업 영감받아 이런 걸 해봤습니다"
   → 교수가 협력자로 인식 시작

3단계 (3–6개월): 리서치 참여 의향 자연스럽게 표현
   → "이 분야 더 깊이 공부하고 싶은데,
      혹시 제가 도울 수 있는 게 있을까요?"
   → 거절해도 관계 유지, 수락하면 리서치 시작
```

🎓 **Ivy Tip**: "도울 수 있는 게 있을까요?"는 마법의 문장이다. "리서치 시켜주세요"보다 훨씬 낮은 부담감으로 교수의 Yes를 이끌어낸다. 이 프레이밍이 입학사정관에게 보이는 "기여형 인간"의 실제 모습이다.

🎓 **Ivy Tip (Dartmouth '26, 화학)**: "매주 Office Hours에 가다 보니 교수님이 먼저 '너 이 프로젝트 관심 있지 않니?'라고 하셨어요. 제가 요청하지도 않았는데요. 꾸준함이 최고의 전략이었어요."

✍️ 실습: 현재 가장 관심 있는 교수 1명 선택 → Office Hours 3회 방문 계획 수립 (날짜, 질문 초안 포함).
