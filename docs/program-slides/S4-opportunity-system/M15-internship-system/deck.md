# 0. 왜 고등학생 인턴십인가

```
일반 경로:   수상 → 스펙 쌓기 → "경험 없음" 악순환 → 지원 포기
InHero 경로: 관심 영역 확정 → 증거 기획 → 탐색·지원·협상 → 실전 경험
```

**사정관이 인턴십을 보는 방식**
- Activity list에서 "Research Intern @ MIT Lab"과 "Tutoring"은 *읽히는 무게가 다르다.*
- 단, 브랜드보다 **"무엇을 배웠고, 무엇을 만들었는가"** 가 에세이 소재가 된다.
- 고등학생에게 불법 무급 노동을 요구하는 기관은 피할 것 — 규정 확인 필수.

🎓 **Ivy Tip**: 인턴십 이름이 아니라 **그 경험에서 나온 산출물(코드·보고서·발표)** 이 에세이를 살린다.

# 1. 강의 62 · 인턴 찾기

## 탐색 채널 4-Layer 시스템

```
Layer 1 (가장 쉬움)  →  학교·교사 네트워크: 교수 추천, 동문 연결
Layer 2             →  디지털 플랫폼: Handshake, LinkedIn, Indeed (HS 필터)
Layer 3             →  콜드 이메일: 연구실·스타트업·NGO 직접 접촉
Layer 4 (원격·해외) →  국제 원격 인턴: Intern Abroad HQ, Virtual Internships
```

**우선순위**: Layer 3이 가장 높은 전환율. 왜?
- 경쟁자가 없다.
- 담당자에게 *이름이 기억된다.*
- "자리가 없어도" 직접 만들어낼 수 있다.

|---|---|---|

| ⑤ CTA | 달력 링크 or "월·화 중 언제가 편하신가요?" | 행동 유도 |

**이메일 길이:** 150단어 이하. 모바일로 읽힌다고 가정.

# 1-4. 흔한 실수 ❌ & 국제학생 현실

**❌ 실수**
- "인턴 자리 있나요?" 한 줄 이메일 → 삭제됨
- 큰 기업 HR 포털만 접근 → HS 필터로 탈락
- 회신 없으면 포기 → 팔로업 없이 기회 消失

**🌏 국제학생·원격 인턴 FAQ**
| 질문 | 답 |
|---|---|
| 미국 인턴 비자? | J-1 (Exchange Visitor) or 원격이면 불필요. 반드시 학교 상담실 확인. |
| 시차 문제? | 이메일에 KST/EST 병기. Calendly로 양방 편한 슬롯 공유. |
| 원격 인턴 찾는 곳? | Virtual Internships, Remote Student, 한국 스타트업 채용 (원티드·로켓펀치) |
| 무급 합법? | 미국: 교육 목적+비영리 한정. 한국: 고등학생 무급 일반적. 반드시 확인. |

# 3-4. 흔한 실수 ❌ & FAQ (포트폴리오)

**❌ 실수**
- README 없는 코드 폴더 → "이게 뭐야?" 인상
- 10개 프로젝트 vs 3개 깊이 있는 프로젝트 → 3개가 이긴다
- 과거 수상만 나열, 현재 진행 없음 → 마지막 커밋 날짜 보인다
- 팀 프로젝트에서 내 역할 불명확 → "내가 한 것" 명시 필수

**Q. 코딩을 못하는데 포트폴리오가 가능한가?**
A. 가능. 글쓰기(Medium), 디자인(Behance), 연구 보고서(PDF+Notion) 모두 포트폴리오.

**Q. 원격 인턴의 경우 결과물 공개 가능한가?**
A. 기관 허락 필수. "결과물 일부 공개 가능 여부" 인턴 시작 전 계약서 확인.

# 4. 강의 65 · 인터뷰 준비

## 인턴 인터뷰 = 경험 없어도 이기는 게임

```
그들이 묻는 것:  "당신은 이 일을 왜 하고 싶은가?"
                "배운 것을 실제로 적용한 적 있는가?"
그들이 보는 것:  성장 가능성 · 호기심 · 기본 소통 · 신뢰성
```

**인터뷰 종류별 전략**
| 종류 | 특징 | 핵심 전략 |
|---|---|---|
| 전화 인터뷰 (30분) | 1차 필터 | 짧고 명확하게, 메모지 준비 |
| 화상 인터뷰 | 가장 흔함 | 조명·배경·카메라 위치 |
| 과제 인터뷰 | 기술 검증 | 24–48h 제출물, 주석 필수 |
| 원격 인턴 초기 미팅 | 적응 확인 | 도구(Slack·Notion) 익숙도 |

# 4-1. STAR 기법 — 답변 구조

```
S — Situation  : 맥락·배경 (1–2문장, 짧게)
T — Task       : 내가 맡은 역할·목표 (1문장)
A — Action     : 내가 구체적으로 한 행동 (핵심, 가장 길게)
R — Result     : 결과·배운 점 (숫자 있으면 최강)
```

**STAR 길이 가이드**
```
S : 20%
T : 10%
A : 50%  ← 여기에 집중
R : 20%
```

🎓 **Ivy Tip**: A(Action)에서 "우리 팀이(we)"가 아니라 "나는(I)"으로 말해야 평가된다.

# 4-2. 📂 실물 — STAR 답변 예시 4종

**Q1. "Tell me about yourself."**
> "저는 환경 데이터와 생명과학의 접점을 파고드는 11학년 학생입니다. 작년 SNU 바이오센서 연구실에서 8주 인턴을 하며 MATLAB으로 형광 분광 데이터 240개를 분석했고, 두 배치의 이상값을 찾아 일관성을 18% 개선했습니다. 지금은 미세플라스틱 탐지 대시보드를 파이썬으로 직접 만들고 있습니다."

**Q2. "어려운 문제를 해결한 경험은?"**
> **S:** 환경재단 인턴 당시 번역 마감이 48시간 앞당겨졌습니다. **T:** 10개 IPCC 요약본을 2.5일 안에 번역해야 했습니다. **A:** 먼저 기술 용어 glossary를 DeepL+수동 교정으로 만들고, 초안 2시간→교정 30분 루틴을 반복했습니다. **R:** 마감 4시간 전 완료. 이후 팀이 제 glossary를 표준으로 채택했습니다.

# 4-3. 📂 실물 — STAR 답변 예시 (계속)

**Q3. "왜 우리 팀/기관에서 인턴하고 싶은가?"**
> "교수님의 2024 논문에서 형광 강도와 미세플라스틱 농도 간 비선형 관계를 설명하신 부분이 인상적이었습니다. 저도 학교 실험에서 비슷한 패턴을 발견했는데, 정밀 센서 없이는 검증이 불가했습니다. 교수님 팀의 장비와 지도 아래 이 가설을 직접 테스트해보고 싶습니다."

**Q4. "본인의 약점은?"**
> "통계 모델링이 아직 부족합니다. 데이터 정리와 시각화는 자신 있지만, 고급 회귀 분석은 Coursera로 공부 중입니다. 이 인턴을 통해 실전 데이터에 적용해보고 싶습니다."

# 4-6. 흔한 실수 ❌ & 원격·국제 인터뷰 FAQ

**❌ 실수**
- "경험이 없어서요"로 시작 → 프로젝트·수업으로 대체 가능
- 역질문을 안 함 → 관심 없음으로 읽힘
- "열심히 하겠습니다"만 반복 → 구체성 0
- 시간 초과 답변 (2분 이상) → 핵심 먼저

**🌏 국제·원격 인터뷰 FAQ**
| 상황 | 해결법 |
|---|---|
| 시차로 인한 새벽 인터뷰 | 전날 수면 조정, 카페인 섭취 시점 계획 |
| 인터넷 불안정 | 유선 연결 + 모바일 핫스팟 백업 준비 |
| 영어 발음 자신 없음 | 천천히+명확하게 > 빠르고 불명확 |
| 가족 소음 | 조용한 공간 예약, 이어폰 사용 |
