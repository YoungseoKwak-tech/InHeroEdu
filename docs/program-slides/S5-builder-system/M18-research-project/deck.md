# 1-1. 좋은 연구 질문 만들기 — 3단계

```
Step 1 · BROAD   "나는 [주제]에 관심 있다"
                         ↓
Step 2 · NARROW  "그중에서도 [특정 집단/지역/기간]이 궁금하다"
                         ↓
Step 3 · RQ      "X가 Y에 미치는 영향은 무엇인가?
                  (in context Z, using method M)"
```

**좋은 RQ 체크리스트**
- [ ] 답을 *찾을 수 있는가* (Answerable)?
- [ ] 내가 *실제로 데이터를 모을 수 있는가* (Feasible)?
- [ ] 이미 완벽히 답된 질문은 아닌가 (Novel)?
- [ ] 결과가 누군가에게 *의미 있는가* (Relevant)?

# 1-3. 흔한 실수 ❌ & FAQ — 연구 주제 선정

**흔한 실수 ❌**

# 2. 강의 75 · 문헌조사 워크플로우

## 왜 문헌조사가 먼저인가

```
내가 연구하기 전에 → 이미 누가 연구했나?
                    → 그들이 쓴 방법은?
                    → 빈 구멍(Gap)은 어디인가?
                                 ↓
                    내 연구가 그 Gap을 채운다
```

**3가지 역할**
1. **중복 방지** — 이미 완벽히 답된 질문인지 확인
2. **방법 학습** — 선행 연구 방법론을 내 연구에 적용
3. **근거 제공** — Introduction/Discussion에서 인용

---

# 2-1. 신뢰할 수 있는 소스 계층

```
★★★ 최우선
  └─ Google Scholar (scholar.google.com)
  └─ PubMed (biomedical)
  └─ JSTOR (인문·사회)
  └─ arXiv (물리·CS·수학 preprint)

★★  2차 소스
  └─ 학교 도서관 DB (RISS, KISS, DBpia)
  └─ 정부 공개 데이터 (통계청, 교육부, WHO)

★   최후 수단
  └─ Wikipedia (개요 파악만, 절대 인용 금지)
  └─ 뉴스 기사 (팩트 확인용, 학문적 인용 금지)
```

🎓 **Ivy Tip**: 논문 한 편의 **참고문헌 리스트**를 역추적하면 핵심 선행연구 10편이 한꺼번에 나온다 — "Snowball 전략."

# 2-3. 검색 효율화 — Boolean 연산자

```
나쁜 검색:   "스마트폰과 수면"
좋은 검색:   ("smartphone" OR "mobile phone") AND "sleep quality"
```

**다운로드 팁**

- DOI 붙여넣기 → [Sci-Hub 사용은 저작권 회색지대 — 학교 도서관을 먼저 써라]
- 학교 사서에게 "ILL(상호대차)" 요청 → 2–5일 내 무료

# 2-4. 흔한 실수 ❌ — 문헌조사

**흔한 실수 ❌**
- Wikipedia·블로그만 읽고 "조사 완료" → 학문적 근거 없음
- 논문을 *읽지 않고* 제목+초록만 인용 → 맥락 오독 위험
- 자기 주장에 맞는 논문만 선별 → **확증 편향(Confirmation Bias)** → 반론 논문도 포함할 것
- 인용 형식 안 지킴 → 표절(Plagiarism) 의심

🎓 **Ivy Tip**: 반론 논문을 찾아 Discussion에 "그러나 X는 다른 결론을 냈다. 이는 샘플 크기 차이 때문일 수 있다"처럼 쓰면 **비판적 사고력**이 드러난다 — 사정관이 제일 좋아하는 패턴.

# 3. 강의 76 · 실험 설계 / 데이터 연구 설계

## 연구 설계서 3요소

```
① Research Question  → 무엇을 알고 싶나
② Hypothesis         → 예측은 무엇인가
③ Method             → 어떻게 검증할 것인가
```

**가설 작성 공식**
> "만약 [독립변수]가 [증가/감소]하면, [종속변수]는 [방향]으로 변할 것이다.
> 왜냐하면 [근거 논문 1줄 요약]이기 때문이다."

예시:
> "수면 전 스마트폰 사용 시간이 길어질수록, 다음날 자기보고 집중력 점수는 낮아질 것이다. 왜냐하면 청색광이 멜라토닌 분비를 억제한다는 선행 연구(Kim 2020)에 근거한다."

# 3-4. 흔한 실수 ❌ — 실험·설계 단계

**흔한 실수 ❌**
- 통제변수 없이 "그냥 비교" → 결과가 다른 원인 때문일 수 있음
- 샘플 너무 작음 (n=5) → 통계적으로 의미 없음 → 설문 최소 30명, 실험 최소 3반복
- 가설을 결과 본 *후에* 작성 → **HARKing (Hypothesizing After Results Known)** — 비윤리적

**Q. 결과가 가설과 반대로 나왔어요.**

# 4-1. Excel 기초 분석 — 단계별

```
Step 1 · 데이터 정리
  - 빈 셀 처리: =IF(ISBLANK(A2), "NA", A2)
  - 이상치 확인: 정렬 → 최대·최솟값 확인

Step 2 · 기술통계 (Descriptive)
  - 평균: =AVERAGE(B2:B100)
  - 표준편차: =STDEV(B2:B100)
  - 중앙값: =MEDIAN(B2:B100)

Step 3 · 상관 분석
  - =CORREL(A2:A100, B2:B100) → r 값

Step 4 · 시각화
  - 산점도 삽입 → 추세선 추가 → R² 표시
```

# 4-2. Python 기초 분석 — 스타터 코드

```python
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats

# 데이터 불러오기
df = pd.read_csv("data.csv")

# 기술통계
print(df.describe())

# 상관 분석
r, p = stats.pearsonr(df["park_area"], df["heatstroke"])
print(f"r = {r:.3f}, p = {p:.4f}")

# 산점도
plt.scatter(df["park_area"], df["heatstroke"], alpha=0.7)
plt.xlabel("1인당 공원 면적 (㎡)")
plt.ylabel("열사병 이송 건수")
plt.title("공원 면적과 열사병 이송의 관계")
plt.savefig("figure1.png", dpi=300)
plt.show()
```

# 4-3. 결과 해석 — 통계 기초

| 지표 | 의미 | 논문에 쓰는 법 |
|---|---|---|
| r = 0.7 이상 | 강한 양의 상관 | "strong positive correlation (r=0.72)" |
| p < 0.05 | 통계적으로 유의 | "statistically significant (p=0.03)" |
| p ≥ 0.05 | 유의하지 않음 | "no significant correlation (p=0.12)" — 이것도 결과다 |
| R² = 0.5 | 변동의 50% 설명 | "park area explains 50% of variance" |

**⚠️ 주의**
- "상관관계 ≠ 인과관계"를 항상 Discussion에 명시
- p < 0.05 = 참 이 아님. "이 결과가 우연일 확률 5% 미만"

# 4-4. 흔한 실수 ❌ — 데이터 분석

**흔한 실수 ❌**
- 이상치(outlier) 제거하고 "언급 안 함" → 논문에 반드시 이유 기재
- 상관관계를 인과관계로 표현 → "X가 Y를 증가시킨다" → **"X는 Y와 양의 상관관계를 보였다"**
- 그래프 축 레이블·단위 없음 → 무의미한 그래프

✍️ **실습**: 1개 핵심 변수쌍에 대해 상관계수 r, p값, 산점도 1개 완성 → 논문 Figure 1 후보.

# 5. 강의 78 · 논문 IMRAD 작성

## IMRAD 구조란

```
I — Introduction  (왜 이 연구를 했나)
M — Methods       (어떻게 했나)
R — Results       (무엇을 발견했나)
A — And
D — Discussion    (그게 무슨 의미인가)
    + References  (인용 목록)
    + Abstract    (100–250단어 요약, 마지막에 씀)
```

> 논문은 **서론부터 쓰지 않는다.**
> Methods → Results → Discussion → Introduction → Abstract 순서로 써라.

---

# 5-1. 각 섹션 작성 가이드

| 섹션 | 분량 | 핵심 질문 | 흔한 실수 |
|---|---|---|---|
| **Abstract** | 100–250단어 | 한 문단에 전체 요약 | 결과 없이 "~했다" |
| **Introduction** | 400–600단어 | 왜? Gap은? RQ는? | 배경만 길게, RQ 안 나옴 |
| **Methods** | 600–800단어 | 재현 가능한가? | 재현 불가능할 만큼 모호 |
| **Results** | 400–600단어 | 수치·그래프 | 해석 섞기 (Discussion 몫) |
| **Discussion** | 600–800단어 | 의미·한계·미래 | 결과 반복만, 해석 없음 |
| **References** | 10편 이상 | APA 또는 AMA 형식 | 형식 불일치 |

# 5-2. Introduction — 📝 채워진 예시 (발췌)

> *"도시 열섬 현상은 지구 온난화와 함께 심화되고 있으며, 서울의 경우 2010년 이후 여름철 평균기온이 1.3°C 상승했다(Kim et al., 2022). 특히 녹지가 부족한 도심 지역에서 열사병 관련 응급 이송이 집중되는 것으로 보고되었으나(Lee, 2021), 자치구 단위에서 공원 면적과 열사병 발생 간의 정량적 관계를 분석한 연구는 드물다. 본 연구는 서울 25개 자치구의 1인당 공원 면적과 열사병 응급 이송 건수 간의 상관관계를 분석함으로써 이 공백을 메우고자 한다."*

**구조 분석**
- 문장 1–2: 배경 (선행 연구 인용)
- 문장 3: Gap ("드물다")
- 문장 4: RQ ("본 연구는…")

# 5-3. Discussion — 어떻게 쓰는가

```
Discussion 4단계 구조:

1. 핵심 발견 재진술
   "본 연구는 1인당 공원 면적과 열사병 이송 건수 간에
    유의한 음의 상관관계(r = −0.68, p = 0.003)를 발견했다."

2. 선행 연구와 비교
   "이는 Lee(2021)의 폭염 취약성 연구 결과와 일치하며…"

3. 대안 설명 / 한계
   "그러나 본 연구는 횡단 자료를 사용했으므로 인과관계를
    주장할 수 없다. 또한 고령 인구 비율 등 교란 변수를
    완전히 통제하지 못했다."

4. 미래 연구 방향
   "향후 연구는 종단 데이터와 기온 측정을 포함해야 한다."
```

# 5-5. 흔한 실수 ❌ & 윤리 — 논문 작성

**흔한 실수 ❌**
- Results에 해석 쓰기 ("유의미하게 낮았다" → Discussion 몫)
- Discussion을 결과 반복으로 채움 → *왜 그런가*가 없음
- Abstract를 Introduction처럼 씀 → 방법·결과·결론 다 있어야 함
- 한 문단에 인용 없이 3문장 이상 → **표절 위험**

**⚠️ 출판에 대한 현실**
- 고등학생 논문이 피어리뷰 저널에 실리는 건 매우 드물다.
- **목표는 출판이 아니다** — 과정, 포트폴리오, 에세이 소재.
- 콘퍼런스(Regeneron, ISEF, Scioly) 제출, ResearchGate 업로드도 유효한 공유 방법.
