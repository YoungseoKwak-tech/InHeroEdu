# 0. 왜 "리더십 활동"이 달라 보이는가

```
일반 학생:   동아리 가입 → 1년 회원 → "했다" 한 줄
InHero 경로: 0→1 창설 → 시스템 구축 → 임팩트 수치화 → 에세이 소재
```

**입학사정관의 시선**
- 수백 개 원서에서 **'창설자'와 '참여자'는 즉시 구별된다.**
- 묻는 것: "이 학생이 없었다면 이 조직이 존재했을까?"
- 숫자가 말한다: 회원 수, 모금액, 참석자 수, 미디어 커버리지.

🎓 **Ivy Tip**: 클럽 이름보다 **"Before / After 숫자"** 가 기억에 남는다.
(예: "창립 → 3개월 → 회원 47명 · 지역 후원 2개 · ₩2,000,000 모금")

# 강의 88 · 커뮤니티 0→1 — 단계별 플레이북

```
WEEK 1–2   핵심 멤버 5명 모집 (1:1 DM, 직접 대화)
               ↓
WEEK 3     킥오프 미팅 — 미션 문장 · 이름 합의
               ↓
WEEK 4–6   첫 작은 이벤트 (30명 이하) 실행
               ↓
WEEK 7–8   구조화: 역할·회칙·소통 채널
               ↓
MONTH 3+   공개 성장 — 학교 공식 등록 / 외부 후원
```

**핵심 원칙**: 완벽한 구조보다 **"첫 이벤트 먼저"**. 이벤트가 멤버를 모은다.

🎓 **Ivy Tip**: Yale 합격생 인터뷰 — "클럽은 인스타 DM 12개로 시작했다. 공식 절차는 두 달 뒤였다."

# 강의 88 · 채워진 예시 — 환경 클럽 창설

**갭**: 학교에 재활용 분리수거 표지판이 없고 매주 100L 플라스틱이 일반 쓰레기로 나감.

| 단계 | 실제 행동 | 결과 |
|---|---|---|
| 핵심 5명 | 과학부 친구 + 미술부 2명 + 선생님 멘토 | 구성 완료 |
| 첫 이벤트 | "Trash Walk" — 교내 쓰레기 지도 그리기 | 참가 31명 |
| 구조화 | 회칙 1페이지 + 위챗 그룹 + 월간 회의 | 3개월째 운영 |
| 임팩트 | 분리수거 박스 6개 설치 · 플라스틱 -42% | 학교 방송 보도 |

→ **Common App EC 한 줄**: "환경 클럽 창설 · 회원 47명 · 분리수거율 42% 향상"

# 강의 88 · 흔한 실수 ❌ + FAQ

**흔한 실수 ❌**
- 이름·로고부터 만들고 멤버 없음 → **사람 먼저, 브랜드 나중**
- 혼자 다 하다가 번아웃 → Week 3에 역할 배분 필수
- "모두를 위한" 클럽 → 대상 너무 넓으면 아무도 안 옴; 좁게 시작해라
- 학교 승인 기다리다 6개월 소비 → **비공식으로 먼저 움직여라**

**Q. 학교에 비슷한 클럽이 이미 있으면?**
A. ① 더 특화 (예: "환경 클럽" → "업사이클 패션 클럽") ② 기존 클럽 안에서 Sub-팀 창설 ③ 교외(지역사회)로 나가라.

🎓 **Ivy Tip**: 하버드 EC 리뷰어 — "학교 밖 임팩트가 학교 안 클럽보다 배점 높다."

# 강의 89 · 행사 기획 A–Z

## 단계 개요

```
아이디어  →  타깃·목적  →  예산  →  장소·일정  →  홍보
    →  현장 운영  →  사후 정리  →  임팩트 수치화
```

**행사의 3가지 유형**
| 유형 | 예시 | 주요 고려 |
|---|---|---|
| 소규모 워크숍 | 30명 이하 · 실내 | 깊이 vs 폭 |
| 중규모 컨퍼런스 | 100–300명 | 스폰서 · 진행팀 |
| 대규모 공개 행사 | 300명+ | 장소·보험·예산 |

> **첫 행사는 반드시 소규모**로 시작하라. 실수를 작게 만든다.

# 강의 89 · 흔한 실수 ❌ + 예산 함정

**흔한 실수 ❌**
- 장소 먼저 예약, 목적·예산 나중 → 취소 불가로 손해

- 홍보를 D-3에 시작 → 참석자 5명; **홍보는 T-4주부터**
- 당일 역할 분담 없음 → 대표 혼자 모든 문제 처리

**예산 함정 3가지**
| 함정 | 예방법 |
|---|---|
| AV 장비 대여비 과소평가 | 장소 포함 여부 먼저 확인 |
| 음식/케이터링 과다 지출 | 협찬으로 대체; 없으면 커피만 |
| 환불·취소 정책 없음 | RSVP 시 약관 명시 |

🎓 **Ivy Tip**: 프린스턴 합격생 — "행사 예산을 ₩0으로 만드는 법: 장소(학교), 음식(스폰서), 홍보(SNS) 순으로 무료 채널부터 채워라."

# 강의 90 · TEDx 운영 실전

## TEDx란?

```
TED가 라이선스를 부여 → 개인·조직이 독립적으로 개최
                       → 'x' = independently organized
```

**학생에게 왜 TEDx인가**
- TED 브랜드 = 전 세계 공신력 → 입시·이력서에서 즉각 인식
- 라이선스 무료 (비상업 이벤트 기준)
- 영상이 TED.com에 올라갈 수 있음 → 영구 온라인 자산
- 운영 경험 자체가 리더십 증거 (기획·섭외·제작 all-in-one)

🎓 **Ivy Tip**: Columbia 합격생 — "TEDxYouth@Seoul 오거나이저였는데, 에세이 5편 중 3편이 여기서 나왔다."

# 강의 90 · TEDx 라이선스 취득 단계

```
① TED.com/tedx/organize 신청서 작성
       ↓  (3–6주 심사)
② TED 팀 승인 이메일 수신
       ↓
③ 라이선스 계약서 서명 (무료, 비영리)
       ↓
④ Organizer Guidebook 수령 → 규정 숙지
       ↓
⑤ 행사 날짜·장소·테마 TED 포털에 등록
       ↓
⑥ 행사 개최 → 영상 업로드 → TED 검토
```

**라이선스 핵심 규정 요약**
| 항목 | 규정 |
|---|---|
| 입장료 | 최대 $100 (TEDxYouth: $50) |
| 연사 수 | 최대 12명/행사 |
| 행사 길이 | 최대 4시간 (파트 분리 가능) |
| TED Talk 비율 | 75% 이하 (나머지는 라이브 발표) |
| 영리 행위 | 엄격히 금지 |

# 강의 91 · RACI 매트릭스 — 의사결정 명확화

**RACI 란?**
- **R** = Responsible (실행) · **A** = Accountable (최종 책임)
- **C** = Consulted (의견 제공) · **I** = Informed (결과 공유)

**TEDx 주요 결정 RACI 예시**

| 결정 | Chief | Program | Marketing | Logistics |
|---|---|---|---|---|
| 테마 확정 | **A** | R | C | I |
| 연사 최종 선발 | **A** | R | I | I |
| SNS 콘텐츠 | I | C | **R/A** | I |
| 장소 계약 서명 | **A** | I | I | R |
| 예산 최종 승인 | **A** | C | C | C |

🎓 **Ivy Tip**: RACI 한 장이 "왜 내가 해야 해?"를 없앤다. Columbia 동아리 회장 팁.

# 강의 91 · 갈등 관리 — 3단계 프레임워크

**팀 내 갈등의 3가지 유형**

```
Type 1: 역할 갈등  → "그건 내 일 아니야"
Type 2: 의견 갈등  → "내 아이디어가 더 낫다"
Type 3: 에너지 갈등 → 번아웃·참여도 차이
```

**3단계 해결 프레임워크**

| 단계 | 행동 | 예시 대사 |
|---|---|---|
| ① 듣기 | 1:1 미팅 · 판단 보류 | "어떤 점이 힘들었어?" |
| ② 명확화 | 기대치·역할 재정의 | "네 역할 범위를 다시 정리해보자" |
| ③ 합의 | 문서화·팀 공유 | "이걸 슬랙에 올려두고 다같이 확인하자" |

> 갈등을 피하지 말고 **빠르게 1:1로** 처리하라. 팀 전체 앞에서 지적은 최후 수단.

# 강의 91 · 팀 리딩 실전 — 번아웃 예방

**팀원 번아웃 조기 신호**
- 슬랙 응답 속도가 갑자기 느려짐
- 미팅에 늦거나 카메라 끔
- 결과물 퀄리티 하락 or 기한 어김 반복

**번아웃 예방 루틴**

| 루틴 | 주기 | 내용 |
|---|---|---|
| 1:1 체크인 | 격주 | 일 + 컨디션 둘 다 물어라 |
| 팀 회고 | 월 1회 | Keep / Stop / Start 3항목 |
| 소셜 세션 | 행사 후 1회 | 밥 먹기·놀기 — 팀 유대 |
| 공개 감사 | 매 미팅 | 팀원 기여 1명씩 소리내어 |

🎓 **Ivy Tip**: 다트머스 합격생 — "팀장으로 처음 배운 것: 사람 에너지를 관리하는 것이 일정 관리보다 중요하다."

# 강의 91 · 리더십 루브릭 — 입시 관점

**사정관이 평가하는 리더십 스펙트럼**

| 레벨 | 행동 증거 | 점수 |
|---|---|---|
| L0 | 참여만 함 | 중립 |
| L1 | 담당 파트 책임 (부장급) | +1 |
| L2 | 팀 창설 or 행사 기획 | +2 |
| L3 | 조직 성장 수치화 + 지속성 | +3 |
| L4 | 외부 임팩트 (미디어·파트너십·상) | +4 |

**L3→L4 점프 조건**
- 수치: 회원 수 증가 % / 모금액 / 참석자 수
- 지속성: 내가 떠난 뒤에도 조직이 살아있음
- 외부 인정: 기사·수상·파트너 협약
