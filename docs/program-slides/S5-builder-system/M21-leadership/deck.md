# 0. 왜 "리더십 활동"이 달라 보이는가

```
일반 학생:   동아리 가입 → 1년 회원 → "했다" 한 줄
InHero 경로: 0→1 창설 → 시스템 구축 → 임팩트 수치화 → 에세이 소재
```

**입학사정관의 시선**
- 수백 개 원서에서 **'창설자'와 '참여자'는 즉시 구별된다.**
- 묻는 것: "이 학생이 없었다면 이 조직이 존재했을까?"
- 숫자가 말한다: 회원 수, 모금액, 참석자 수, 미디어 커버리지.

🎓 **Ivy Tip 1**: 클럽 이름보다 **"Before / After 숫자"** 가 기억에 남는다.
(예: "창립 → 3개월 → 회원 47명 · 지역 후원 2개 · ₩2,000,000 모금")

🎓 **Ivy Tip 2**: Harvard 입학사정관 공개 발언 (2024 QA 세션) — "우리는 활동 목록이 아니라 **활동이 만들어낸 변화**를 읽는다." 변화를 숫자로 증명하라.

🎓 **Ivy Tip 3**: 국제 학생은 "내 나라에서만 가능한 활동"이 강점이다. 미국 학생이 못 하는 로컬 임팩트 — 한국 지역사회·학교·NGO 연계가 차별화 포인트.

# 강의 88 · 커뮤니티 만들기 (0→1)

## 단계 1 — "왜 이게 없나?" 갭 진단

```
관찰  →  갭 정의  →  첫 5명  →  구조화  →  공개 출범
```

**갭 진단 3문항**
| 질문 | 내 답 |
|---|---|
| 학교/지역에 없는데 내가 원하는 것은? | ___ |
| 그게 없어서 불편하거나 화가 난 순간은? | ___ |
| 나 말고 같은 불편을 느낄 사람 5명이 있나? | ___ |

> 세 칸이 다 채워지면 **커뮤니티 씨앗**이 있다.

🎓 **Ivy Tip**: 갭 진단 전에 **학교 기존 동아리 목록 전수 조사** 먼저 하라. 중복 없음 = 신청서에서 "학교 최초" 문구 쓸 수 있다. MIT AO는 "first at school"을 EC 설명에서 명시적으로 높이 평가한다고 밝힌 바 있다.

# 강의 88 · 커뮤니티 0→1 — 단계별 플레이북

```
WEEK 1–2   핵심 멤버 5명 모집 (1:1 DM, 직접 대화)
               ↓
WEEK 3     킥오프 미팅 — 미션 문장 · 이름 합의
               ↓
WEEK 4–6   첫 작은 이벤트 (30명 이하) 실행
               ↓
WEEK 7–8   구조화: 역할·회칙·소통 채널
               ↓
MONTH 3+   공개 성장 — 학교 공식 등록 / 외부 후원
```

**핵심 원칙**: 완벽한 구조보다 **"첫 이벤트 먼저"**. 이벤트가 멤버를 모은다.

🎓 **Ivy Tip 1**: Yale 2025 합격생 (서울 국제학교 출신) — "클럽은 인스타 DM 12개로 시작했다. 공식 절차는 두 달 뒤였다. 입학원서 제출 시 회원 수 61명·협찬 3개를 적었다."

🎓 **Ivy Tip 2**: 킥오프 미팅 전 **1페이지 "왜 우리가?" 문서**를 미리 만들어 보내라. 첫 미팅에서 방향 논쟁 없이 바로 행동 계획으로 넘어갈 수 있다.

🎓 **Ivy Tip 3**: 첫 5명은 스스로 "공동 창설자"라고 느끼게 하라 — 이름을 창립 문서에 올리고 역할을 처음부터 주어라. 주인의식이 지속성을 만든다.

# 강의 88 · 채워진 예시 — 환경 클럽 창설

**갭**: 학교에 재활용 분리수거 표지판이 없고 매주 100L 플라스틱이 일반 쓰레기로 나감.

| 단계 | 실제 행동 | 결과 |
|---|---|---|
| 핵심 5명 | 과학부 친구 + 미술부 2명 + 선생님 멘토 | 구성 완료 |
| 첫 이벤트 | "Trash Walk" — 교내 쓰레기 지도 그리기 | 참가 31명 |
| 구조화 | 회칙 1페이지 + 카카오톡 그룹 + 월간 회의 | 3개월째 운영 |
| 임팩트 | 분리수거 박스 6개 설치 · 플라스틱 -42% | 학교 방송 보도 |

→ **Common App EC 한 줄**: "환경 클럽 창설 · 회원 47명 · 분리수거율 42% 향상"

🎓 **Ivy Tip**: "Trash Walk" 같은 **이름 붙인 고유 이벤트**는 에세이 소재가 된다. 단순한 "쓰레기 줍기"보다 기억에 남고, 보도 가능성도 올라간다.

# 강의 88 · 흔한 실수 ❌ + FAQ

**흔한 실수 ❌**
- 이름·로고부터 만들고 멤버 없음 → **사람 먼저, 브랜드 나중**
- 혼자 다 하다가 번아웃 → Week 3에 역할 배분 필수
- "모두를 위한" 클럽 → 대상 너무 넓으면 아무도 안 옴; 좁게 시작해라
- 학교 승인 기다리다 6개월 소비 → **비공식으로 먼저 움직여라**

**Q. 학교에 비슷한 클럽이 이미 있으면?**
A. ① 더 특화 (예: "환경 클럽" → "업사이클 패션 클럽") ② 기존 클럽 안에서 Sub-팀 창설 ③ 교외(지역사회)로 나가라.

🎓 **Ivy Tip 1**: Harvard EC 리뷰어 (Alumni Interview) 전언 — "학교 밖 임팩트가 학교 안 클럽보다 배점 높다. 지역사회·NGO·지방정부와 협업이 있으면 반드시 명시하라."

🎓 **Ivy Tip 2**: 클럽 이름을 영어로 지어라 — Common App EC 기술란은 150자 영어다. 번역할 필요 없이 자연스럽게 설명 가능하도록 처음부터 영어 이름을 병기하라.

# 🎓 강의 88 · 실전 꿀팁 모음

- **첫 5명 모집 DM 구조**: ① 왜 너를 콕 집었는지 1줄 ② 아이디어 1줄 ③ "10분만 통화 가능?" 로 끝내라. 긴 DM은 읽히지 않는다.
- **창립 날짜 기록 보존**: 킥오프 미팅 사진 + 캘린더 초대 스크린샷을 Drive에 저장하라. 입시 원서에 "설립 연도/월"을 적을 때 증거가 된다.
- **공식 등록 전략**: 학교 승인이 느리면 지역 청소년단체(예: 구청 청소년참여위원회)에 먼저 등록해 "공식 단체" 지위를 얻어라.
- **숫자 업데이트 루틴**: 매달 1일 회원 수·이벤트 횟수·모금액을 구글 스프레드시트에 기록하라. Common App 제출 직전 가장 높은 숫자를 쓸 수 있다.
- **미디어 전략**: 첫 이벤트 직후 학교 신문·지역 신문에 보도자료 1페이지를 이메일로 보내라. 기사 1건 = EC 설명에서 "media coverage" 한 줄 추가.
- **후계자 지명**: 11학년 말에 반드시 후계자를 훈련시켜라. "내가 떠난 뒤에도 조직이 살아있다"는 지속성 증거가 L3→L4 점프 조건이다.
- **협찬 첫 단계**: 지역 소상공인(카페·서점)부터 시작하라. 협찬 금액이 아니라 **공식 파트너십 로고** 자체가 원서 소재다. ₩50,000 협찬도 "기업 파트너십 확보"로 쓸 수 있다.
- **커뮤니티 플랫폼 선택**: 한국 학생 대상은 카카오톡 오픈채팅, 국제 대상은 Discord. 두 채널 동시 운영하면 회원 수가 2배로 기재 가능하다.

# 강의 89 · 행사 기획 A–Z

## 단계 개요

```
아이디어  →  타깃·목적  →  예산  →  장소·일정  →  홍보
    →  현장 운영  →  사후 정리  →  임팩트 수치화
```

**행사의 3가지 유형**
| 유형 | 예시 | 주요 고려 |
|---|---|---|
| 소규모 워크숍 | 30명 이하 · 실내 | 깊이 vs 폭 |
| 중규모 컨퍼런스 | 100–300명 | 스폰서 · 진행팀 |
| 대규모 공개 행사 | 300명+ | 장소·보험·예산 |

> **첫 행사는 반드시 소규모**로 시작하라. 실수를 작게 만든다.

🎓 **Ivy Tip**: Princeton 합격생 (대구 출신) — "첫 행사 참석자 목표를 30명으로 잡고 28명이 왔다. 두 번째는 80명. 세 번째는 210명. 숫자가 커지는 **궤적** 자체가 에세이 소재가 됐다."

# 강의 89 · 예산 항목 실전 템플릿

**중규모 컨퍼런스 (100명) 예산 예시**

| 항목 | 예상 비용 | 절약 전략 |
|---|---|---|
| 장소 대여 | ₩300,000–₩800,000 | 학교·구청·대학 강당 = 무료/할인 |
| AV 장비 (마이크·프로젝터) | ₩200,000–₩500,000 | 장소 포함 여부 먼저 확인 |
| 케이터링 (다과) | ₩300,000–₩600,000 | 카페 협찬으로 대체 |
| 인쇄물 (포스터·프로그램북) | ₩80,000–₩150,000 | 디지털 QR 대체 |
| 연사 교통비 | ₩0–₩200,000 | 서울 내 연사 = KTX 불필요 |
| **합계** | **₩880,000–₩2,250,000** | 스폰서 ₩1,000,000+ 목표 |

🎓 **Ivy Tip 1**: 스폰서 제안서에 "로고 노출 + 소셜 미디어 태그 + 참석자 수"를 명시하면 협찬 성공률 2배 올라간다. 숫자 없는 제안서는 거절된다.

🎓 **Ivy Tip 2**: 지역 교육청·구청 청소년과에 공문 한 장으로 무료 장소를 신청하라. 학생 주최 행사는 대부분 공간비 면제 대상이다. Columbia 출신 박지원(가명) — "성동구청 강당을 공문 1장으로 무료로 썼다. 비용이 ₩500,000 줄었다."

🎓 **Ivy Tip 3**: 행사 후 스폰서 보고서를 반드시 PDF로 만들어 전달하라. 다음 행사 때 이 보고서가 신규 스폰서 유치 자료가 된다.

# 🎓 강의 89 · 실전 꿀팁 모음

- **연사 섭외 성공률 높이는 법**: LinkedIn으로 연락할 때 "학생이 기획한 행사"임을 강조하라. 성인 기획 행사보다 수락률이 높다. 연사 거절 시 "대신 추천해줄 분이 있나요?" 로 반드시 물어라 — 소개율 40%.

- **인스타 홍보 타이밍**: T-4주 티저 → T-2주 연사 공개 → T-1주 카운트다운 → D-1 "내일 봐요" — 이 4단계 포스팅이 알고리즘 노출 최대화.
- **자원봉사 인센티브**: 봉사 시간 확인서 + 행사 참석 무료 + 단체 사진 등록증은 자원봉사자 40~50명 모집 가능. 봉사 시간은 학교와 미리 협의하라.
- **현장 비상 키트**: 이름표 여분 20장, 셀로판테이프, 유성 매직, 연장선, 핸드폰 충전기, 물 2L, 진통제 — 이 7가지를 박스에 미리 챙겨라.
- **임팩트 리포트 작성 공식**: "날짜·장소·참석자 수·연사 수·미디어 커버리지·후속 파트너십 수" 6항목이 들어간 1페이지 보고서를 행사 후 48시간 이내 작성하라.
- **Google Form + Sheets 연동**: 피드백 설문을 Sheets에 자동 연결하면 결과를 스폰서에게 실시간으로 공유 가능. 응답률 30% 이상이면 다음 스폰서 제안서에 "참석자 만족도" 항목을 넣어라.
- **사진·영상 보관**: Google Drive 공유 폴더를 만들고 팀원 전원이 촬영본을 즉시 업로드하는 규칙을 만들어라. D+1에 정리하지 않으면 영영 사라진다.

# 강의 90 · 연사 코칭 실전 — TED Talk 형식 가이드

**TED Talk vs 일반 발표 차이**

| 항목 | 일반 발표 | TED Talk |
|---|---|---|
| 슬라이드 | 텍스트 빽빽 | 이미지 중심, 슬라이드당 1 메시지 |

| 구조 | 서론-본론-결론 | 아이디어 여정 (Why → What → So What) |
| 마무리 | "이상입니다" | "Idea worth spreading" 1문장 |
| 길이 | 제한 없음 | **18분 이하** (TEDxYouth: 12분 권장) |

**연사 코칭 3회 구조**
- 1회 (M-2): 아이디어 핵심 1문장 + 스토리 아크 피드백
- 2회 (M-2+2주): 슬라이드 리뷰 + 리허설 (타이머 포함)
- 3회 (M-1): 드레스 리허설 + 무대 동선 확인

🎓 **Ivy Tip**: Yale SOM 출신 TEDx 퍼실리테이터 조언 — "연사가 '내 아이디어'를 말하게 하라. '내 경력'을 말하게 하면 강연이 지루해진다. 오프닝 30초가 청중을 잡는다."

- **TED 영상 심사 가속**: 행사 후 2주 이내 YouTube 업로드 + TED 포털 제출이 빠를수록 심사 대기열에서 유리하다. 오래된 제출은 검토 후순위가 된다.
- **학생 연사 오디션 공식**: 구글 폼으로 "아이디어 1문장 + 왜 당신이 말해야 하는가 + 3분 영상 링크"를 받아라. 지원자 수 자체가 홍보 효과다.
- **스폰서 등급제**: 골드(₩500,000+) / 실버(₩200,000+) / 파트너(현물) 3등급으로 나누고 등급별 혜택(로고 크기·SNS 언급 횟수)을 제안서에 명시하라. 등급제가 있으면 소액 협찬도 받기 쉬워진다.
- **행사 테마 굿즈**: 에코백·스티커 1종 제작 (₩3,000~₩5,000/개)은 참석자 인스타 인증 게시물을 유도한다. UGC(사용자 생성 콘텐츠) = 무료 홍보.
- **TED.com 게재 후 활용**: 게재 링크를 Common App Additional Info, 인터뷰 포트폴리오, 교사 추천서 요청 이메일에 반드시 첨부하라. 영구 링크가 있는 것과 없는 것은 신뢰도 차원에서 완전히 다르다.

# 강의 91 · 팀 리딩 — 역할 분담

## 리더의 첫 번째 임무: 역할 명확화

```
모호한 팀:   "다들 알아서 해"  →  책임 공백  →  갈등
명확한 팀:   역할 매트릭스 1장 →  자율 운영  →  스케일
```

**TEDx/커뮤니티 기준 핵심 역할 매트릭스**

| 역할 | 담당 영역 | KPI |
|---|---|---|
| Chief Organizer | 총괄·의사결정·TED 연락 | 행사 완주 여부 |
| Program Director | 연사 섭외·코칭·런타임 | 연사 확정률 (목표: 8주 전 100%) |
| Marketing Lead | SNS·포스터·PR | RSVP 수 (목표 인원×1.4배) |
| Sponsor Manager | 제안서·파트너 관리 | 모금액 (지출의 80% 이상 커버) |
| Logistics Lead | 장소·장비·당일 운영 | 세팅 완료 시간 (개시 30분 전) |
| Content/AV Lead | 영상 촬영·편집·업로드 | 업로드 기한 준수 (행사 후 2주) |

🎓 **Ivy Tip**: 역할 매트릭스를 만들 때 KPI를 **숫자로** 적어라. "잘 하기" 대신 "8주 전 100% 확정"처럼. 숫자 없는 KPI는 달성 여부를 아무도 모른다.

# 강의 91 · RACI 매트릭스 — 의사결정 명확화

**RACI 란?**
- **R** = Responsible (실행) · **A** = Accountable (최종 책임)
- **C** = Consulted (의견 제공) · **I** = Informed (결과 공유)

**TEDx 주요 결정 RACI 예시**

| 결정 | Chief | Program | Marketing | Logistics | Sponsor |
|---|---|---|---|---|---|
| 테마 확정 | **A** | R | C | I | I |
| 연사 최종 선발 | **A** | R | I | I | I |
| SNS 콘텐츠 | I | C | **R/A** | I | C |
| 장소 계약 서명 | **A** | I | I | R | I |
| 예산 최종 승인 | **A** | C | C | C | R |
| 스폰서 계약 | A | I | I | I | **R** |

🎓 **Ivy Tip 1**: RACI 한 장이 "왜 내가 해야 해?"를 없앤다. Columbia 2025 동아리 회장 — "RACI 도입 후 팀 갈등이 80% 줄었다. 역할 싸움이 사라졌다."

🎓 **Ivy Tip 2**: RACI에서 A(최종 책임)가 2명 이상이면 실제로는 책임자가 없는 것이다. 모든 행은 A가 정확히 1명이어야 한다.

# 강의 91 · 갈등 관리 — 3단계 프레임워크

**팀 내 갈등의 3가지 유형**

```
Type 1: 역할 갈등  → "그건 내 일 아니야"
Type 2: 의견 갈등  → "내 아이디어가 더 낫다"
Type 3: 에너지 갈등 → 번아웃·참여도 차이
```

**3단계 해결 프레임워크**

| 단계 | 행동 | 예시 대사 |
|---|---|---|
| ① 듣기 | 1:1 미팅 · 판단 보류 | "어떤 점이 힘들었어?" |
| ② 명확화 | 기대치·역할 재정의 | "네 역할 범위를 다시 정리해보자" |
| ③ 합의 | 문서화·팀 공유 | "이걸 슬랙에 올려두고 다같이 확인하자" |

> 갈등을 피하지 말고 **빠르게 1:1로** 처리하라. 팀 전체 앞에서 지적은 최후 수단.

🎓 **Ivy Tip 1**: 갈등 해결 경험은 에세이 소재 1순위다. "팀원 A가 번아웃으로 이탈하려 했을 때, 나는 역할을 재분배하고 일정을 조정했다 — 그 결과 행사는 성공했고 A는 지금도 팀에 있다." 이 구조가 리더십 에세이의 정석이다.

🎓 **Ivy Tip 2**: Dartmouth 합격생 (부산 출신) — "팀장으로 처음 배운 것: 사람 에너지를 관리하는 것이 일정 관리보다 중요하다. 스케줄은 고칠 수 있어도 번아웃 팀원은 못 고친다."

# 강의 91 · 팀 리딩 실전 — 번아웃 예방 + 팀 문화

**팀원 번아웃 조기 신호**
- 슬랙/카카오톡 응답 속도가 갑자기 느려짐
- 미팅에 늦거나 카메라 끔 (비대면 기준)
- 결과물 퀄리티 하락 or 기한 어김 반복
- 미팅에서 말수가 급격히 줄어듦

**번아웃 예방 루틴**

| 루틴 | 주기 | 내용 |
|---|---|---|
| 1:1 체크인 | 격주 | 일 + 컨디션 둘 다 물어라 |
| 팀 회고 | 월 1회 | Keep / Stop / Start 3항목 |
| 소셜 세션 | 행사 후 1회 | 밥 먹기·놀기 — 팀 유대 |
| 공개 감사 | 매 미팅 | 팀원 기여 1명씩 소리내어 칭찬 |

🎓 **Ivy Tip**: 미팅 시작 5분 "체크인 라운드" — 한 사람씩 "이번 주 에너지 레벨 1~10점"을 말하게 하라. 6점 이하가 있으면 그 사람의 짐을 즉시 줄여라. Harvard 리더십 수업에서 가르치는 "psychological safety" 기법의 학생 버전이다.

# 강의 91 · 리더십 루브릭 — 입시 관점

**사정관이 평가하는 리더십 스펙트럼**

| 레벨 | 행동 증거 | 점수 |
|---|---|---|
| L0 | 참여만 함 | 중립 |
| L1 | 담당 파트 책임 (부장급) | +1 |
| L2 | 팀 창설 or 행사 기획 | +2 |
| L3 | 조직 성장 수치화 + 지속성 | +3 |
| L4 | 외부 임팩트 (미디어·파트너십·수상) | +4 |

**L3→L4 점프 조건**
- 수치: 회원 수 증가 % / 모금액 / 참석자 수 추이
- 지속성: 내가 떠난 뒤에도 조직이 살아있음 (후계자 증거)
- 외부 인정: 기사·수상·파트너 협약·TED.com 게재

🎓 **Ivy Tip**: L4를 입증하는 가장 빠른 방법 — ① 지역 신문 기사 클리핑 PDF ② 시상식 수상 사진 ③ 파트너 기관 공식 서한 (협력 확인 레터). 이 3가지를 인터뷰 포트폴리오에 실물로 준비하라.

# 🎓 강의 91 · 실전 꿀팁 모음

- **역할 매트릭스 공유 방법**: Notion 또는 구글 시트에 올리고 팀원 전원이 댓글로 "확인 완료"를 남기게 하라. 나중에 "몰랐다"는 말이 없어진다.
- **갈등 예방 루틴**: 킥오프 미팅에서 "우리 팀 규칙 5가지"를 팀원이 직접 만들게 하라. 위에서 내려온 규칙보다 스스로 만든 규칙을 더 잘 지킨다.
- **팀원 이탈 대비**: 핵심 역할 3개(Program / Marketing / Logistics)는 반드시 백업 담당자를 처음부터 지정하라. 이탈은 언제든 일어난다.
- **미팅 효율화**: 매 미팅 시작 전 안건을 공유 문서에 올리고, 결정 사항·담당자·기한을 3열 표로 기록하라. 미팅 후 요약 없으면 다음 미팅이 이전 내용 복습으로 낭비된다.
- **팀장 에세이 소재 채굴법**: 매 달 리더로서 "가장 어려운 결정"을 메모 1줄로 기록하라. 이것이 6개월 뒤 Common App 에세이 첫 문장이 된다.
- **인터뷰 대비 — STAR 프레임**: 리더십 경험을 Situation(배경) / Task(임무) / Action(행동) / Result(결과)로 정리하라. "갈등 해결" "번아웃 팀원 살리기" "행사 당일 위기 대응" 3가지 스토리를 미리 만들어라.
- **추천서 전략**: 함께 일한 어른(교사 멘토 or 코어팀 어드바이저)이 당신의 리더십을 직접 목격했다면 추천서 1장이 나온다. 모듈 시작 시 어드바이저를 미리 선정하라.
- **후계자 시스템**: 조직을 떠나기 6개월 전부터 "그림자 리더"를 훈련시켜라. 문서화된 인수인계 + 후계자 사진/이름을 원서에 추가하면 "지속성" 증거가 완성된다.
