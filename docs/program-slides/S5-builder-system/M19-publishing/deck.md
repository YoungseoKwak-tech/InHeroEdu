# 0. 왜 고등학생이 책을 써야 하는가

```
일반 학생:   활동 → 수상 → "할 게 없다" → 에세이 막힘
출판 학생:   관심사 → 책 → ISBN → 저자 신분 → 에세이 = 집필 과정
```

**입학사정관이 보는 것**
- 활동 10개가 나열된 학생 vs. **"저는 이 문제가 너무 궁금해서 책을 썼습니다"**
- 책 = **self-directed 학습의 물증** — 추천서·인터뷰 없이도 입증됨
- 사정관은 Common App 한 페이지를 평균 **8분** 읽는다. 책 제목 한 줄이 나머지 9개 활동을 압도한다.

🎓 **Ivy Tip (Princeton 재학생, 2024년 합격)**: "사정관 입장에서 책 한 권은 research paper 100편이 아니라도 **'얘는 뭔가 다르다'**는 신호다. ISBN이 찍히는 순간 검증 가능한 외부 증거가 된다."

🎓 **Ivy Tip (Harvard GSAS 재학생, 한국 출신)**: "나는 11학년 여름에 24,000단어 책을 한 권 냈다. Common App 에세이 500단어가 그 책의 '서문 요약'이 됐다. 면접관도 책 먼저 물어봤다."

# 0-1. 책 vs. 다른 활동 — 입시 효과 비교

| 활동 유형 | 검증 가능성 | 재현 불가능성 | 에세이 연결 | 추가 확장 |
|---|---|---|---|---|
| 수학 경시 수상 | ★★★ | ★★ | ★★ | 제한적 |
| 리서치 논문 | ★★★ | ★★★ | ★★★ | 중간 |
| 자가출판 책 | ★★★★★ | ★★★★★ | ★★★★★ | 강연·SNS·인터뷰 |
| 앱 개발 | ★★★★ | ★★★★ | ★★★★ | 사용자 수 필요 |
| 봉사활동 | ★★ | ★ | ★★ | 시간 의존 |

**결론**: 책은 검증 가능한 증거물 중 **가장 낮은 비용으로 가장 강력한 서사**를 만든다.

🎓 **Ivy Tip (Yale 재학생, 서울 국제학교 출신)**: "사정관이 Amazon에서 내 책 이름을 검색할 수 있다는 게 핵심이었다. 나머지 활동은 '제가 했어요' 주장이지만, 책은 URL 하나로 증명된다."

# 79-4. 기획 흔한 실수 ❌ & FAQ

**흔한 실수 ❌**
- ❌ 너무 광범위: "환경 문제 전반" → ✅ "우리 학교 반경 1km 대기질"로 좁혀라
- ❌ 독자 불명확: "모든 사람을 위한 책" → ✅ "환경 동아리 고1–2 학생"
- ❌ 저자 자격 없이 시작: → ✅ 프로젝트/리서치 먼저, 집필은 그 다음
- ❌ 출판=마지막 목표: → ✅ 출판=입시 서사의 *증거물*
- ❌ 챕터 8개 이상 기획: → ✅ 6–8챕터가 집필 완주율 최고. 10챕터 이상은 미완성으로 끝남

**Q. 주제가 너무 작지 않나요?**
A. 오히려 작을수록 좋다. "좁고 깊은 주제" = 전문성 = 스파이크. 사정관은 큰 주제의 얇은 책보다 **작은 주제의 깊은 관찰**을 더 높이 산다.

🎓 **Ivy Tip (Yale 재학생)**: "합격 에세이 주제로 쓴 연구를 챕터로 확장했다. 에세이와 책이 서로를 증명했다."

# 🎓 실전 꿀팁 모음 — 강의 79 (기획)

- **주제 선택 테스트**: "이 주제로 2시간 강의할 수 있는가?" YES면 진행, NO면 주제 변경
- **챕터 수 황금 비율**: 7챕터 × 2,500단어 = 17,500단어 = 페이퍼백 120페이지 (가장 완주율 높음)
- **경쟁 분석 필수**: Amazon에서 동일 주제 책 10권 검색 → 없으면 좋은 신호, 있으면 차별화 포인트 찾기
- **기획서를 멘토/선생님께 먼저 보여라**: 1페이지 기획서 피드백 = 집필 방향 확정. 이 피드백 메일이 나중에 추천서 근거가 됨
- **제목은 마지막에**: 집필 전 제목에 집착하면 범위가 고정됨. 초고 완성 후 제목 확정
- **부제에 키워드 박기**: "기후 측정 가이드 for 고등학생 — 30달러 센서로 PM2.5 데이터 수집하기" 형식이 Amazon 검색 SEO에 유리
- **서문부터 써라**: 서문에서 "왜 내가 이 책을 써야 하는가"가 명확해져야 나머지 챕터가 써진다. 기획 단계에서 서문 초고 500단어 작성 권장
- **공동저자 옵션**: 같은 프로젝트를 한 팀원과 공동 집필 시 각자 별도 챕터 → 둘 다 'Author' 신분 획득 가능

# 강의 80 · 원고 작성 시스템

## 고등학생용 집필 엔진

```
주간 목표: 2,000단어 (≈ A4 4장)
일일 목표: 300–400단어 (≈ 20–30분)
12주 완성 = 24,000단어 = 책 1권
```

**집필 3원칙**
1. **"완벽한 초고"는 없다** — 초고는 *날것*이어야 한다
2. **챕터 순서대로 쓰지 마라** — 쓰고 싶은 챕터부터
3. **소스를 먼저 모아라** — 자료 없이 쓰면 막힌다

🎓 **Ivy Tip (MIT 재학생)**: "나는 챕터마다 노션 페이지 하나를 만들고, 관련 논문 링크·인용문·내 메모를 먼저 30분 동안 채운 뒤에 집필을 시작했다. 빈 화면을 보며 쓰는 게 아니라 소스를 *정리*하는 느낌으로 접근하면 막힘이 80% 줄어든다."

# 80-1. 12주 집필 타임라인

| 주차 | 목표 | 산출물 | 실전 팁 |
|---|---|---|---|
| 1–2주 | 리서치 + 아웃라인 확정 | 챕터별 개요 2–3줄 | Google Scholar 5편 이상 리뷰 |
| 3–5주 | Part 1 초고 | Ch.1–2 완성 | 일일 Pomodoro 25분 × 2세트 |
| 6–8주 | Part 2 초고 | Ch.3–5 완성 | 완성된 챕터 PDF 저장 (백업) |
| 9–10주 | Part 3 초고 + 서문 | Ch.6–7 + 서문 | 서문은 마지막에 쓰는 게 정석 |
| 11주 | 1차 셀프 편집 | 전체 통독 교정 | 소리 내어 읽기 (오류 발견율 3배↑) |
| 12주 | 최종 편집 + KDP 준비 | 업로드용 파일 | Word → PDF 변환 전 스타일 체크 |

🎓 **Ivy Tip (Harvard 재학생)**: "챕터 초고를 쓰고 나서 72시간 뒤에 다시 읽어라. 낯설어질수록 편집 눈이 생긴다."

🎓 **Ivy Tip (Brown 재학생, 대만 출신)**: "11학년 여름방학 8주를 집필에 썼다. 매일 아침 6시 30분에 300단어를 쓰고 학교를 갔다. 습관이 생기면 단어 수는 자동으로 늘어난다."

# 80-4. 📂 실물 — 합격생의 챕터 1 훅 예시

> *"2022년 11월, 나는 학교 옥상에서 측정 장비가 아닌 아이폰 카메라와 30달러짜리 센서 하나를 들고 있었다. 그날 오후 2시 미세먼지 수치는 PM2.5 기준 '매우 나쁨'이었지만, 운동장에서는 체육 수업이 진행 중이었다. 데이터는 거기 있었다. 그 데이터를 볼 사람이 없었을 뿐이다."*

**무엇이 좋은가**
- 구체적 날짜 + 장소 → 독자가 장면에 들어옴
- 저자의 관찰력 = 저자 자격의 증거
- 마지막 두 문장 = 책 전체의 테마

**흔한 실수 ❌**: "환경 문제는 현대 사회의 중요한 이슈입니다" 식의 교과서 훅 → 즉시 독자 이탈

# 🎓 실전 꿀팁 모음 — 강의 80 (원고 작성)

- **300단어 규칙**: 하루 최소 300단어. 적다고 느껴도 12주 지속하면 25,000단어 = 책 1권
- **Block Writing 기법**: 알람을 25분 맞추고 그 시간 안에 타이핑만 한다. 사전·리서치 금지. 편집 금지. 쓰는 것만
- **챕터 첫 문장 스톡**: 막히면 "나는 [날짜]에 [장소]에서 [행동]을 하고 있었다"로 시작. 99% 훅이 만들어진다
- **인용문 쿼터**: 챕터마다 외부 인용 최소 3개 포함 (논문·뉴스·인터뷰). 저자 자격을 독자에게 간접 증명
- **집필 진행률 공개**: 매주 Instagram/카톡 그룹에 진행률 올리기 (예: "7장 중 3장 완성"). 사회적 압력이 완주율 높임
- **리서치와 집필을 분리**: 리서치 시간 = 소스 수집만. 집필 시간 = 타이핑만. 섞으면 둘 다 느려짐
- **'나쁜 문장' 허용**: 초고에서 나쁜 문장을 쓰는 것을 두려워하지 마라. [DRAFT] 태그를 달아두고 나중에 편집
- **서문은 마지막에**: 서문은 책 전체가 완성된 후 가장 마지막에 써야 진짜 메시지가 나온다

# 강의 81 · 편집 3단계

## 편집은 집필과 다른 기술이다

```
1단계 구조 편집 (Structural Edit)
      "챕터 순서가 맞는가? 빠진 논리가 있는가?"
           ↓
2단계 라인 편집 (Line Edit)
      "문장 수준에서 명확한가? 중복은 없는가?"
           ↓
3단계 교정 (Proofreading)
      "맞춤법·문법·숫자·인용 오류"
```

**편집 원칙: 10% 삭제 룰**
초고 단어 수 × 0.9 = 최종 목표. *줄이면 힘이 생긴다.*

🎓 **Ivy Tip (Stanford 재학생)**: "나는 편집을 3회 했다. 1회차: 인쇄해서 종이로 읽기. 2회차: 소리 내어 읽기. 3회차: 친구에게 읽어달라고 해서 막히는 곳 표시. 각 회차마다 다른 오류가 나온다."

# 81-2. 라인 편집 — 흔한 실수 ❌ 예시

| 나쁜 문장 ❌ | 고친 문장 ✅ | 이유 |
|---|---|---|
| "이것은 매우 중요한 문제입니다" | "이 문제로 매년 학생 1만 명이 영향받는다" | 구체 수치로 대체 |
| "~라고 할 수 있습니다" | "~다" (단정) | 수동·모호 제거 |
| "다양한 측면에서 살펴보면" | 삭제하고 바로 본론 | 공허한 도입 삭제 |
| "우선 첫째로" | "첫째" | 중복 삭제 |
| 수동태 남발 | 능동태로 전환 | 힘 있는 문장 |
| "~것 같다" | "~이다" | 저자 자신감 표현 |

**문장 레벨 셀프 테스트**
1. 문장을 소리 내어 읽는다 — 막히는 곳 = 편집 포인트
2. 각 단락의 첫 문장만 모아 읽는다 — 논리가 보여야 함

# 🎓 실전 꿀팁 모음 — 강의 81 (편집)

- **인쇄 편집 효과**: 화면으로 보이지 않던 오류가 종이에서 보인다. 최종 원고는 반드시 1회 인쇄해서 읽어라
- **24시간 냉각 원칙**: 초고 완성 후 최소 24시간(가능하면 72시간) 후에 편집 시작. 거리가 생겨야 오류가 보인다
- **베타 리더 구하기**: 책의 타깃 독자 2–3명에게 챕터 1–2를 읽히고 피드백 받기. 가장 빠른 구조 편집 방법
- **Hemingway Editor 무료 사용**: hemingwayapp.com에 붙여넣기 → 복잡한 문장·수동태·부사 과용 자동 표시
- **10% 삭제 적용법**: 챕터 단어 수 × 0.9 목표 설정 → 중복 단락·공허한 도입부 우선 삭제
- **숫자 통일 룰**: 1–9는 영문("one"~"nine"), 10 이상은 숫자. 또는 전체 숫자. 방식 하나 선택 후 전체 통일
- **인용 확인 필수**: 책에 사용한 모든 통계·인용문의 원출처 URL 보존. 편집 단계에서 체크. 잘못된 인용 = 신뢰도 붕괴
- **챕터 단어 수 편차 관리**: 가장 짧은 챕터 vs. 가장 긴 챕터의 단어 수 차이가 50% 이상이면 독자 리듬이 깨진다. 짧은 챕터를 늘리거나 긴 챕터를 쪼개라

# 강의 82 · Amazon KDP 자가출판

## KDP란?

**Kindle Direct Publishing** — Amazon의 자가출판 플랫폼.
- 비용: **무료** (출판 비용 0원)
- 수익: 전자책 35–70%, 종이책 60% 로열티
- ISBN: KDP가 **무료로 발급** (고유 도서 번호)
- 납기: 승인 후 **24–72시간** 내 Amazon 전세계 판매

```
계정 생성 → 책 정보 입력 → 파일 업로드 → 표지 디자인 → 가격 설정 → 제출 → 승인 → 판매
```

🎓 **Ivy Tip (Harvard 재학생)**: "KDP 계정 개설에 부모 정보가 필요한 경우(만 18세 미만), 계좌 명의는 부모로 하되 저자명 등록은 본인 이름으로 한다. Amazon Author Central은 저자 본인 계정으로 별도 개설 가능하다."

# 82-4. 로열티 계산 — 실전 수치

**전자책 (Kindle) 로열티**
```
가격 $2.99 × 70% 로열티 = $2.09 / 권
가격 $0.99 × 35% 로열티 = $0.35 / 권
→ 반드시 $2.99 이상 설정 (70% 구간 진입)
→ 입시 서사용 권장 가격: $4.99–$9.99 (저자 신뢰도↑)
```

**종이책 (Paperback) 로열티**
```
정가 $9.99, 100페이지 기준
- 인쇄비: ~$2.15
- Amazon 수수료 40%: $3.99
= 저자 수령 ≈ $3.85 / 권
→ 최소 정가: $8.99 이상 설정해야 손실 없음
```

**수익보다 중요한 것**: 판매 수량은 입시 서사의 **데이터 포인트**
"출판 3개월 만에 독자 200명" = 에세이 한 줄

🎓 **Ivy Tip (MIT 재학생)**: "로열티로 $500 이상 번 경우 Common App의 'Honors' 또는 'Activities' 란에 '수익을 낸 저자'로 기재 가능하다. 금액보다 '시장이 반응했다'는 사실이 사정관에게 설득력 있다."

- **가격 실험 전략**: 출판 첫 주 $0.99 프로모션 → 리뷰 유도 → 2주차부터 $4.99로 올리기. 초기 리뷰 10개가 장기 판매 결정
- **종이책 증정본 주문**: 출판 후 Author Copy를 5권 주문 (권당 인쇄비만 부담, 약 $2–3). 학교 도서관 기증 + 강연 시 실물 소품으로 활용
- **Amazon 판매 데이터 스크린샷 보관**: KDP 대시보드의 판매 그래프를 매월 스크린샷. 입시 에세이 작성 시 "독자 수 데이터" 근거로 활용

# 83-7. 흔한 실수 ❌ & 출판 후 FAQ

**흔한 실수 ❌**
- ❌ 출판 후 아무것도 안 함 → 판매 0 = 서사 약화
- ❌ 리뷰 요청을 민망해함 → 첫 20개 리뷰가 Amazon 알고리즘 결정
- ❌ SNS에 책 소개 1회로 끝냄 → 챕터 요약 주 1회 연재가 더 효과적
- ❌ 강연 제안서를 한 곳에만 보냄 → 최소 10곳 동시 발송
- ❌ Author Central 미설정 → 저자 페이지 없으면 신뢰도 급락

**Q. 책이 잘 안 팔리면 입시에 쓸 수 없나요?**
A. 전혀 아니다. **"판매량"이 아니라 "출판한 사실"**이 입시 포인트. 100권 팔린 책과 5권 팔린 책, 사정관이 보는 건 ISBN이 있는 저자 신분이다.

**Q. 한국어로 써도 되나요?**
A. 한국어 책은 한국 독자 대상 서사에서 강력. 영어 책은 글로벌 독자 → "국제적 영향력" 서사. 가능하면 **영한 병행 출판** 권장.
