# 0. 왜 고등학생이 책을 써야 하는가

```
일반 학생:   활동 → 수상 → "할 게 없다" → 에세이 막힘
출판 학생:   관심사 → 책 → ISBN → 저자 신분 → 에세이 = 집필 과정
```

**입학사정관이 보는 것**
- 활동 10개가 나열된 학생 vs. **"저는 이 문제가 너무 궁금해서 책을 썼습니다"**
- 책 = **self-directed 학습의 물증** — 추천서·인터뷰 없이도 입증됨

🎓 **Ivy Tip (Princeton 재학생)**: "사정관 입장에서 책 한 권은 research paper 100편이 아니라도 **'얘는 뭔가 다르다'**는 신호다. ISBN이 찍히는 순간 검증 가능한 외부 증거가 된다."

# 강의 79 · 책 기획

## 기획의 3가지 질문

```
Q1. 누가 읽는가? (독자)
Q2. 무엇을 얻어가는가? (전환점)
Q3. 왜 내가 써야 하는가? (저자 자격)
```

**고등학생에게 맞는 책 장르 선택표**

| 장르 | 집필 난이도 | 입시 효과 | 예시 |
|---|---|---|---|
| How-to 가이드 | ★★☆ | ★★★ | "국제학생 SAT 독학 90일" |
| 에세이 모음 | ★★☆ | ★★★ | "기후 세대의 과학 일기" |
| 소설/단편집 | ★★★ | ★★☆ | 단편 10편 묶음 |
| 연구 정리본 | ★★★ | ★★★★ | "십대가 쓴 AI 윤리 입문" |
| 시집/문학 | ★☆☆ | ★★☆ | 언어 특기자용 |

# 79-3. 기획 흔한 실수 ❌ & FAQ

**흔한 실수 ❌**
- ❌ 너무 광범위: "환경 문제 전반" → ✅ "우리 학교 반경 1km 대기질"로 좁혀라
- ❌ 독자 불명확: "모든 사람을 위한 책" → ✅ "환경 동아리 고1–2 학생"
- ❌ 저자 자격 없이 시작: → ✅ 프로젝트/리서치 먼저, 집필은 그 다음
- ❌ 출판=마지막 목표: → ✅ 출판=입시 서사의 *증거물*

**Q. 주제가 너무 작지 않나요?**
A. 오히려 작을수록 좋다. "좁고 깊은 주제" = 전문성 = 스파이크. 사정관은 큰 주제의 얇은 책보다 **작은 주제의 깊은 관찰**을 더 높이 산다.

🎓 **Ivy Tip (Yale 재학생)**: "합격 에세이 주제로 쓴 연구를 챕터로 확장했다. 에세이와 책이 서로를 증명했다."

# 강의 80 · 원고 작성 시스템

## 고등학생용 집필 엔진

```
주간 목표: 2,000단어 (≈ A4 4장)
일일 목표: 300–400단어 (≈ 20–30분)
12주 완성 = 24,000단어 = 책 1권
```

**집필 3원칙**
1. **"완벽한 초고"는 없다** — 초고는 *날것*이어야 한다
2. **챕터 순서대로 쓰지 마라** — 쓰고 싶은 챕터부터
3. **소스를 먼저 모아라** — 자료 없이 쓰면 막힌다

---

# 80-1. 12주 집필 타임라인

| 주차 | 목표 | 산출물 |
|---|---|---|
| 1–2주 | 리서치 + 아웃라인 확정 | 챕터별 개요 2–3줄 |
| 3–5주 | Part 1 초고 | Ch.1–2 완성 |
| 6–8주 | Part 2 초고 | Ch.3–5 완성 |
| 9–10주 | Part 3 초고 + 서문 | Ch.6–7 + 서문 |
| 11주 | 1차 셀프 편집 | 전체 통독 교정 |
| 12주 | 최종 편집 + KDP 준비 | 업로드용 파일 |

🎓 **Ivy Tip (Harvard 재학생)**: "챕터 초고를 쓰고 나서 72시간 뒤에 다시 읽어라. 낯설어질수록 편집 눈이 생긴다."

# 80-3. 📂 실물 — 합격생의 챕터 1 훅 예시

> *"2022년 11월, 나는 학교 옥상에서 측정 장비가 아닌 아이폰 카메라와 30달러짜리 센서 하나를 들고 있었다. 그날 오후 2시 미세먼지 수치는 PM2.5 기준 '매우 나쁨'이었지만, 운동장에서는 체육 수업이 진행 중이었다. 데이터는 거기 있었다. 그 데이터를 볼 사람이 없었을 뿐이다."*

**무엇이 좋은가**
- 구체적 날짜 + 장소 → 독자가 장면에 들어옴
- 저자의 관찰력 = 저자 자격의 증거
- 마지막 두 문장 = 책 전체의 테마

**흔한 실수 ❌**: "환경 문제는 현대 사회의 중요한 이슈입니다" 식의 교과서 훅 → 즉시 독자 이탈

✍️ **실습 80**: 챕터 1 훅 150단어 + 전체 아웃라인 1페이지

# 강의 81 · 편집 3단계

## 편집은 집필과 다른 기술이다

```
1단계 구조 편집 (Structural Edit)
      "챕터 순서가 맞는가? 빠진 논리가 있는가?"
           ↓
2단계 라인 편집 (Line Edit)
      "문장 수준에서 명확한가? 중복은 없는가?"
           ↓
3단계 교정 (Proofreading)
      "맞춤법·문법·숫자·인용 오류"
```

**편집 원칙: 10% 삭제 룰**
초고 단어 수 × 0.9 = 최종 목표. *줄이면 힘이 생긴다.*

---

# 81-1. 구조 편집 체크리스트

| 항목 | 확인 질문 | ✅/❌ |
|---|---|---|
| 논리 흐름 | 챕터 1→2→3이 자연스럽게 이어지는가? | |
| 독자 여정 | 독자가 책 끝에서 뭘 할 수 있나 명확한가? | |
| 챕터 균형 | 각 챕터 분량이 30% 이상 편차 없는가? | |
| 서문 | 독자가 "이 책 내게 필요하다"고 느끼는가? | |
| 결론 | 책 전체 메시지를 한 단락으로 요약했는가? | |

🎓 **Ivy Tip (Princeton 재학생)**: "구조 편집은 *목차를 보면서* 해라. 챕터 제목만 읽어도 책의 논리가 보여야 한다."

---

# 81-2. 라인 편집 — 흔한 실수 ❌ 예시

| 나쁜 문장 ❌ | 고친 문장 ✅ |
|---|---|
| "이것은 매우 중요한 문제입니다" | "이 문제로 매년 학생 1만 명이 영향받는다" |
| "~라고 할 수 있습니다" | "~다" (단정) |
| "다양한 측면에서 살펴보면" | 삭제하고 바로 본론 |
| "우선 첫째로" | "첫째" (중복 삭제) |
| 수동태 남발 | 능동태로 전환 |

**문장 레벨 셀프 테스트**
1. 문장을 소리 내어 읽는다 — 막히는 곳 = 편집 포인트
2. 각 단락의 첫 문장만 모아 읽는다 — 논리가 보여야 함

✍️ **실습 81**: 챕터 1 초고를 위 체크리스트 3단계로 편집

# 강의 82 · Amazon KDP 자가출판

## KDP란?

**Kindle Direct Publishing** — Amazon의 자가출판 플랫폼.
- 비용: **무료** (출판 비용 0원)
- 수익: 전자책 35–70%, 종이책 60% 로열티
- ISBN: KDP가 **무료로 발급** (고유 도서 번호)
- 납기: 승인 후 **24–72시간** 내 Amazon 전세계 판매

```
계정 생성 → 책 정보 입력 → 파일 업로드 → 표지 디자인 → 가격 설정 → 제출 → 승인 → 판매
```

# 82-3. 로열티 계산 — 실전 수치

**전자책 (Kindle) 로열티**
```
가격 $2.99 × 70% = $2.09 / 권
가격 $0.99 × 35% = $0.35 / 권
→ $2.99 이상 설정 권장
```

**종이책 (Paperback) 로열티**
```
정가 $9.99
- 인쇄비 (100페이지 기준): ~$2.15
- Amazon 수수료 40%: $3.99
= 저자 수령 ≈ $3.85 / 권
```

**수익보다 중요한 것**: 판매 수량은 입시 서사의 **데이터 포인트**
"출판 3개월 만에 독자 200명" = 에세이 한 줄

`[스크린샷 자리: KDP 대시보드 "Royalties & Pricing" 설정 화면]`

# 82-4. KDP 흔한 실수 ❌ & FAQ

**흔한 실수 ❌**
- ❌ Word 파일을 스타일 없이 제출 → 전자책 레이아웃 깨짐
- ❌ 표지 해상도 부족 → "Low resolution" 오류 거절
- ❌ 저작권 없는 이미지 사용 → 계정 정지 위험
- ❌ 카테고리 1개만 선택 → 2개 모두 설정해 노출 극대화

**Q. 미성년자도 KDP 계정 개설 가능한가요?**
A. 만 18세 미만은 **부모 계정으로 출판** 가능. 저자 이름은 본인 이름 그대로 사용. 로열티 수령은 부모 은행 계좌로 연결.

**Q. 한국어 책도 Amazon에서 팔 수 있나요?**
A. 가능. "Amazon.co.jp" (일본) 또는 글로벌 마켓플레이스 설정. 단, **영어 책이 입시 서사로는 더 강력** — 국제 독자 = 글로벌 영향력 증명.

# 강의 83 · 출판 후 브랜딩

## 출판은 끝이 아니라 시작이다

```
출판 전: "책 쓰는 학생"
출판 후: "저자 + 전문가 + 커뮤니티 빌더"
```

# 83-5. 흔한 실수 ❌ & 출판 후 FAQ

**흔한 실수 ❌**
- ❌ 출판 후 아무것도 안 함 → 판매 0 = 서사 약화
- ❌ 리뷰 요청을 민망해함 → 첫 20개 리뷰가 Amazon 알고리즘 결정
- ❌ SNS에 책 소개 1회로 끝냄 → 챕터 요약 주 1회 연재가 더 효과적
- ❌ 강연 제안서를 한 곳에만 보냄 → 최소 10곳 동시 발송

**Q. 책이 잘 안 팔리면 입시에 쓸 수 없나요?**
A. 전혀 아니다. **"판매량"이 아니라 "출판한 사실"** 이 입시 포인트. 100권 팔린 책과 5권 팔린 책, 사정관이 보는 건 ISBN이 있는 저자 신분이다.

**Q. 한국어로 써도 되나요?**
A. 한국어 책은 한국 독자 대상 서사에서 강력. 영어 책은 글로벌 독자 → "국제적 영향력" 서사. 가능하면 **영한 병행 출판** 권장.

✍️ **실습 83**: 저자 바이오 50단어 + 강연 제안서 초안 1장 + Common App 활동란 초안
