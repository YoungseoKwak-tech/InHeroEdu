# InHero — Ivy League Operating System · 강의 보조자료(슬라이드)

각 **모듈(M1~M25)** 마다 폴더가 하나씩 있고, 그 안에 **슬라이드 덱(Markdown)** 이 들어 있습니다.
도표·프레임워크·아이비리그생 팁·실습이 슬라이드당 꽉 차도록 구성했습니다.

## 슬라이드 → PPT 변환법
이 `.md` 파일들은 **Marp / Slidev / Deckset** 으로 바로 슬라이드(PPT/PDF)로 변환됩니다.
- `---` 는 슬라이드 구분선.
- **Marp(추천, 무료):** VS Code "Marp for VS Code" 확장 설치 → `.md` 열고 → "Export Slide Deck" → PPTX/PDF.
- 또는 [marp.app](https://marp.app) CLI: `marp deck.md -o deck.pptx`
