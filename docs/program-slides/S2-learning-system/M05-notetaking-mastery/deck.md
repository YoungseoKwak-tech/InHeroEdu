# Module 5 · Notetaking Mastery
### 시즌 2 · 학습 시스템

> 노트는 "받아쓰기"가 아니라 **생각의 외장하드(Second Brain)**.
> 과목 유형마다 노트 방식이 다르다.

🎯 결과물: **개인 노트 시스템** (4종 템플릿 + Second Brain)

`[그림: Cornell / Engineering / Research / Digital 노트 4종 비교 이미지]`

---

# 왜 노트 방식을 바꿔야 하나 (도표)

| 베끼는 노트 | 생각하는 노트 |
|---|---|
| 강의 그대로 받아씀 | 내 말로 압축 |
| 복습 안 함 | 질문·요약 칸으로 복습 |
| 시험 전 버림 | 평생 검색 가능 |
| 수동 | 능동(재구성) |

🎓 **Ivy Tip**: 노트의 목적은 "적는 것"이 아니라 **"나중의 나에게 설명하는 것"**.

---

# 강의 16 · Cornell Notes (구조)

```
┌──────────┬───────────────────────┐
│  Cue     │   Notes               │
│ (질문/   │  (강의 핵심, 내 말로) │
│  키워드) │                       │
├──────────┴───────────────────────┤
│  Summary (한 줄 요약)             │
└───────────────────────────────────┘
```
- 수업 중: 오른쪽 Notes / 수업 후: 왼쪽 Cue 질문화 + 아래 Summary.
- 복습: 오른쪽 가리고 **Cue만 보고 답하기**(Active Recall 내장).

---

# 강의 17 · Engineering Notes (수식·도해)

| 칸 | 내용 |
|---|---|
| 개념 | 정의 + 직관(왜) |
| 수식 | 유도 과정 1줄씩 |
| 도해 | 그림/그래프 |
| 함정 | 자주 틀리는 포인트 |
| 예제 | 적용 1개 |

🎓 **Ivy Tip**: 수식은 **유도(derivation)** 를 적어라. 외우는 게 아니라 다시 만들 수 있어야 한다.

`[그림: 실제 공대생의 회로/미적분 노트 스캔]`

---

# 강의 18 · Research Notes (논문/실험)

```
[논문/실험 1개 = 카드 1장]
 · 질문(왜 읽나)
 · 핵심 주장 1문장
 · 방법 요약
 · 내 생각/비판
 · 내 연구와의 연결
```
> 논문은 "읽었다"가 아니라 **카드로 남겨야** 자산이 된다 (Season 5 연구로 연결).

---

# 강의 19 · Digital Notes (도구)

| 도구 | 강점 | 추천 용도 |
|---|---|---|
| Notion | 구조·DB | 과목 허브 |
| Obsidian | 링크·그래프 | Second Brain |
| OneNote | 손필기 | 수업 중 |
| Anki | 간격반복 | 암기 |

🎓 **Ivy Tip**: 도구 3개 이상 쓰지 마라. **검색 가능 + 링크 가능** 1개면 충분.

---

# 강의 20 · Second Brain 구축 (PARA)

```
P · Projects   진행 중 (논문·프로젝트)
A · Areas      지속 (과목별)
R · Resources  참고 (논문·아이디어)
A · Archive    종료
```
- 모든 노트를 4개 폴더에. **찾는 시간 0** 이 목표.

✍️ 실습: 내 자료를 PARA 4폴더로 재배치.

---

# 📂 실물 — 합격생의 Second Brain

`[그림: 실제 학생 Obsidian 그래프 뷰 — 노트들이 링크로 연결된 모습]`

- 고1~고3 노트가 **하나의 망**으로 연결.
- 에세이 쓸 때 검색 한 번에 소재가 쏟아짐.

🎓 **Ivy Tip**: 노트끼리 **링크**를 걸어라. 점이 아니라 망이 지식이다.
