# 16-1. Cornell Notes — 언제·어떻게 쓰나

**최적 상황**
- 강의 중 실시간 필기 (인문·사회·생물·역사)
- 교수 말이 빠르고 슬라이드가 조밀할 때
- 중간·기말고사 복습 사이클이 필요할 때

**3단계 사용법**
```
① 강의 중 → 필기 열에만 빠르게 받아쓰기
   (완벽한 문장 X, 키워드·약어·기호 사용)

② 강의 후 24시간 내 → 단서 열 채우기
   (핵심 질문·키워드 — "시험에 나온다면 어떤 질문?")

③ 주말 → 요약 열 작성 + 단서 열만 보고 구술 복습
   (단서 열로 가리고 필기 열 내용을 말로 설명)
```

🎓 **Ivy Tip**: Cornell을 발명한 Walter Pauk 교수는 코넬大 학생들의 시험 성적이 이 방식 도입 후 **평균 0.7점(GPA) 상승**했다고 보고했다. 핵심은 24시간 내 단서 열 작성.

# 16-2. Cornell Notes — 📝 채워진 실제 예시

**과목: AP Biology / 토픽: 세포 호흡 (Cellular Respiration)**

```
┌──────────────────┬──────────────────────────────────┐
│  단서 열         │  필기 열                          │
├──────────────────┼──────────────────────────────────┤
│ ATP란?           │ Adenosine Triphosphate            │
│                  │ 세포의 "에너지 화폐"               │
│ 해당과정 산물?   │ 해당과정 (Glycolysis)              │
│                  │  → 포도당(6C) → 피루브산(3C)×2    │
│ 순 ATP 몇 개?    │  → 순 ATP 2개, NADH 2개           │
│                  │                                  │
│ 크렙스 입력물?   │ 미토콘드리아 기질에서 진행          │
│                  │  입력: 아세틸-CoA (2C)             │
│                  │  → CO₂ 방출, NADH·FADH₂ 생성     │
│ ETC 최종 수용체? │ 전자전달계 → 최종 수용체: O₂      │
│                  │  → H₂O 생성, ATP 32–34개          │
├──────────────────┴──────────────────────────────────┤
│ 요약: 포도당 1분자 → 해당(2ATP) → 크렙스 → ETC →   │
│ 총 36–38 ATP. 산소 필요(호기성). O₂ 없으면 발효.   │
└─────────────────────────────────────────────────────┘
```

# 16-3. Cornell Notes — 흔한 실수 & 🎓 Ivy Tip

**흔한 실수 ❌**
- 필기 열에 교수 말을 **문장 그대로** 받아쓰기 → 처리(processing) 없이 복사만 됨
- 단서 열을 **강의 끝난 뒤 일주일 후**에 채움 → 복습 효과 소멸
- 요약을 "이 페이지에 뭐가 있었지" 나열 → **"가장 중요한 1가지"** 만 써라
- 색펜 과용으로 **형광펜 투성이** → 뇌가 우선순위를 못 잡음

**🎓 Ivy Tip — Harvard 선배 노하우**
> "나는 단서 열을 무조건 **질문형**으로 쓴다. '세포호흡 단계는?'처럼. 그러면 요약 시간에 그냥 시험 연습이 된다."
— Harvard '25, 분자생물학 전공

✍️ **실습**: 다음 수업에서 Cornell 포맷 종이 한 장 써오기. 단서 열은 수업 끝난 직후(교실 나오기 전) 채울 것.

# 17-1. Engineering Notes — 언제·어떻게 쓰나

**최적 상황**
- 물리·화학·수학·공학 문제풀이
- 회로도·자유물체도·그래프가 핵심인 수업
- 과제 오답 분석·오류 노트 작성 시

**핵심 원칙 4가지**
```
① 스케치 먼저 — 그림 없이 풀지 않는다
   (MIT 공대생: "그림 안 그리면 50% 실수 확률")

② Given / Find 분리 — 주어진 것과 구해야 할 것을 명시

③ 단위(Unit)를 모든 중간 계산에 표시
   (단위 소거법으로 검증)

④ 오류 노트 필수 — 왜 틀렸는지 1줄 기록
   (틀린 개념 / 계산 실수 / 단위 오류 중 무엇인가)
```

🎓 **Ivy Tip**: Caltech·MIT 1학년 과제에서 **풀이 과정 없이 답만 쓰면 0점**이다. 아이비 수준에서는 **과정의 논리**가 답보다 중요하다.

# 17-2. Engineering Notes — 📝 채워진 실제 예시

**과목: AP Physics C / 토픽: 뉴턴 2법칙 응용 (경사면)**

```
┌──────────────────────────┬──────────────────────────┐
│    [자유물체도]          │ 공식:                    │
│                          │  ΣF = ma                 │
│    N ↑                  │  f = μN                   │
│    ↑                    │                           │
│  ──●──→ f(마찰)         │ Given:                    │
│   /│ 30°                │  m = 5 kg, θ = 30°       │
│  / ↓ mg                 │  μ_k = 0.2, g = 9.8      │
│ /경사면                  │                           │
│                          │ Find: a = ?               │
│                          │                           │
│                          │ 풀이:                     │
│                          │  N = mg cosθ = 42.4 N    │
│                          │  f = 0.2×42.4 = 8.5 N    │
│                          │  ΣF = mgsinθ - f         │
│                          │     = 24.5 - 8.5 = 16 N  │
│                          │  a = 16/5 = 3.2 m/s²    │
├──────────────────────────┴──────────────────────────┤
│ 오류 노트: cosθ·sinθ 혼동 → 수직항력은 cos, 경사방향은 sin │
└─────────────────────────────────────────────────────┘
```

# 17-3. Engineering Notes — 흔한 실수 & ✍️ 실습

**흔한 실수 ❌**
- 스케치 없이 수식부터 → **시각화 없이 풀면 오류 증가**
- 단위 생략 → 중간 계산에서 오류 발견 불가
- 오류 노트 건너뜀 → 같은 실수 반복
- 너무 깔끔하게 쓰려다 시간 낭비 → Engineering 노트는 **지저분해도 된다**

**🎓 Ivy Tip — MIT 물리 TA 조언**
> "자유물체도를 그리지 않은 학생은 거의 예외 없이 부호 실수를 한다. 5초짜리 스케치가 30분 검토를 대체한다."

`[그림: 실제 공대생 노트 스캔 — Princeton 공대생의 자유물체도 + 공식 + 오류 노트 병기]`

✍️ **실습**: 현재 풀고 있는 물리/수학 문제 3개를 이 포맷으로 다시 풀어라. 오류 노트 칸에 "왜 틀렸나" 1줄씩 기록.

# 18-1. Research Notes — 언제·어떻게 쓰나

**최적 상황**
- 논문·학술지 읽을 때 (IB Extended Essay, AP Research, 대학 과제)
- 책·비문학 텍스트 분석 시
- 자신의 리서치 프로젝트 자료 정리 시

**3-패스 독서법 (연구에서 검증된 방법)**
```
1차 (훑기, 5분):
   → 제목·초록·결론·그래프만 읽기
   → "이 논문이 뭘 주장하나?" 1줄 메모

2차 (핵심 읽기, 20분):
   → 본문 읽으면서 핵심 개념·인용구 채우기
   → 이해 안 되는 용어 ☐ 체크

3차 (비판 읽기, 10분):
   → 내 생각(My Response) 작성
   → 다른 자료와 연결고리(Links) 기록
```

🎓 **Ivy Tip**: Princeton 학생들은 논문 1편당 **Research Note 1장**을 원칙으로 삼는다. 인용구를 직접 옮겨 쓰면 **paraphrasing 역량**이 자동으로 길러진다.

# 18-2. Research Notes — 📝 채워진 실제 예시

**주제: CRISPR 유전자 가위 (AP Research 과제용)**

```
출처: Doudna & Charpentier (2012) "A Programmable Dual-RNA–Guided
      DNA Endonuclease in Adaptive Bacterial Immunity" Science

📌 핵심 주장:
   Cas9 단백질 + guide RNA 조합으로 특정 DNA 서열을 정밀 절단 가능

🔑 핵심 개념                 📊 방법/데이터
① Cas9: DNA 절단 효소        실험: in vitro 절단 실험
② gRNA: 목표 서열 안내       결과: 목표 서열 특이적 절단 확인
③ PAM 서열: 절단 위치 기준   → 이전 ZFN 대비 설계 비용 99% 감소
④ 이중가닥 절단 (DSB)

💬 직접 인용:
   "These results...establish an RNA-programmable genome editing
   technology." (p. 823)

🤔 내 생각:
   gRNA만 바꾸면 어떤 유전자도 편집 가능 → 치료 가능성 무한
   BUT 오프타겟 효과 문제 → 다음 논문(Ran 2013)에서 확인 필요

🔗 연결: → Ran et al. 2013 (오프타겟 감소 전략)
         → 진단 적용: Sherlock 시스템(2017)
```

# 18-3. Research Notes — 흔한 실수 & ✍️ 실습

**흔한 실수 ❌**
- 논문 전체를 **요약만** 하고 "내 생각" 생략 → 분석 역량 미발달
- 인용구 출처(페이지)를 나중에 찾으려 함 → **그 자리에서 기록**
- 첫 번째 논문만 읽고 리서치 종료 → **연결(Links) 칸**이 논문 확장의 씨앗
- 너무 많이 기록 → 핵심 주장 + 인용 3개 이하로 제한

**🎓 Ivy Tip — Yale 문과 선배 노하우**
> "나는 'My Response' 칸을 가장 먼저 채운다. 억지로라도 동의 또는 반박 1문장을 써야 진짜 읽은 것이다. 그 문장이 에세이 thesis가 된다."
— Yale '26, 역사학 전공

✍️ **실습**: 관심 있는 주제로 논문 1편 찾아서(Google Scholar) Research Note 1장 완성. My Response 칸에 **내 의견 2문장** 필수 작성.

> **InHero 추천 조합**: 수업 노트 → Cornell(종이) · Obsidian(디지털) / 암기 → Anki / 프로젝트 관리 → Notion

# 19-1. Digital Notes — Obsidian 워크플로우

**Obsidian이 아이비리그에서 압도적 이유**

```
일반 노트앱:   파일 → 파일 → 파일   (독립된 섬들)

Obsidian:      파일 ── 파일
                │        │
               파일 ── 파일 ── 파일
               (지식 그래프 — 연결이 곧 이해)
```

**핵심 기능 3가지**
1. **[[쌍괄호 링크]]** — 단어 앞뒤에 [[ ]] 붙이면 다른 노트로 연결
2. **Graph View** — 내 지식 연결망을 시각화 (학기 끝에 그래프가 빽빽해짐)
3. **Backlinks** — "이 개념이 어디서 등장했나" 역추적

`[그림: 실제 Obsidian 그래프뷰 — 노드들이 거미줄처럼 연결된 스크린샷]`

🎓 **Ivy Tip**: Columbia 컴사이언스 학생: "노트 500개를 6개월 모으면 그래프가 교과서보다 내 머리 구조를 더 잘 보여준다."

# 19-2. Digital Notes — Anki 플래시카드 워크플로우

**Anki의 핵심: 간격 반복 (Spaced Repetition)**

```
기억 곡선 없이:  배움 → 망각 → 재학습 (반복)
  100% │＼
       │  ＼___    ← 급격히 잊음
       └──────── 시간

Anki 간격 반복:  복습 타이밍이 잊기 직전
  100% │＼ /＼ /＼ /───→  ← 장기기억 형성
       └────────────── 시간
```

**카드 만들기 원칙 (3가지)**
1. **1카드 1개념** — 한 장에 여러 개 넣으면 연결이 아닌 덩어리 암기
2. **이미지 포함** — 그림 있는 카드가 기억률 1.4배 높음 (연구 결과)
3. **내가 만들 것** — 인터넷 덱 다운로드 X → 직접 만들어야 학습이 됨

✍️ **실습**: Cornell 노트 단서 열 키워드 5개 → Anki 카드 5장으로 변환

# 강의 20 · Second Brain 구축 — PARA 시스템

## PARA란?

> **"모든 정보는 4개 버킷에 들어간다"** — Tiago Forte, *Building a Second Brain* (2022)

```
P — Projects  (프로젝트)   : 데드라인 있는 진행 중 일
A — Areas     (영역)       : 지속 관리하는 책임 영역
R — Resources (자료)       : 언젠가 쓸 참고 자료
A — Archive   (아카이브)   : 완료·비활성 항목
```

**핵심 원칙**: 자료를 **주제(Topic)** 가 아니라 **행동 가능성(Actionability)** 으로 분류한다.

| 버킷 | 시간 지평 | 예시 |
|---|---|---|
| Projects | 지금 ~ 3개월 | AP Bio 내신, Common App 작성, 리서치 페이퍼 |
| Areas | 지속 | 학업, 건강, 과외활동, 독서 |
| Resources | 언젠가 | CRISPR 논문 모음, 글쓰기 팁, 코딩 레퍼런스 |
| Archive | 완료 | 제출한 에세이, 끝난 학기 노트, 지난 프로젝트 |

# 흔한 실수 & FAQ (종합)

**❌ 가장 흔한 실수 TOP 5**
1. 노트를 예쁘게 쓰려고 시간 낭비 → 노트는 **도구**, 갤러리가 아님
2. 하나의 방식만 고집 → 과목·목적에 따라 **조합**
3. 나중에 정리하려고 모아둠 → **24시간 규칙** (강의 후 당일 단서 열 채우기)
4. 디지털 도구를 너무 많이 씀 → **하나 깊게** (Notion + Obsidian 중 하나로 시작)
5. 노트를 만들고 복습 안 함 → 노트는 **만드는 게 아니라 읽는 것**

**Q. 영어로 노트해야 하나요?**
A. 처리 속도가 더 빠른 언어로. 개념 이해 중: 한국어. 논문 읽기·영어 수업: 영어. 단, 인용구는 **원문 그대로** 기록.

**Q. 손글씨 vs 타이핑 — 뭐가 더 좋나요?**
A. 연구(Mueller & Oppenheimer, 2014): **손글씨가 이해도 높음** (받아쓰기 강제 없음 → 요약 강제). 강의 중: 손글씨, 복습 정리: 타이핑 조합 추천.
