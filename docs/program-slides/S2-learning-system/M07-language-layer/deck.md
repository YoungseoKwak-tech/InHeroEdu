# 0-1. 두 문제를 분리하는 진단 (자가 테스트)

**지금 바로 해보기 — 같은 문제를 두 번 푼다**

> *"Evaluate the impact of monetary policy on aggregate demand."*

| 단계 | 질문 | 내 대답 |
|---|---|---|
| ① 한국어로 | 이 문제가 무슨 뜻인지 한국어로 설명할 수 있나? | Yes / No |
| ② 한국어로 | 답의 핵심 논리를 한국어로 쓸 수 있나? | Yes / No |
| ③ 영어로 | 그 논리를 영어 문장으로 옮길 수 있나? | Yes / No |

**결과 해석**
- ①②No → **개념 문제** → 내용 공부가 먼저
- ①②Yes, ③No → **언어 레이어 문제** → 이 모듈이 직접 해결
- ①②③Yes → 이미 Language Layer 통과

🎓 **Ivy Tip**: 매주 이 3단계 진단을 과목별로 돌려라. Cornell 재학 유학생 이민준(Cornell '25, 생물)은 "과목마다 ③에서 막히는 단어가 다르다. 진단을 매주 했더니 6주 만에 과학 영어 블록이 사라졌다"고 했다.

# 1. 강의 27 · 영어와 개념 분리하기

**핵심 원리: 모국어로 생각하고 영어로 출력한다**

```
[잘못된 경로]
영어 문제 읽기 → 영어로 생각 → 영어로 답 쓰기
       ↑ 영어 실수 + 개념 혼선 = 이중 부하(cognitive overload)

[InHero 경로]
영어 문제 읽기 → 한국어로 변환 → 한국어로 추론 → 영어로 번역·출력
                  ↑ 2초           ↑ 핵심 단계      ↑ 훈련 가능
```

- 이중 언어 인지 부하 연구(Baddeley, 1986): 외국어로 생각하면 **작업 기억(working memory)의 30–40%를 언어 처리에 낭비**한다.
- 해결책: 언어 처리를 **자동화**해 인지 자원을 개념 추론에 집중.

🎓 **Ivy Tip 1**: Harvard 한인 유학생 스터디 그룹에서 실제로 쓰는 방법 — "머릿속에서 한국어로 풀고 영어로 받아쓰기." 이 그룹에서 AP 5점 취득률이 92%였다(2023 자체 집계).

🎓 **Ivy Tip 2**: 이 루틴을 연습하려면 **매일 AP 문제 1개**를 한국어로 먼저 풀고 그다음 영어 답안을 쓰는 연습을 4주간 지속하라. 4주 후 "한→영 번역" 단계가 자동화된다.

🎓 **Ivy Tip 3**: Columbia 재학 유학생 최서연(Columbia '26, 정치학) — "논술 수업에서 교수가 'write a draft in any language first'라고 했는데, 한국어 초안을 먼저 쓰면 구조가 훨씬 선명해진다."

# 1-1. "영어→한국어→영어" 변환 루틴

**3단계 변환 스크립트 (시험장 즉시 적용)**

```
STEP 1 [10초]: 문제의 핵심 동사와 명사만 마킹
               "Evaluate the IMPACT of MONETARY POLICY on AGGREGATE DEMAND"
                ↓
STEP 2 [10초]: 한국어로 재구성
               "통화정책이 총수요에 미치는 영향을 평가하라"
                ↓
STEP 3 [답안 작성]: 한국어 논리 구조 잡기 → 영어로 1:1 번역
               한국어 초안: "금리 인하 → 소비·투자 증가 → AD 우측 이동"
               영어 출력: "A decrease in interest rates stimulates consumption
                          and investment, shifting AD rightward."
```

🎓 **Ivy Tip 1**: 시험지 여백은 나만 보는 메모장이다. 채점관은 답만 본다. 과정은 어떤 언어로 써도 된다. — Yale 재학 유학생 인터뷰

🎓 **Ivy Tip 2**: STEP 1에서 핵심 동사·명사만 서클 표시하는 습관을 들여라. AP Chem FRQ 연습 시 실제로 마킹하면 문제 독해 오류가 70% 줄어든다(Princeton Review 내부 데이터).

🎓 **Ivy Tip 3**: STEP 3의 "영어 출력"은 동의어 사전(Merriam-Webster Thesaurus)을 쓰면 어휘 단조로움을 피할 수 있다. AP Lang & Comp 고득점자들은 이 습관을 연습 단계에서부터 들인다.

# 1-3. 지시동사 (Command Terms) — 유학생 최대 함정

**같은 문제인데 다른 걸 묻는 동사들**

| 동사 | 뜻 | 요구하는 것 | 흔한 실수 |
|---|---|---|---|
| **Define** | 정의하라 | 공식 정의 1–2문장 | 설명·예시까지 씀 |
| **Describe** | 묘사하라 | 특징·과정 나열 | 분석을 시작함 |
| **Explain** | 설명하라 | 원인·메커니즘 | Describe처럼 나열 |
| **Evaluate** | 평가하라 | 장단점·근거·판단 | 단순 설명으로 끝냄 |
| **Analyse** | 분석하라 | 요소·패턴·관계 | 판단(evaluate) 추가함 |
| **Justify** | 정당화하라 | 근거 제시·왜 맞나 | 반론 무시 |
| **Derive** | 유도하라 | 수식 단계별 전개 | 답만 씀 |
| **Outline** | 개요 쓰라 | 핵심만 간결하게 | 에세이 분량으로 씀 |
| **Compare** | 비교하라 | 공통점 + 차이점 | 차이점만 나열 |
| **Contrast** | 대조하라 | 차이점만 | 공통점까지 씀 |

---

# 1-4. 지시동사 답안 분량 기준

```
짧음 ←──────────────────────────────→ 길음

Define    Outline    Describe    Explain    Analyse    Evaluate
1–2문장   3–5줄      5–8줄       1단락       2–3단락     3–4단락+판단
```

**IB 채점관이 공개한 기준 (IB Examiner Report, 2024)**
- "Evaluate"를 "Describe"처럼 쓴 답안 → 자동으로 중간 밴드 이하
- "Justify"에서 반론을 다루지 않으면 → 최대 3/6점

🎓 **Ivy Tip 1**: AP FRQ도 동일 — "Explain"에서 인과관계(because, therefore, as a result)가 없으면 0점 처리.

🎓 **Ivy Tip 2**: IB 시험 전날, 지시동사 8개를 플래시카드로 각각 10초 안에 "분량 기준 + 포함 요소"를 말할 수 있을 때까지 돌려라. Penn 합격생 김민아(UPenn '27) — "이거 전날 밤에 외웠더니 시험장에서 동사 보는 순간 자동으로 답 틀이 잡혔다."

🎓 **Ivy Tip 3**: "Compare"는 반드시 공통점을 1개 이상 포함해야 한다. IB History 채점관 코멘트(2023 Examiner Report) — "Compare 문항에서 차이점만 쓴 답안은 최고 4/8점."

# 2. 강의 28 · 수학 영어 정복

**수학은 "언어"보다 "기호"가 먼저지만, 영어 문장이 함정이다**

```
흔한 함정 문장:
"Find the value of x such that f(x) is maximized, given that x ≥ 0."
                     ↑                              ↑
               "such that" = "이때"          "given that" = "주어진 조건 ~"

→ 한국어: "x ≥ 0 조건에서 f(x)가 최대가 되는 x 값을 구하라."
```

**수학 영어의 특징**
- 실제 계산 난이도와 언어 난이도가 **반드시 비례하지 않는다.**
- 짧은 영어 문장이 오히려 더 많은 수학 조건을 숨긴다.

🎓 **Ivy Tip 1**: MIT 수학과 합격생 이준혁(MIT '26) — "AP Calc BC FRQ에서 'such that'을 '그래서'로 해석해서 조건을 빠뜨리고 틀렸다. 이 단어 하나가 4점짜리 문제를 0점으로 만들었다."

🎓 **Ivy Tip 2**: AP Calculus BC FRQ에서 가장 자주 나오는 핵심 동사 10개: **find, determine, calculate, show, justify, verify, approximate, evaluate, write, express.** 이 10개의 미묘한 차이를 알면 FRQ 독해에서 실수가 사라진다.

🎓 **Ivy Tip 3**: "Show that" = 수식을 단계별로 써야 하며 답만 쓰면 0점. "Verify" = 이미 주어진 답이 맞음을 증명하는 것. 두 단어는 완전히 다른 작업이다.

# 2-1. 수학 핵심 용어 한영 대조표

| 한국어 | 영어 | 자주 쓰이는 문장 패턴 |
|---|---|---|
| 미분하다 | differentiate / derive | "Differentiate f(x) with respect to x." |
| 적분하다 | integrate | "Evaluate the integral from 0 to π." |
| 극값 (최대/최소) | extremum / max / min | "Find the local maximum of f." |
| 연속 | continuous | "Show that f is continuous at x = 2." |
| 수렴 | converge | "Determine whether the series converges." |
| 증명하라 | prove / show that | "Prove that n² + n is always even." |
| ~를 구하라 | find / determine / calculate | "Find all values of x such that…" |
| 나머지 | remainder | "Find the remainder when divided by 7." |
| 공약수 | common factor / GCD | "Find the greatest common divisor." |
| 이항 | binomial | "Expand using the binomial theorem." |
| 점화식 | recurrence relation | "Given the recurrence relation aₙ = …" |
| 단조 증가 | monotonically increasing | "Show f is monotonically increasing." |
| 임계점 | critical point | "Find all critical points of f." |
| 변곡점 | inflection point | "Determine the inflection points of f." |
| 오목/볼록 | concave up / concave down | "f is concave up when f'' > 0." |

# 2-2. 수학 함정 표현 & 번역 오류 주의

**"such that" vs "so that" vs "given that"**

| 표현 | 의미 | 예시 |
|---|---|---|
| **such that** | ~인 (조건 한정) | "Find x such that f(x) = 0" → f(x)=0인 x |
| **given that** | ~임을 전제로 | "Given that x > 0, find…" → x>0 전제 |
| **so that** | 목적 (~되도록) | "Choose n so that the sum exceeds 100" |
| **provided that** | ~이면 (조건부) | "The formula holds provided that n ≥ 1" |
| **in terms of** | ~에 대한 식으로 | "Express y in terms of x" → x로 나타내라 |
| **with respect to** | ~에 대해 (미분·적분) | "Differentiate with respect to t" |

**숫자 표현 함정**
```
"at least 3"   → 3 이상 (≥ 3), 3 포함 O
"at most 3"    → 3 이하 (≤ 3), 3 포함 O
"more than 3"  → 3 초과 (> 3), 3 포함 X
"fewer than 3" → 3 미만 (< 3), 3 포함 X
"no more than" → 이하 (≤)   "no less than" → 이상 (≥)
```

# 2-3. 📝 채워진 예시 — AP Calculus FRQ 독해

**원문 문제 (AP Calc BC 2023)**
> *"Let f be a twice-differentiable function such that f(2) = 5 and f'(2) = 3. The graph of the line tangent to f at x = 2 is used to approximate values of f. For what values of x will the linear approximation give an overestimate? Justify your answer."*

**유학생 독해 스크립트**
```
1. "twice-differentiable" → 두 번 미분 가능 (f'' 존재)
2. "tangent to f at x=2" → x=2에서의 접선
3. "linear approximation" → 선형 근사 (L(x) = f(2) + f'(2)(x-2))
4. "overestimate" → 근사값이 실제값보다 클 때
5. "Justify" → 이유 제시 (f''의 부호 판별 필요)
```

🎓 **Ivy Tip**: "Justify your answer"는 AP에서 가장 많이 나오는 지시 표현 중 하나. 반드시 f''의 부호를 언급하며 "The linear approximation is an overestimate because f''(x) < 0 (concave down) in this region"처럼 **인과 문장**으로 마무리해야 한다. 결론만 쓰면 0점.

```
유학생 평균 영어 독해 속도:  120–160 wpm
시험 요구 속도 (AP/IB):      180–220 wpm (지문 + 문제 포함)

속도 손실 주요 원인:
  40%  모르는 단어마다 멈춰서 생각
  30%  한 문장을 여러 번 다시 읽음 (re-reading loop)
  20%  긴 명사구·수동태 구조 파악 시간
  10%  집중력 분산
```

**이 강의의 목표: 180 wpm 이상으로 끌어올리는 3가지 기법**

🎓 **Ivy Tip 1**: Princeton 입학생 조사(2024) — "입학 전 영어 독해 속도가 180 wpm 이상인 국제학생의 GPA 1학년 평균이 160 wpm 미만 학생보다 0.4점 높았다." 독해 속도는 성적에 직결된다.

🎓 **Ivy Tip 2**: AP SAT Reading에서 주어진 시간 내에 지문 + 문제를 처리하려면 **지문 읽기 3분 30초, 문제 풀기 5분 30초** 배분이 최적이다. 이 배분을 맞추려면 지문 독해 속도 최소 175 wpm이 필요하다.

# 5-1. 기법 1 · Chunking (청킹)

**단어 하나씩이 아니라 "의미 덩어리"로 읽는다**

```
[단어 단위 읽기 — 느림]
The / rate / of / reaction / increases / with / temperature.

[청킹 읽기 — 빠름]
"The rate of reaction" / "increases" / "with temperature."
─────────────────────   ────────────   ──────────────────
   주어 덩어리 (명사구)    동사 핵심      이유/조건 덩어리
```

**청킹 훈련 3단계**
1. 매일 AP/IB 지문 1개 읽으며 슬래시(/) 표시
2. 명사구, 동사구, 전치사구 3가지만 구별
3. 2주 후: 슬래시 없이 눈이 자동으로 덩어리 인식

🎓 **Ivy Tip 1**: Princeton 글쓰기 센터에서 비영어권 학생에게 권장하는 첫 번째 속독 훈련이 바로 이 청킹이다.

🎓 **Ivy Tip 2**: 청킹 속도를 측정하려면 **ReadingSoft.com** 또는 **Spreeder.com** — 무료 wpm 측정 사이트. 매주 월요일 측정해서 그래프 그려라. 숫자가 보여야 동기가 유지된다.

🎓 **Ivy Tip 3**: Yale 글쓰기 프로그램 튜터(국제학생 담당) 인터뷰 — "청킹보다 더 빠른 방법은 없다. 하지만 이게 자동화되려면 최소 3주, 매일 15분 연습이 필요하다. 단기 집중은 효과 없다."

# 5-2. 기법 2 · 모르는 단어 처리법 (2초 룰)

**모르는 단어에서 멈추지 않는 시스템**

```
모르는 단어 발견!
        ↓
    2초 판단
   ┌────┴────┐
  핵심어?  주변어?
   │         │
  표시 후   무시하고
  계속 읽기  계속 읽기
      ↓
   문단 끝나면 문맥으로 추론
```

**핵심어 vs 주변어 판별법**
| 핵심어 | 주변어 |
|---|---|
| 동사, 주어, 목적어 위치 | 형용사 수식어, 부사 |
| 없으면 문장 의미 완전 붕괴 | 없어도 대략 이해 가능 |
| 반복해서 나오는 단어 | 한 번만 나오는 단어 |

🎓 **Ivy Tip 1**: AP English Lang에서 모르는 단어를 만났을 때 **어근 분석**이 가장 빠르다. "bene-"(좋다), "mal-"(나쁘다), "-ology"(학문), "-tion"(명사화). 이 20개 어근만 알면 모르는 단어 70%를 유추할 수 있다.

🎓 **Ivy Tip 2**: Cornell 입학생 이민준 — "SAT Reading에서 모르는 단어는 밑줄 긋고 넘겼다. 나중에 문맥으로 유추했더니 8개 중 6개를 맞게 유추했다. 멈추는 것보다 유추가 낫다."

# 5-3. 기법 3 · Skimming & Scanning

**Skimming (훑기) — 전체 구조 파악**

```
목적: "이 지문이 무엇에 관한 글인가?"
방법:
  ① 첫 문단 전체 읽기 (주제 파악)
  ② 각 단락의 첫 문장만 읽기 (단락 주제문)
  ③ 마지막 문단 전체 읽기 (결론)
  ④ 그래프·표·이탤릭체·굵은 글씨 체크
소요시간: 500단어 지문 기준 약 40초
```

**Scanning (찾기) — 특정 정보 추출**

```
목적: "특정 수치/사건/이름을 빠르게 찾는다"
방법:
  ① 찾을 키워드 머릿속에 고정
  ② 눈을 Z자/S자 패턴으로 이동
  ③ 키워드와 유사한 형태 발견 시 즉시 멈춤
  ④ 주변 문장만 꼼꼼히 읽기
```

🎓 **Ivy Tip**: "Reading은 passive가 아니다. 펜 들고 능동적으로 표시하면서 읽어야 속도가 는다." — Columbia Writing Fellow 조언. AP DBQ 지문에서 첫 skimming 40초를 아끼려다 전체 구조를 못 잡으면 더 오래 걸린다.

# 5-4. 읽기 속도 향상 4주 루틴

| 주차 | 훈련 내용 | 목표 속도 | 소요 시간/일 |
|---|---|---|---|
| 1주 | 청킹 표시 훈련 + 모르는 단어 2초 룰 | 140 wpm | 15분 |
| 2주 | Skimming 먼저 → 전체 읽기 순서 연습 | 160 wpm | 15분 |
| 3주 | AP/IB 기출 지문 타이머 독해 | 175 wpm | 20분 |
| 4주 | 모의시험 조건 전체 독해 | 185+ wpm | 20분 |

**속도 측정법**
```
(단어 수) ÷ (읽은 시간(분)) = wpm

AP US History DBQ 지문 평균: 약 600단어
목표: 600 ÷ 3.3분 = 182 wpm → 충분히 달성 가능
```

🎓 **Ivy Tip**: wpm 측정 앱 추천 — **Readlang** (Chrome 확장, 웹 기사 실시간 wpm 측정), **Spreeder** (텍스트 붙여넣기 후 속도 조절 훈련). AP 기출 지문을 직접 붙여넣어 연습하면 가장 효과적이다.

# 5-5. 장르별 읽기 전략 요약

| 장르 | 추천 접근 | 핵심 포인트 |
|---|---|---|
| 수학 문제 | 천천히, 전체 읽기 | 조건 하나도 빠트리면 안 됨 |
| 과학 실험 지문 | Skimming 후 → 데이터 집중 | 그래프·표가 핵심, 본문은 보조 |
| 역사 지문 | Scanning으로 날짜·이름 | 주장(claim) 먼저 찾기 |
| 경제 에세이 문제 | 지시동사 먼저 마킹 | "Evaluate"냐 "Explain"이냐가 전략 결정 |
| SAT Reading | Passage map 그리기 | 문단별 3단어 요약 여백에 메모 |
| AP Lang FRQ | 지문 읽기 전 문제 먼저 읽기 | 무엇을 찾아야 할지 알면 scanning이 빠름 |

🎓 **Ivy Tip 1**: SAT Reading에서 "Passage Map"은 각 문단을 3단어로 요약해 여백에 적는 것이다. 10초면 되고, 이게 있으면 특정 문단 돌아갈 때 전체 다시 읽는 시간이 사라진다.

🎓 **Ivy Tip 2**: Brown 재학 유학생 김채원(Brown '25, 영문학) — "AP Lang 지문은 문제를 먼저 30초 읽은 후 지문 읽기를 시작했다. 뭘 찾아야 하는지 알면 능동적으로 읽어서 속도가 20% 빨라졌다."

# 🎓 실전 꿀팁 모음 — 강의 31 (읽기 속도)

- **꿀팁 1**: 매일 **뉴욕타임스 또는 BBC** 기사 1편(500~800단어)을 타이머 켜고 읽어라. 처음엔 이해율 70%여도 된다. 3주 후 이해율이 90%로 올라가면 속도가 자연히 올라간 것.
- **꿀팁 2**: **Readlang.com** — 웹 기사 읽으면서 모르는 단어 클릭하면 번역 + 자동 Anki 덱 추가. 속독 훈련과 단어 암기를 동시에.
- **꿀팁 3**: AP Biology 지문처럼 명사구가 긴 과학 텍스트는 **동사를 먼저 찾아라.** 동사를 찾으면 주어와 목적어가 자동으로 보인다. 명사구가 길어도 동사 하나가 문장의 핵심.
- **꿀팁 4**: Princeton 재학 유학생 오지훈(Princeton '27, 물리학) — "AP Physics C 시험 지문을 원어민 속도(250 wpm)로 읽으려다 실수가 늘었다. 내게 최적 속도는 185 wpm이었다. 무조건 빠른 게 아니라 정확하게 빠른 게 목표."
- **꿀팁 5**: **Spreeder.com** — 속도 훈련 전용 사이트. AP 기출 지문 텍스트를 붙여넣고 150 wpm → 175 wpm → 200 wpm으로 단계적 훈련. 눈이 빠른 텍스트에 익숙해진다.
- **꿀팁 6**: SAT Reading에서 지문 마지막 문장은 항상 정독하라. 저자의 핵심 주장이 대부분 마지막 문장에 담겨 있다. 이것만으로 "main idea" 문제의 80%가 풀린다.
- **꿀팁 7**: re-reading loop(한 문장을 여러 번 다시 읽는 습관)을 끊는 방법 — 각 문장을 읽을 때 **오른손 손가락으로 읽는 줄을 가볍게 따라가라**. 신체적 앵커가 re-reading을 물리적으로 방지한다.
- **꿀팁 8**: 속독 훈련 기록표를 만들어라. 날짜 / 지문 제목 / wpm / 이해율(%) 3개 컬럼. 4주치 데이터를 보면 어느 날 더 집중했는지, 어느 지문 유형이 느린지가 보인다.

# 6. Language Toolkit — 통합 체크리스트

**시험장 입장 전 2분 체크리스트**

```
□ 지시동사 확인: Evaluate / Explain / Derive / Justify 중 어느 것?
□ 답안 분량 확인: 해당 동사에 맞는 분량인가?
□ 모르는 단어: 핵심어인지 주변어인지 판단했나?
□ 한국어 변환: 문제를 한국어로 재구성했나?
□ 한국어 논리: 한국어로 답의 구조를 잡았나?
□ 영어 출력: 1:1 번역으로 깔끔하게 옮겼나?
□ 키워드 포함: 해당 과목 핵심 용어가 영어로 들어갔나?
□ 문장 구조: "As…, … because…" 인과 패턴 사용했나?
□ 반론 포함: "Evaluate/Justify"라면 반론 1개 이상 있나?
□ 인과 연결어: "therefore," "as a result," "because" 있나?
```

🎓 **Ivy Tip**: 이 체크리스트를 A6 카드에 인쇄해서 시험장 입장 직전까지 보라. Harvard 합격생 강다은 — "시험 전날 이 목록을 머릿속으로 읊으면서 잠들었다. 시험장에서 체크리스트가 자동으로 떠올랐다."

# 6-1. 자기 점검 루브릭 (제출 전)

| 항목 | 미달 | 통과 |
|---|---|---|
| 지시동사 이해 | 10개 중 6개 미만 | 10개 모두 + 분량 기준 암기 |
| 수학 용어 | 표 절반 이상 모름 | 표 80% 이상 즉답 |
| 과학 용어 | 수동태 구조 혼선 | 주요 표현 패턴 3개 습득 |
| 사회 용어 | 일상 뜻으로 해석 | 전문 의미로 즉시 전환 |
| 읽기 속도 | 140 wpm 미만 | 175 wpm 이상 (4주 후) |

# 6-2. 흔한 실수 & FAQ

**가장 많이 하는 실수**
- "Evaluate"를 "Explain"처럼 쓰는 것 → 반드시 **판단문(judgment)** 포함
- 수학 조건에서 "at least"와 "more than" 혼동 → **포함 여부**가 핵심
- 과학에서 "rate" 혼자 쓰기 → "rate of [무엇]"으로 명시
- 사회과학에서 전문 용어 없이 일상 언어로 쓰기 → 채점 키워드 누락
- "prove"를 과학 답안에 쓰기 → "support" / "suggest"로 바꿔라
- "Compare"에서 공통점 빠뜨리기 → 최고 4/8점

**FAQ**

**Q. 영어 문법이 틀리면 감점되나?**
A. AP/IB는 내용 채점이 주다. 의미가 전달되면 문법 오류는 대체로 허용. 단, 핵심 용어 스펠링은 정확해야 한다(예: "equilibrium" → "equilbrium" X).

**Q. 한국어로 생각하면 시간이 더 걸리지 않나?**
A. 처음 2주는 그렇다. 3주차부터 한→영 변환이 자동화되며 오히려 오류가 줄어 총 답안 작성 시간이 단축된다.

**Q. Anki vs Quizlet 뭐가 나은가?**
A. 장기 암기는 Anki(스페이스드 리피티션 알고리즘 우수), 공유 덱 찾기는 Quizlet(공개 덱 수가 훨씬 많음). 두 개 병행하되 Anki를 메인으로 쓰는 것을 권장.

# 🎓 실전 꿀팁 모음 — 통합 (Language Toolkit)

- **꿀팁 1**: Language Toolkit 노트는 **살아있는 문서**다. 시험 전날까지 새로 모르는 단어·표현이 나올 때마다 추가해라. 고정된 노트는 죽은 노트다.
