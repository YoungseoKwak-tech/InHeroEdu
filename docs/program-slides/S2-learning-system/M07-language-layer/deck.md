# 1. 강의 27 · 영어와 개념 분리하기

**핵심 원리: 모국어로 생각하고 영어로 출력한다**

```
[잘못된 경로]
영어 문제 읽기 → 영어로 생각 → 영어로 답 쓰기
       ↑ 영어 실수 + 개념 혼선 = 이중 부하(cognitive overload)

[InHero 경로]
영어 문제 읽기 → 한국어로 변환 → 한국어로 추론 → 영어로 번역·출력
                  ↑ 2초           ↑ 핵심 단계      ↑ 훈련 가능
```

- 이중 언어 인지 부하 연구(Baddeley, 1986): 외국어로 생각하면 **작업 기억(working memory)의 30–40%를 언어 처리에 낭비**한다.
- 해결책: 언어 처리를 **자동화**해 인지 자원을 개념 추론에 집중.

# 1-1. "영어→한국어→영어" 변환 루틴

**3단계 변환 스크립트 (시험장 즉시 적용)**

```
STEP 1 [10초]: 문제의 핵심 동사와 명사만 마킹
               "Evaluate the IMPACT of MONETARY POLICY on AGGREGATE DEMAND"
                ↓
STEP 2 [10초]: 한국어로 재구성
               "통화정책이 총수요에 미치는 영향을 평가하라"
                ↓
STEP 3 [답안 작성]: 한국어 논리 구조 잡기 → 영어로 1:1 번역
               한국어 초안: "금리 인하 → 소비·투자 증가 → AD 우측 이동"
               영어 출력: "A decrease in interest rates stimulates consumption
                          and investment, shifting AD rightward."
```

# 1-3. 지시동사 (Command Terms) — 유학생 최대 함정

**같은 문제인데 다른 걸 묻는 동사들**

| 동사 | 뜻 | 요구하는 것 | 흔한 실수 |
|---|---|---|---|
| **Define** | 정의하라 | 공식 정의 1–2문장 | 설명·예시까지 씀 |
| **Describe** | 묘사하라 | 특징·과정 나열 | 분석을 시작함 |
| **Explain** | 설명하라 | 원인·메커니즘 | Describe처럼 나열 |
| **Evaluate** | 평가하라 | 장단점·근거·판단 | 단순 설명으로 끝냄 |
| **Analyse** | 분석하라 | 요소·패턴·관계 | 판단(evaluate) 추가함 |
| **Justify** | 정당화하라 | 근거 제시·왜 맞나 | 반론 무시 |
| **Derive** | 유도하라 | 수식 단계별 전개 | 답만 씀 |
| **Outline** | 개요 쓰라 | 핵심만 간결하게 | 에세이 분량으로 씀 |

---

# 1-4. 지시동사 답안 분량 기준

```
짧음 ←──────────────────────────────→ 길음

Define    Outline    Describe    Explain    Analyse    Evaluate
1–2문장   3–5줄      5–8줄       1단락       2–3단락     3–4단락+판단
```

**IB 채점관이 공개한 기준 (IB Examiner Report, 2024)**
- "Evaluate"를 "Describe"처럼 쓴 답안 → 자동으로 중간 밴드 이하
- "Justify"에서 반론을 다루지 않으면 → 최대 3/6점

🎓 **Ivy Tip**: AP FRQ도 동일 — "Explain"에서 인과관계가 없으면 0점 처리.

# 2. 강의 28 · 수학 영어 정복

**수학은 "언어"보다 "기호"가 먼저지만, 영어 문장이 함정이다**

```
흔한 함정 문장:
"Find the value of x such that f(x) is maximized, given that x ≥ 0."
                     ↑                              ↑
               "such that" = "이때"          "given that" = "주어진 조건 ~"

→ 한국어: "x ≥ 0 조건에서 f(x)가 최대가 되는 x 값을 구하라."
```

**수학 영어의 특징**
- 실제 계산 난이도와 언어 난이도가 **반드시 비례하지 않는다.**
- 짧은 영어 문장이 오히려 더 많은 수학 조건을 숨긴다.

---

# 2-1. 수학 핵심 용어 한영 대조표

| 한국어 | 영어 | 자주 쓰이는 문장 패턴 |
|---|---|---|
| 미분하다 | differentiate / derive | "Differentiate f(x) with respect to x." |
| 적분하다 | integrate | "Evaluate the integral from 0 to π." |
| 극값 (최대/최소) | extremum / max / min | "Find the local maximum of f." |
| 연속 | continuous | "Show that f is continuous at x = 2." |
| 수렴 | converge | "Determine whether the series converges." |
| 증명하라 | prove / show that | "Prove that n² + n is always even." |
| ~를 구하라 | find / determine / calculate | "Find all values of x such that…" |
| 나머지 | remainder | "Find the remainder when divided by 7." |
| 공약수 | common factor / GCD | "Find the greatest common divisor." |
| 이항 | binomial | "Expand using the binomial theorem." |
| 점화식 | recurrence relation | "Given the recurrence relation aₙ = …" |
| 단조 증가 | monotonically increasing | "Show f is monotonically increasing." |

---

# 2-2. 수학 함정 표현 & 번역 오류 주의

**"such that" vs "so that" vs "given that"**

| 표현 | 의미 | 예시 |
|---|---|---|
| **such that** | ~인 (조건 한정) | "Find x such that f(x) = 0" → f(x)=0인 x |
| **given that** | ~임을 전제로 | "Given that x > 0, find…" → x>0 전제 |
| **so that** | 목적 (~되도록) | "Choose n so that the sum exceeds 100" |
| **provided that** | ~이면 (조건부) | "The formula holds provided that n ≥ 1" |

**숫자 표현 함정**
```
"at least 3"   → 3 이상 (≥ 3), 3 포함 O
"at most 3"    → 3 이하 (≤ 3), 3 포함 O
"more than 3"  → 3 초과 (> 3), 3 포함 X
"fewer than 3" → 3 미만 (< 3), 3 포함 X
```

# 2-3. 📝 채워진 예시 — AP Calculus FRQ 독해

**원문 문제 (AP Calc BC 2023)**
> *"Let f be a twice-differentiable function such that f(2) = 5 and f'(2) = 3. The graph of the line tangent to f at x = 2 is used to approximate values of f. For what values of x will the linear approximation give an overestimate? Justify your answer."*

**유학생 독해 스크립트**
```
1. "twice-differentiable" → 두 번 미분 가능 (f'' 존재)
2. "tangent to f at x=2" → x=2에서의 접선
3. "linear approximation" → 선형 근사 (L(x) = f(2) + f'(2)(x-2))
4. "overestimate" → 근사값이 실제값보다 클 때
5. "Justify" → 이유 제시 (f''의 부호 판별 필요)
```

# 3. 강의 29 · 과학 영어 정복

**과학 영어의 3대 특징**
```
① 수동태가 압도적으로 많다
   "The reaction was carried out at 25°C."  ← 실험 서술
   "It was observed that…"                  ← 결과 서술

② 명사구가 길다
   "a concentration-dependent inhibition of enzyme activity"
   → "효소 활성의 농도 의존적 억제"

③ 같은 개념이 여러 이름으로 나온다
   "rate of reaction" = "reaction rate" = "speed of reaction"
```

🎓 **Ivy Tip**: MIT에서 한국인 유학생이 가장 많이 틀린 유형 — 수동태 해석 오류 + 명사구 순서 역전.

```

**평가(Evaluate) 답안에 반드시 들어가야 하는 구조**
- 찬성 근거 2개 이상 → 반론 1개 이상 → 판단문 1개

# 4-4. 📝 채워진 예시 — IB Economics Evaluate 문항

**문제:** *"Evaluate the effectiveness of fiscal policy in reducing unemployment."*

**유학생 독해 → 답안 구조 변환**

```
독해:
"Evaluate" → 장단점 + 판단 필요 (단순 설명 X)
"fiscal policy" → 재정정책 = 정부지출·조세
"reducing unemployment" → 실업 감소 효과

한국어 답안 구조:
① 장점: 총수요 자극 → 경기적 실업 감소 (AD-AS 모델)
② 장점: 직접 일자리 창출 가능
③ 단점: 시간 지연(time lag), 구조적 실업엔 한계
④ 판단: "단기적으로는 효과적이나 장기적 구조 개혁 없이는 한계"

영어 출력: 위 구조를 1:1 번역
```

# 5. 강의 31 · 읽기 속도 향상

**국제학생의 독해 속도 손실 원인 분석**

```
일반 영어 원어민 독서 속도:  250–300 wpm (words per minute)
유학생 평균 영어 독해 속도:  120–160 wpm
시험 요구 속도 (AP/IB):      180–220 wpm (지문 + 문제 포함)

속도 손실 주요 원인:
  40%  모르는 단어마다 멈춰서 생각
  30%  한 문장을 여러 번 다시 읽음 (re-reading loop)
  20%  긴 명사구·수동태 구조 파악 시간
  10%  집중력 분산
```

**이 강의의 목표: 180 wpm 이상으로 끌어올리는 3가지 기법**

---

# 5-1. 기법 1 · Chunking (청킹)

**단어 하나씩이 아니라 "의미 덩어리"로 읽는다**

```
[단어 단위 읽기 — 느림]
The / rate / of / reaction / increases / with / temperature.

[청킹 읽기 — 빠름]
"The rate of reaction" / "increases" / "with temperature."
─────────────────────   ────────────   ──────────────────
   주어 덩어리 (명사구)    동사 핵심      이유/조건 덩어리
```

**청킹 훈련 3단계**
1. 매일 AP/IB 지문 1개 읽으며 슬래시(/) 표시
2. 명사구, 동사구, 전치사구 3가지만 구별
3. 2주 후: 슬래시 없이 눈이 자동으로 덩어리 인식

🎓 **Ivy Tip**: Princeton 글쓰기 센터에서 비영어권 학생에게 권장하는 첫 번째 속독 훈련.

---

# 5-2. 기법 2 · 모르는 단어 처리법 (2초 룰)

**모르는 단어에서 멈추지 않는 시스템**

```
모르는 단어 발견!
        ↓
    2초 판단
   ┌────┴────┐
  핵심어?  주변어?
   │         │
  표시 후   무시하고
  계속 읽기  계속 읽기
      ↓
   문단 끝나면 문맥으로 추론
```

**핵심어 vs 주변어 판별법**
| 핵심어 | 주변어 |
|---|---|
| 동사, 주어, 목적어 위치 | 형용사 수식어, 부사 |
| 없으면 문장 의미 완전 붕괴 | 없어도 대략 이해 가능 |
| 반복해서 나오는 단어 | 한 번만 나오는 단어 |

---

# 5-3. 기법 3 · Skimming & Scanning

**Skimming (훑기) — 전체 구조 파악**

```
목적: "이 지문이 무엇에 관한 글인가?"
방법:
  ① 첫 문단 전체 읽기 (주제 파악)
  ② 각 단락의 첫 문장만 읽기 (단락 주제문)
  ③ 마지막 문단 전체 읽기 (결론)
  ④ 그래프·표·이탤릭체·굵은 글씨 체크
소요시간: 500단어 지문 기준 약 40초
```

**Scanning (찾기) — 특정 정보 추출**

```
목적: "특정 수치/사건/이름을 빠르게 찾는다"
방법:
  ① 찾을 키워드 머릿속에 고정
  ② 눈을 Z자/S자 패턴으로 이동
  ③ 키워드와 유사한 형태 발견 시 즉시 멈춤
  ④ 주변 문장만 꼼꼼히 읽기
```

# 5-4. 읽기 속도 향상 4주 루틴

| 주차 | 훈련 내용 | 목표 속도 | 소요 시간/일 |
|---|---|---|---|
| 1주 | 청킹 표시 훈련 + 모르는 단어 2초 룰 | 140 wpm | 15분 |
| 2주 | Skimming 먼저 → 전체 읽기 순서 연습 | 160 wpm | 15분 |
| 3주 | AP/IB 기출 지문 타이머 독해 | 175 wpm | 20분 |
| 4주 | 모의시험 조건 전체 독해 | 185+ wpm | 20분 |

**속도 측정법**
```
(단어 수) ÷ (읽은 시간(분)) = wpm

AP US History DBQ 지문 평균: 약 600단어
목표: 600 ÷ 3.3분 = 182 wpm → 충분히 달성 가능
```

# 6. Language Toolkit — 통합 체크리스트

**시험장 입장 전 2분 체크리스트**

```

□ 키워드 포함: 해당 과목 핵심 용어가 영어로 들어갔나?
□ 문장 구조: "As…, … because…" 인과 패턴 사용했나?

# 6-2. 흔한 실수 & FAQ

**❌ 가장 많이 하는 실수**
- "Evaluate"를 "Explain"처럼 쓰는 것 → 반드시 **판단문(judgment)** 포함
- 수학 조건에서 "at least"와 "more than" 혼동 → **포함 여부**가 핵심
- 과학에서 "rate" 혼자 쓰기 → "rate of [무엇]"으로 명시
- 사회과학에서 전문 용어 없이 일상 언어로 쓰기 → 채점 키워드 누락

**FAQ**

**Q. 영어 문법이 틀리면 감점되나?**
A. AP/IB는 내용 채점이 주다. 의미가 전달되면 문법 오류는 대체로 허용. 단, 핵심 용어 스펠링은 정확해야 한다(예: "equilibrium" → "equilbrium" X).

**Q. 한국어로 생각하면 시간이 더 걸리지 않나?**
A. 처음 2주는 그렇다. 3주차부터 한→영 변환이 자동화되며 오히려 오류가 줄어 총 답안 작성 시간이 단축된다.
