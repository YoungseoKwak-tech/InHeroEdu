# 0. 왜 AI 사용법이 핵심 스킬인가

```
2019년 이전:  구글 검색 → 블로그 긁기 → 복붙
2025년 현재:  AI 답변 → 그대로 제출 → (표절·이해 0)
InHero 경로:  AI를 코치로 → 내 생각을 더 깊이 → 진짜 이해 + 내 언어
```

**입학사정관이 이미 알고 있는 것**
- GPT 감지 툴이 아니라, **"이 학생이 정말 생각했는가?"** 를 에세이에서 읽는다.
- AI로 쓴 범용 에세이: 읽히는 순간 떨어진다 (수백 편 중 *개성 없음*).
- AI를 코치로 쓴 에세이: **너만의 목소리**가 살아있다.

🎓 **Ivy Tip 1**: AI를 금지하는 학교도, 허용하는 학교도 — 결국 *너의 사고*를 채점한다.
🎓 **Ivy Tip 2**: "하버드 AO는 에세이 한 편을 5분 안에 읽는다. 처음 3문장이 'AI 냄새'나면 끝" — Harvard '26 입학 멘토 James L.
🎓 **Ivy Tip 3**: 최근 MIT·Yale 인터뷰에서 "AI를 어떻게 쓰냐"는 질문이 등장. 프로세스를 정직하게 설명할 수 있어야 한다.

# 1. 강의 32 · AI 시대 공부법 — 핵심 원칙

**AI를 학습에 쓰는 황금 원칙 3가지**

```
원칙 1. 답 전에 내 생각 먼저
         → AI에게 묻기 전, 내 답을 한 줄이라도 먼저 쓴다.

원칙 2. AI를 선생님이 아니라 "까다로운 스터디 파트너"로
         → "이게 맞아?" 대신 "내 논리의 약점이 뭐야?"

원칙 3. AI 출력은 재료, 내 언어로 재조합
         → 복붙 절대 금지. 읽고 → 닫고 → 내 말로 다시 쓰기.
```

**왜 원칙 1이 가장 중요한가**
- 뇌는 *검색보다 인출*에서 학습한다 (Retrieval Practice 효과).
- 먼저 틀려야 AI 설명이 *기억*에 박힌다.

🎓 **Ivy Tip**: AI 없이 5분 먼저 → 그다음 AI와 대화 → 학습 효율 **2–3배 차이**.
🎓 **Ivy Tip**: Princeton '27 수학 전공 Minseo K. 팁 — "시험 전날엔 AI 끄고 혼자 백지 풀기. AI가 있으면 내가 아는 착각을 한다."

# 1-1. AI 학습의 두 가지 모드

```
❌ 소비 모드 (Consumption Mode)
   "이 개념 설명해줘" → 읽음 → 끝
   → 5분 후 기억 0. 에세이에도 내 생각 없음.

✅ 생성 모드 (Generation Mode)
   "내가 이렇게 이해했는데, 틀린 부분 찾아줘"
   → AI 피드백 → 내가 고침 → 기억 + 진짜 이해
```

| | 소비 모드 | 생성 모드 |
|---|---|---|
| 시작 | AI가 먼저 | 내가 먼저 |
| 결과 | 읽은 느낌 | 아는 상태 |
| 에세이 | AI 언어 | 내 언어 |
| 정직성 | 위험 영역 | 안전 |

✍️ **이 모듈 전체 원칙**: 모든 프롬프트는 *내가 먼저 써본 뒤* AI와 대화.

# 2. 강의 33 · ChatGPT 활용

**ChatGPT가 가장 강한 것**
- 복잡한 개념을 다양한 방식으로 **재설명** (비유, 예시, 쉬운 버전)
- 브레인스토밍 파트너 (아이디어 폭발)
- **소크라테스식 대화**: 답 대신 질문으로 내 생각 끌어내기
- 오답 분석: "왜 내가 이걸 틀렸는가" 파고들기
- o3 모드: 수학·물리·논리 추론 문제 스텝별 검증

**ChatGPT가 약한 것 ⚠️**
- 최신 정보 (지식 컷오프 존재, 웹 검색 켜야 함)
- 긴 문서 전체 분석 (컨텍스트 한계 — Claude가 더 강함)
- 출처 추적 (할루시네이션 주의 — NotebookLM으로 검증)

🎓 **Ivy Tip**: "ChatGPT o3은 수학 올림피아드 문제를 풀 수 있는 수준. AP Calc BC FRQ를 직접 풀어보고 내 풀이와 비교해라." — Columbia '27 수학 전공

# 2-1. ChatGPT — 소크라테스 대화 프롬프트

**언제**: 개념은 읽었지만 *진짜 이해*했는지 모를 때

**프롬프트 (복붙용, 실제 채워진 버전)**

```
나는 AP Chemistry의 Le Chatelier's Principle을
이렇게 이해했어:
"외부 자극(온도·압력·농도)을 주면 평형이
그 자극을 줄이는 방향으로 이동한다."

내 이해가 맞는지 소크라테스식으로 확인해줘.
답 바로 주지 말고, 내 이해의 약점을 드러내는
질문 3개만 해줘. 나는 그 질문에 먼저 답할게.
```

**이 프롬프트가 좋은 이유**
- AI가 답을 주는 게 아니라 *내 약점을 드러내는 질문*만 함.
- 나는 그 질문에 답하며 **스스로 이해를 완성**한다.

🎓 **Ivy Tip**: 이 방법으로 Yale '25 합격생 Junho P. 는 AP Chemistry 5점을 받았다. "답을 달달 외우는 게 아니라 '왜'를 파고드는 연습이 FRQ에서 터졌다."

# 2-2. ChatGPT — 오답 분석 프롬프트

**언제**: AP/SAT 모의고사 오답 검토 후

**프롬프트 (복붙용)**

```
나는 아래 AP Physics C 문제에서 오답을 냈어.

[문제 전문 붙여넣기]
내 답: (B) — 이유: 전기장은 도체 내부에서 0이라고 생각했음.
정답: (C)

내가 왜 틀렸는지 설명해줘. 단, 다음 순서로:
1. 내 논리에서 맞는 부분 먼저
2. 내가 놓친 핵심 개념 1가지
3. 같은 실수를 안 하게 기억법 1가지
4. 이 개념이 시험에서 다르게 출제되는 변형 패턴 2가지
```

🎓 **Ivy Tip**: 오답 1개당 이 프롬프트를 쓰면 **오답 노트가 자동으로** 만들어진다.
🎓 **Ivy Tip**: "변형 패턴 2가지" 추가로 AP 시험 FRQ에서 낯선 형태로 나와도 당황 안 한다.

# 2-3. ChatGPT — 브레인스토밍 프롬프트

**언제**: 리서치 페이퍼·Extended Essay 주제 고를 때

**프롬프트 (복붙용)**

```
나는 IB Extended Essay 주제를 찾고 있어.
관심사: 해양 미세플라스틱 오염 + 생태계 영향.

다음 조건을 모두 충족하는 RQ(Research Question) 후보 5개를 제안해줘:
- 4,000단어 EE 범위에서 실제로 답할 수 있을 것

각 RQ에 가능한 방법론 1줄씩 붙여줘.
그리고 5개 중 IB 채점자가 가장 참신하게 볼 것 1개를 골라서 이유도 달아줘.
```

🎓 **Ivy Tip**: "마지막 줄 '가장 참신하게 볼 것 1개' 추가 — 이게 EE 주제 선정에서 차별화 포인트." — Penn Wharton '26 학생

# 2-5. ChatGPT — 하면 안 되는 것 ❌

```
절대 금지 사용 패턴:

❌ "이 에세이 주제로 에세이 써줘"
❌ "이 문제의 답 풀어줘" (이해 없이 답만 받기)
❌ GPT 출력을 그대로 숙제 제출
❌ "이 단락 좀 더 좋게 고쳐줘" (내 목소리 삭제)
❌ 여러 GPT 출력을 짜깁기 → 하나의 에세이 (= 표절)
```

**학습 정직성 경계선**

| 허용 ✅ | 금지 ❌ |
|---|---|
| 개념 이해를 위한 질문 | 과제 대신 작성 |
| 내 글에 대한 피드백 요청 | AI 글 그대로 제출 |
| 아이디어 브레인스토밍 | 아이디어 없이 생성만 |
| 오답 원인 분석 | 답지로만 사용 |
| 내 풀이 검증 | 풀이 통째로 받아쓰기 |

> **학교별 AI 정책 반드시 확인.** 정책 위반 = 학점 0 + 징계.

# 3. 강의 34 · Claude 활용

**Claude가 가장 강한 것**
- **긴 문서 전체 분석** (논문 20쪽, 교과서 챕터 전체 붙여넣기 가능, 200K 토큰)
- 에세이·글쓰기에 **구체적·논리적 피드백** (어디가 약한지 정확히 짚음)
- 복잡한 주장 구조화 (Outline → 논리 흐름 점검)
- 다국어 지원 + 뉘앙스 (한국어 ↔ 영어 논리 대조)
- **Projects 기능**: 과목별 컨텍스트 유지 (세션 종료 후에도 기억)

**Claude가 약한 것 ⚠️**
- 실시간 웹 검색 없음 (최신 데이터 주의 — Perplexity 보완)
- 긴 수학 계산 체인 (계산 실수 가능성 — ChatGPT o3 보완)

🎓 **Ivy Tip**: 에세이 초고를 ChatGPT로 브레인스토밍 → **Claude claude-sonnet-4-5에서 비평** — 이게 최강 콤보.
🎓 **Ivy Tip**: Claude는 "날카로운 피드백을 줘"라고 하면 진짜로 준다. GPT보다 솔직한 비평에 강하다. — Yale '26 Writing Center 튜터 추천 툴.
🎓 **Ivy Tip**: Claude Projects에 "나는 IB HL Chemistry 학생이고, EE 주제는 X야" 저장 → 이후 모든 대화에서 매번 설명 불필요.

# 3-1. Claude — 논문 요약 + 비판적 분석 프롬프트

**언제**: IB EE·AP Research 논문 읽을 때

**프롬프트 (복붙용)**

```
아래 논문 초록과 본문 발췌를 읽고 분석해줘.

[논문 전문 또는 발췌 붙여넣기]

다음 4가지로 나눠서 답해줘:
1. 핵심 주장 1–2문장 (내가 인용 가능한 형태, APA 형식으로)
2. 연구 방법의 강점 1가지 + 한계 1가지
3. 이 논문이 내 RQ("미세플라스틱이 산호 백화에 미치는 영향")와
   어떻게 연결되는지 1문단
4. 추가로 읽어야 할 방향 1가지 + 검색 키워드 추천

한국어로 답해줘.
```

**이 프롬프트가 좋은 이유**: 단순 요약이 아닌, **내 리서치 맥락에 연결**된 분석을 받는다.
🎓 **Ivy Tip**: "APA 형식으로 인용 가능한 형태" 추가하면 나중에 Bibliography 작성 시간이 50% 줄어든다.

# 3-2. Claude — 에세이 비평 프롬프트

**언제**: Common App 에세이 / IB ToK 에세이 초고 완성 후

**프롬프트 (복붙용)**

```
내 Common App 에세이 초고야. 다음 기준으로만 피드백해줘:

[에세이 전문 붙여넣기]

피드백 조건:
1. 내 목소리(voice)가 살아있는 부분 — 구체 문장 2개 이상 인용
2. 사정관이 "이게 누구 글이야?"라고 할 것 같은 부분 — 구체 문장 지적
3. 스토리 구조: Hook → 전환 → 인사이트 → 의미 — 각 파트 충족 여부
4. "이 학생이 대학에서 무엇을 할 것인가"가 느껴지는가 — Yes/No + 이유
5. 절대 내용을 바꿔 쓰지 말 것. 질문이나 지적만.

GPT처럼 "멋진 에세이네요" 식 칭찬 말고, 약점만 날카롭게 말해줘.
```

🎓 **Ivy Tip**: "칭찬 말고 약점만" — 이 한 줄이 AI 피드백의 품질을 **3배** 높인다.
🎓 **Ivy Tip**: 피드백 받은 후 "4번 조건이 아직 부족해. 이 에세이 어느 문장을 고치면 그게 살아나겠어?" — 후속 프롬프트로 핀포인트 수정.

# 3-3. Claude — 개념 구조화 프롬프트

**언제**: AP/IB 개념이 머릿속에서 엉켜있을 때

**프롬프트 (복붙용)**

```
나는 AP Microeconomics의 아래 개념들이
서로 어떻게 연결되는지 헷갈려:

- Price elasticity of demand
- Total revenue test
- Consumer surplus
- Deadweight loss

이 4개를 연결하는 개념 지도(텍스트 형태 트리)를 만들어줘.
그리고 "A가 증가하면 B는 왜 어떻게 변하는가"를
각 연결에 한 문장씩 붙여줘.
나중에 내가 혼자 다시 그릴 수 있는 형태로.
마지막으로, AP Microeconomics 시험에서 이 연결고리가
출제되는 전형적인 FRQ 패턴 1가지 알려줘.
```

✍️ **실습**: 지금 가장 헷갈리는 개념 4–5개를 이 템플릿에 넣어라.
🎓 **Ivy Tip**: "나중에 내가 혼자 다시 그릴 수 있는 형태로" — 이 조건이 있어야 AI가 시험에 실제로 쓸 수 있는 형태로 구조화해준다.

# 3-4. Claude — ToK 에세이 심화 분석 프롬프트

**언제**: IB Theory of Knowledge 에세이 초안 작성 전·후

**프롬프트 A — 주제 분석 (복붙용)**

```
IB ToK 에세이 제목: "[제목 입력]"

이 제목을 분석해줘:
1. 제목에서 핵심 Knowledge Question은 무엇인가
2. 이 질문에 답하기 위해 탐구해야 할 Areas of Knowledge 2개 추천
3. 각 AOK에서 쓸 수 있는 Real Life Situation 후보 2개 (구체적, 진부하지 않은 것)
4. IB 채점자가 이 제목에서 가장 보고 싶어 하는 논리 구조는?

한국어로.
```

**프롬프트 B — 논리 일관성 점검 (복붙용)**

```
아래는 내 ToK 에세이 초고야.
전체 논리 흐름에서 "주장이 갑자기 바뀌는" 지점,
또는 "근거 없이 단정하는" 지점만 찾아서 줄 번호와 함께 알려줘.
내 결론을 바꾸지 말고, 논리적 취약점만.
```

🎓 **Ivy Tip**: ToK는 IB 점수 중 가장 구별력 큰 과목. Claude로 "논리 취약점만" 받으면 채점자 눈에 논리 구멍이 없어진다.

# 3-5. Claude — 하면 안 되는 것 ❌

```
절대 금지 사용 패턴:

❌ "이 ToK Essay 제목으로 에세이 완성해줘"
❌ "내 EE 결론 써줘"
❌ Claude 피드백을 반영하지 않고 그냥 제출
❌ "번역해서 제출할 거야" — 번역도 표절
❌ "내 에세이 더 학술적으로 다시 써줘" → 내 목소리 완전 삭제
```

**국제학생 특별 주의 ⚠️**

| 상황 | 허용 | 금지 |
|---|---|---|
| 영어 에세이 | 논리 피드백 요청 | "자연스럽게 다시 써줘" → 제출 |
| 번역 과제 | 내 번역 검토 | Claude가 번역 → 제출 |
| 이해 확인 | 한국어로 개념 설명 요청 | 한국어 답 → 영어 번역 제출 |
| ToK/EE | 논리 구조 점검 | 에세이 대신 작성 |

> **"AI가 했지만 내가 제출"** — 이미 부정직. 학교·대학 모두 징계 대상.

# 3-6. 🎓 실전 꿀팁 모음 — Claude편

- **팁 1 (복붙)**: `"내 에세이에서 '내가 아닌 것 같은' 문장 5개만 골라줘. 이유 포함."` — 자기 목소리 감지기.
- **팁 2 (복붙)**: `"이 논문 발췌 500단어를 읽고, 내가 인용해도 되는 핵심 클레임 3개를 MLA 인용 형식으로 정리해줘."` — 리서치 페이퍼 시간 절약.
- **팁 3 (복붙)**: `"아래 두 문단 중 어느 쪽이 더 IB EE 채점 기준에 맞는가? 구체적 기준 항목으로 설명해줘."` — 두 버전 비교 심사.
- **팁 4**: Claude Projects에 과목별 프로젝트 만들기 (예: "IB Chemistry EE 프로젝트") → 논문·노트·교사 피드백 쌓아두면 컨텍스트 유지.
- **팁 5 (복붙)**: `"내 주장이 맞다고 가정했을 때, 가장 강력한 반론은 뭐야? 그리고 내 주장이 그 반론에 어떻게 답해야 해?"` — 에세이 반박 단락 준비.
- **팁 6**: Harvard '28 합격생 Soomin Y. 팁 — "Common App 에세이 마지막 검토는 Claude한테 '이 에세이 읽고 이 학생이 어떤 사람인지 한 문장으로 말해봐'라고 함. AO 시뮬레이션."
- **팁 7 (복붙)**: `"이 에세이에서 내가 보여주고 싶은 특성은 [호기심/리더십/회복력]이야. 지금 에세이에서 그게 실제로 전달되고 있어?"` — 의도 vs 실제 전달 차이 진단.
- **팁 8**: 영어 에세이 최종 교정 프롬프트 — `"문법·어휘만 수정해줘. 문장 구조와 단어 선택의 나다움은 건드리지 말고."` — 스타일 보존 교정.

# 4. 강의 35 · NotebookLM 활용

**NotebookLM이 가장 강한 것**
- **내가 올린 자료만** 기반으로 답변 → 할루시네이션 최소화
- 출처를 문서의 특정 문장으로 **바로 추적** (리서치 필수 스킬)
- 여러 문서를 올리면 **교차 분석** ("교과서 vs 논문 이 개념 차이")
- 팟캐스트 기능: 내 자료를 **듣기용 대화**로 자동 변환 (이동 중 복습)
- 마인드맵 기능: 업로드 자료 기반 개념 지도 자동 생성

**NotebookLM이 약한 것 ⚠️**
- 올린 자료 밖의 정보는 모름 (의도된 제한)
- 이미지 기반 PDF 분석 제한
- 영어 자료에 더 최적화됨 (한국어 자료: 영어로 올리면 더 정확)

🎓 **Ivy Tip**: NotebookLM은 "내가 올린 것만 믿는다"는 점에서 AP Research / IB EE Literature Review의 **가장 안전한 리서치 도구**.
🎓 **Ivy Tip**: Princeton '26 학생 — "교과서 챕터 3개 + 논문 5편 올리고 '이 자료들에서 공통으로 언급하는 핵심 개념 5가지'를 물으면 Literature Review 뼈대가 나온다."

# 4-1. NotebookLM — 세팅 방법

**Step 1: 자료 올리기**

```
올리면 좋은 자료:
✅ AP/IB 교과서 PDF (저작권 없는 버전)
✅ 내가 쓴 노트 (Google Docs, PDF)
✅ 학교 수업 슬라이드 (선생님이 준 것)
✅ 리서치 논문 (공개 논문, arXiv, PubMed 등)
✅ YouTube 자막 (복사-붙여넣기)
✅ AP College Board 공식 Practice Exam 해설

❌ 올리면 안 되는 것:
❌ 유출된 시험지
❌ 저작권 있는 상업 교재 스캔본
❌ 타인의 에세이나 노트 (저작권 + 윤리 문제)
```

**Step 2: 질문 전 내 답 먼저** (원칙 1 유지)
**Step 3**: 답변의 출처 문장 반드시 확인 — 노란 하이라이트 클릭

# 4-2. NotebookLM — 복습 Q&A 프롬프트

**언제**: 시험 1–2주 전 핵심 개념 복습

**프롬프트 (복붙용)**

```
업로드한 AP Biology 챕터 8 자료를 기반으로
다음을 해줘:

1. 이 챕터에서 시험에 자주 나올 개념 Top 5 (자료 근거 출처 포함)
2. 각 개념에 대해 "왜 이게 중요한가"를 한 문장으로
3. 내가 헷갈릴 것 같은 개념 쌍 2세트 (예: 유사분열 vs 감수분열)
   → 핵심 차이점 한 문장
4. 이 챕터 내용에서 AP Exam Free Response 스타일로
   나올 수 있는 질문 2개 예시 (업로드 자료 기반으로만)

답변마다 내 자료의 몇 페이지/몇 번째 단락인지 출처 달아줘.
```

🎓 **Ivy Tip**: 출처 추적 습관 = 나중에 **참고문헌 작성**이 훨씬 쉬워진다.
🎓 **Ivy Tip**: "FRQ 스타일 질문 2개" 추가 — 자료 범위 안에서 실전 예측 문제를 자동으로 뽑아준다.

# 4-3. NotebookLM — 팟캐스트 기능 활용법

**어떤 기능인가**
- "Audio Overview" 버튼 클릭 → 내 자료를 2명이 대화하는 형식으로 자동 변환
- **이동 중, 자기 전** 복습에 최강

**활용 워크플로우**

```
① 내 노트 + 교과서 챕터 → NotebookLM 업로드
② "Audio Overview" 생성 (5–10분 팟캐스트)
③ 등하교 중 청취 → 핵심 키워드 메모
④ 집에서 메모 기반으로 직접 개념 설명 녹음(셀프 설명법)
⑤ 내 설명에서 빠진 부분 → 다시 NotebookLM Q&A
```

🎓 **Ivy Tip**: Columbia '27 학생 — "AP US History 주요 단원 5개를 팟캐스트로 만들어서 러닝할 때 들음. 단순 암기보다 훨씬 오래 기억에 남는다."
✍️ **실습**: 가장 어려운 과목 노트 1챕터를 올리고 팟캐스트 생성해보기.

# 4-4. NotebookLM — 교차 분석 프롬프트

**언제**: 서로 다른 관점의 자료를 비교해야 할 때 (ToK, EE에 특히 강력)

**프롬프트 (복붙용)**

```
업로드한 두 논문을 비교해줘:
- 논문 A: [제목]
- 논문 B: [제목]

다음 기준으로:
1. 두 논문이 동의하는 핵심 포인트 2가지
2. 두 논문이 서로 다른 결론을 내리는 지점 1가지
   → 각자의 근거 포함
3. 내 EE 주장("미세플라스틱이 산호 백화를 가속한다")에
   A, B 각각이 어떤 증거를 제공하는가
4. 두 논문 중 내 주장에 더 유리한 논문과 이유

출처: 각 논문의 구체적 문장이나 섹션 번호 포함.
```

> 이 프롬프트 하나로 **Literature Review 초안**의 절반이 나온다.
🎓 **Ivy Tip**: "내 주장에 더 유리한 논문" 추가 → EE 토론 단락에서 어느 논문을 메인 소스로 쓸지 전략 결정에 도움.

# 4-5. 🎓 실전 꿀팁 모음 — NotebookLM편

- **팁 1 (복붙)**: `"업로드한 모든 자료에서 '아직 해결되지 않은 연구 질문'이나 '한계점'으로 언급된 부분 모아줘. 출처 포함."` — EE 연구 공백 찾기.
- **팁 2 (복붙)**: `"이 챕터에서 정의(definition)가 명확히 나오는 용어 목록 만들어줘. 쪽수 포함."` — 용어 사전 자동 생성.
- **팁 3**: 자료를 올릴 때 내가 쓴 노트 + 교사 슬라이드 + 논문을 함께 올리면 NotebookLM이 교차 분석 → "교사가 강조한 것 vs 논문에서 나온 것" 자동 비교.

- **팁 5**: Yale '26 학생 — "SAT Reading 지문 10개 올리고 '주제별 어휘 클러스터' 뽑음. 어휘 암기 대신 문맥 학습."

# 5. 강의 36 · AI vs 인간의 역할 분리

**핵심 질문**: 어디까지 AI, 어디부터 나?

```
┌─────────────────────────────────────────────────────┐
│            AI가 잘 하는 것 (위임 가능)               │
│  ┌────────────────┐  ┌────────────────┐             │
│  │ 정보 수집·요약  │  │ 문법·스타일 교정│             │
│  └────────────────┘  └────────────────┘             │
│  ┌────────────────┐  ┌────────────────┐             │
│  │ 개념 재설명     │  │ 구조 제안       │             │
│  └────────────────┘  └────────────────┘             │
├─────────────────────────────────────────────────────┤
│            내가 해야 하는 것 (위임 불가)              │
│  ┌────────────────┐  ┌────────────────┐             │
│  │ 내 경험 선택    │  │ 내 목소리로 쓰기│             │
│  └────────────────┘  └────────────────┘             │
│  ┌────────────────┐  ┌────────────────┐             │
│  │ 최종 판단·주장  │  │ 에세이 핵심 스토리│           │
│  └────────────────┘  └────────────────┘             │
└─────────────────────────────────────────────────────┘
```

🎓 **Ivy Tip**: "내가 해야 하는 것" 영역에 AI가 들어오는 순간 — 그 에세이는 더 이상 입학사정관에게 *너*를 보여주지 않는다.

# 5-1. AI vs 인간 — 역할 분리 기준표

| 단계 | AI 역할 | 내 역할 |
|---|---|---|
| **아이디어** | 브레인스토밍 5가지 제안 | 그 중 나와 맞는 것 선택 |
| **리서치** | 논문 요약, 교차 분석 | "이게 내 주장에 왜 필요한가" 판단 |
| **개요** | 논리 구조 제안 | 내 경험에 맞게 재구성 |
| **초고** | 문단 예시 1개 | 내 언어로 처음부터 다시 쓰기 |
| **피드백** | 논리 약점 지적 | 약점 수정 (AI에 맡기지 않음) |
| **최종** | 문법 오류 체크 | 전체 읽고 내 목소리 확인 |

> **"AI가 제안 → 내가 결정 → 내가 작성"** 이 순서가 무너지면 표절.
🎓 **Ivy Tip**: 에세이 최종본을 소리 내어 읽어봐라. "이게 내 목소리인가?" — 어색하면 AI가 너무 많이 들어온 것.

# 5-3. 국제학생을 위한 AI 활용 특별 전략

**한국어 배경 학생의 흔한 문제**

```
문제 1: "영어로 생각이 안 나" → AI한테 번역 → 제출
→ 해결: 한국어로 ChatGPT와 개념 이해 → 영어로 내가 직접 작성

문제 2: "내 영어가 틀릴까봐 두려워" → AI 교정 후 제출
→ 해결: 내 영어 초고 완성 → Claude에 "문법만 체크, 스타일 건드리지 마" → 내가 수정

문제 3: 논문 영어가 너무 어려움
→ 해결: NotebookLM에 올리고 "이 논문을 쉬운 영어로 핵심만" 요청
         → 이해 후 내 노트를 한국어로 작성 → 영어 논문 작성 시 참고

문제 4: "에세이 주제가 한국적 경험인데 영어로 표현이 안 돼"
→ 해결: 한국어로 경험 먼저 자세히 쓰기 → ChatGPT에 "이걸 영어로
         표현하면 어떤 단어가 어울려?"만 물어보기 → 문장은 내가 직접
```

🎓 **Ivy Tip**: 영어 실력을 숨기려 AI를 쓰면 역효과. **진짜 실력이 에세이 인터뷰에서 드러난다.**
🎓 **Ivy Tip**: Yale '27 국제학생 합격자 — "인터뷰에서 에세이 내용을 구체적으로 물어봄. 내가 쓴 글이 아니면 대답 못 한다."

# 5-4. 흔한 실수 & FAQ

**❌ 흔한 실수**
- AI에게 "이 주제로 에세이 써줘" → 자기 목소리 없어짐
- 여러 AI 출력을 붙여넣어 하나의 문서 만들기 (짜깁기 = 표절)
- AI 피드백 반영 없이 초고 그대로 제출
- 프롬프트 없이 "설명해줘" 한 마디 → 피상적 답변만 받음
- 모든 도구를 ChatGPT 하나로만 쓰기 → 장점 못 씀

**Q. 학교에서 AI 사용이 금지되면?**
A. AI 없이 공부한 것처럼 설명할 수 있으면 된다. AI로 이해를 돕되, **제출물은 내 글**.

**Q. AI가 틀린 정보를 줬다면?**
A. NotebookLM: 출처 확인. ChatGPT/Claude: 항상 원본 자료로 검증. **AI는 도구, 교과서가 정답**.

**Q. 어떤 도구를 먼저 써야 하나?**
A. 개념 이해 → ChatGPT. 리서치 → NotebookLM. 글쓰기 피드백 → Claude.

**Q. AI 사용 사실을 에세이에 밝혀야 하나?**
A. 대학별 정책 확인. 일반적으로 AI 보조 = 문제없음, AI 작성 = 위반.
