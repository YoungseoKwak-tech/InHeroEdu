# Module 4 · Learning Architecture
### 시즌 2 · 학습 시스템

> 미국 대학은 "시험 잘 보는 학생"이 아니라 **"스스로 배우는 시스템을 가진 학생"** 을 키운다.
> 그 구조를 먼저 이해해야, 내 공부 OS를 설계할 수 있다.

# 한국식 vs 미국식 학습 (도표)

| 한국식(흔함) | 미국 대학식 |
|---|---|
| 정답 암기 | 개념 적용·논증 |
| 교사가 떠먹임 | 스스로 읽고 옴 |
| 시험 = 끝 | 시험 = 중간 점검 |
| 혼자 공부 | 토론·협업 |
| 정답 1개 | 근거 있는 여러 답 |

🎓 **Ivy Tip**: 교수는 "맞았냐"가 아니라 **"어떻게 생각했냐(reasoning)"** 에 점수를 준다.

# 강의 12 · 미국 대학 수업 구조 (해부)

```
Lecture (대형 강의)  → 개념 입력
   ↓
Reading (사전 독서)  → 진짜 학습은 여기
   ↓
Section/Discussion   → 적용·토론
   ↓
Pset/Essay (과제)    → 산출
   ↓
Office Hours         → 1:1 보정
```
> 핵심: **수업 전 reading**이 80%. 강의는 보조.

---

# 강의 13 · 교수는 무엇을 평가하는가

| 평가 요소 | 비중(체감) | 의미 |
|---|---|---|
| 개념 적용 | ★★★★ | 새 상황에 쓰는가 |
| 논증 구조 | ★★★★ | 근거→결론 |
| 독창성 | ★★★ | 내 생각이 있나 |
| 정확성 | ★★ | 사실 오류 없나 |

🎓 **Ivy Tip**: rubric(채점 기준표)을 **제출 전에** 읽어라. 거기에 답이 다 있다.

---

# 강의 14 · 시험보다 중요한 것

```
시험 점수 ──┐
            ├─→ 결국 "배운 걸 만들 수 있는가"
산출물    ──┘     (프로젝트·논문·코드)
```

- GPA는 입장권, **산출물은 차별점.**
- 시험은 "잊지 않았다"의 증명, 산출물은 "쓸 수 있다"의 증명.

✍️ 1분: 이번 학기 배운 것으로 만들 수 있는 작은 산출물 1개?

---

# 강의 15 · 학습 시스템 설계 (4층 구조)

```
4층  산출 (Output)   : 프로젝트·노트·글
3층  복습 (Review)   : Active Recall·간격반복
2층  정리 (Capture)  : 노트 시스템
1층  입력 (Input)    : 강의·교과서·논문
```
> 대부분 1층만 한다. **아이비식은 2~4층이 두껍다.**

# 📂 실물 — 코넬 학생의 주간 학습 운영표

`[그림: 실제 코넬 학생의 Notion 주간 대시보드 스크린샷]`

- 월: reading 입력 / 수: section 적용 / 금: recall 복습 / 일: 산출 정리.
- 시험기간에 몰아치지 않고 **분산**되어 있음.

🎓 **Ivy Tip**: "공부 시간"이 아니라 **"공부 단계"** 로 주간을 짜라.

# Personal Academic OS — 4개 기둥 (도표)

| 기둥 | 도구(예) | 역할 |
|---|---|---|
| Capture | 노트(Cornell/Notion) | 입력 정리 |
| Organize | Drive·폴더 체계 | 자료 분류 |
| Schedule | Calendar | 단계 배치 |
| Review | Anki·Recall | 장기 기억 |
